# 0.42.0：写作来源贯通生图与确认稿

日期：2026-10-30。完整大版本仍在进行，本批不是全引擎恢复、真实业务或最终用户验收完成。

## 行为变化

- 从独立写作对话提交图片时，固定原写作交接、分析会话/轮次、材料版本、画像、账号和引擎的简洁来源记录，不复制分析报告正文。
- 新受理、领取以及调用生成端前分别复核来源。原分析或材料变化、原对话删除时，尚未提交的图片结束为错误，提示返回原分析重新准备。可识别的写作交接任务缺少或携带不匹配来源证明时，不静默绑定最新分析。
- 已经派发的请求保留实际结果及原来源，不伪造取消或重新生成。同一请求标识先读取原回执；底层队列读取回执不依赖当前凭据，但原请求参数和模型仍须匹配。Web入口继续执行现有渠道完整性校验。
- 会话工坊发送所属会话，并使用独立的`studio-`轮次。停止模型轮次不会误取消手动图片；手动图片不登记成助手交付，也不投影出虚假的模型思考、活动或重复图片。普通对话助手生图继续沿用原交付链路。
- 新成功图片保存实际文件SHA-256；准备稿和确认稿仅在文件字节、原任务路径及成功回执精确匹配时附带来源。隐藏元数据仅定位任务，不采信其自行声明的来源。旧图片、普通媒体及替换后的图片不编造归因。
- 正式服务器生图准入改为观察持久`ImageJobs`终态，修复已生成图片却因访问废弃内存表而请求失败、media占位持续繁忙的问题。认证、并发限制和未知状态保留规则继续生效。

## 升级与限制

版本从0.41.1递增minor为0.42.0，产品版本、前端版本及锁文件同步。既有SQLite表继续使用，来源和图片哈希为可选字段；旧成功图片保持可用而不反向伪造来源。

升级前按既有流程备份数据并停止旧worker；旧worker不理解新来源检查，不可混跑后承诺该保护。此处是升级要求，本轮没有操作138或发布安装包。

分析、任务与图片数据库独立，准入复核不是跨库全局原子事务。最终本地复核通过后来源仍可能发生变化并已提交供应商；保留真实结果及原来源。文件hash证明指定字节和来源记录相符，不证明图片语义贴合正文、生成质量、供应商真实性或发布授权。独立写作不会被来源变化递归停止。

测试管理员`gaojitest / gaoji`仅适用于7920的本地隔离实例，正常密码哈希，不植入生产默认账号。该实例关闭后入口不可用，不能当线上服务。真实付费模型、平台发布、全仓回归、138部署、安装器及最终用户验收均未在本批完成。
