# Easel 0.21.0候选：经验控制与预算召回

2026-10-26，基于79331bea。原0.13的画像经验服务已具来源、确认、版本、失效、迁移及账号过滤；本批扩展该服务，不另造存储系统。0.20.1任务响应式和紧凑目标菜单保留，完整大版本继续进行。

## 行为

- 画像页经验标题同行新增“读取经验”“保存候选”两枚共享开关；窄窗口换行。默认均开启，保持已有行为；关闭不会删除经验、候选或未保存草稿。
- 关闭读取后，Web聊天、共享CLI及模型上下文不注入经验；偏好与红线仍独立。关闭保存候选后，HTTP、分析面板和CLI提案统一拒绝，已有条目仍可管理；显式旧文迁移不受此开关阻断。应用控制不构成同OS用户下的执行隔离。
- 召回先过滤范围/状态/来源，再关键词排序；默认5000、上限12000正文字符，最多8条。超额条目跳过后继续考虑后续小条目；预算不是完整提示词的token上限。
- 返回并记录选择原因、匹配数、所选数、字符预算和使用量；记录只含条目ID/版本及元数据，不含查询或经验正文。预览细节留在原折叠区，逐轮记录兼容旧数据；候选和有效经验仍需用户明确区分。
- 策略与数据变更共用画像revision及事务并发检查，跨页刷新复用原共享事件。组装后版本改变不得登记旧快照；同轮重试不改原条目、策略与预算记录。
