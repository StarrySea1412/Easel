# 当前对话目标模式：纠正与验收

日期：2026-10-16。用户两次纠正：“目标是这一个，你搞错了！”、“这样子不应该是这样子吗”。参考截图为输入框的目标命令，以及对话旁展示目标、勾选步骤、耗时和暂停的紧凑面板。

## 使用方式

本机入口：http://127.0.0.1:7880/ 。进入一个 OpenClaw 对话，在输入框输入 `/`，选择“目标 · 设置要持续追求的目标”，或输入 `/goal`、`/目标`，也可以在命令后写目标正文。方向键选择，Enter 或 Tab 打开设置，Escape 关闭菜单。命令在本地处理，不作为普通消息发送给模型。

设置窗口直接绑定当前对话，无需选择结果对话。执行模型沿用输入框/当前会话选择并明确显示，可通过共享模型选择器调整。“仅保存”不执行，“设置并开始”才请求启动。默认执行上限折叠显示：5轮、1200秒、40次工具、0张生图；Token和金额尚无硬封顶。

目标在对话右侧显示，包含目标正文、步骤完成数、实际累计耗时、暂停/继续和阻塞原因。已完成步骤勾选并划线；没有步骤回执时显示“尚未收到步骤更新”，不生成虚假百分比。桌面使用308px侧栏，窄屏使用可收起浮层；聊天页标题的目标按钮可重新打开。

暂停先持久化停止屏障，再停止精确运行。后台未确认结算前仍占位，不能重复启动；输入草稿保留。暂停/阻塞且已结算时可修改目标，保留原模型、累计轮次、时长、工具与生图限额，清理旧步骤和验收结果，需明确继续。完成/取消的目标保留历史，可建立新目标。

“定时任务”仍在左侧时钟入口，管理周期计划并汇总已有目标；目标创建入口回到当前对话。工具栏和会话列刷新仍默认折叠。当前工作台无管理员认证，本轮没有新增账号系统。

## 真实步骤与质量验收

增加原生 `easel_goal_update` 工具，接收稳定ID的步骤列表及 pending / in_progress / completed / blocked 状态，最多32项、同时最多一个进行中。可信运行器提供会话和工具调用身份，模型不能传入运行身份冒充其他会话。

步骤更新必须匹配当前运行的工具准入记录、目标revision和stopEpoch。SQLite持久化步骤和事件；已停止或修改后的晚到更新被拒绝。执行保护能力版本提升为2，旧插件不允许启动新目标。步骤工具同样消耗工具额度。

步骤用于解释实际工作进展，不代表质量通过。blocked步骤让自动推进停在“等待你的输入”；未完成步骤不因自动文件检查通过便提前完成。全部步骤完成后仍需满足原有证据和人工质量标准，最终确认才完成目标。真实模型是否正确拆分并及时更新步骤仍需付费端到端验收，本轮没有调用真实模型。
