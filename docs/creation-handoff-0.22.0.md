2026-10-26，基于45a8b512，沿用已有CreationDrafts、分析来源解析、创作编辑器和发布回执，不新建并行工作流。任务容器响应式、132像素目标菜单及经验控制保留，完整大版本继续进行。

## 行为

- 准备稿记录素材相对路径、SHA-256和长度；可通过easel_prepare_publish的analysisBindingId或prepare_publish.py的--analysis-binding绑定同一对话已保存的分析。来源记录原平台账号、作品ID、分析轮次及材料/结果组合版本，不把来源不明的文字补成分析事实。
- “载入编辑”先读取并核对服务器准备稿，来源变化、素材丢失、原对话删除或旧未版本化稿均不替换当前编辑内容。成功后保存上一稿和preparationId，刷新、切页和恢复上一稿延续实际绑定；读取期间继续编辑也不会被迟到响应覆盖。
- 发布稿接收区去掉原有双层装饰卡片与额外留白，沿用原按钮和短分组标题，不新增常驻解释。
- 来源会话的发布编辑器使用该会话画像；独立发布页沿用当前全局画像。已载入稿件仍可人工编辑和添加素材。
- 保留原账号检查、预检和最终发布确认。确认后的批次先按平台持久封存实际标题/正文/话题/画像、素材版本及副本，原稿和人工编辑分别可核对；确认接口本身不登录、不调用模型、不发布。
- 发布服务核对确认稿、来源版本、素材及本地账号版本后再建立发布回执，执行时使用封存副本。回执保留确认ID、准备ID、来源轮次、分析摘要、画像、payloadHash及素材摘要，排除正文；同一确认稿已有回执时不再启动第二份。封存成功不等于平台提交成功，平台结果仍由原回执语义决定。
- 无准备来源的手工草稿保持原流程；旧助手稿保留可读历史，但需重新准备后载入，不能把旧路径当成已有字节证据。账号版本是本地登录资料指纹，不是平台在线身份保证；原有在线核验仍必需。

发布时固定提交重建前后端，停写后备份完整数据、SQLite一致快照和素材副本；先隔离检查旧手工稿、新稿、原分析及重启持久化。回退需完整一致备份，旧代码不会执行新确认检查。本批不部署138、不发布安装器。来源检查和回执建立跨两个存储，并非全局事务；封存确保实际执行字节固定，不能承诺其他进程同时删除来源时中止已经建立的外部发布。

分析报告仍是写作材料，不能直接宣称已成稿。自动分析→写作入口、自动经验提取/替代、统一token预算、全部引擎恢复、真实模型效果和成本对照仍未完成。本批不调用付费模型、不自动发布、不改Codex个人记忆。
