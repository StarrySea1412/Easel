更新：2026-10-01，Asia/Shanghai。目标是本地安装的专业创作工具；本轮没有加入付费门槛。源码分支为 `codex/creator-workflow`，原 0.2.6 EXE / ZIP 保留，未重新打包或发布 Release。

最新增量为 [产出搜索、排序与媒体预览](office-media-search-2026-10-01.md)：已完成 263 项前端回归、桌面/窄屏搜索排序、图片失败重试及视频/音频实际播放。下方保留首轮实现和历史证据，最新通过范围以该记录为准。

## 员工形象与可见工作

- 用真正的 Three.js 几何重画小动物员工：小猫、兔子、狐狸、小熊；保留服装、毛色、点缀色、眼镜、耳机、坐姿及爪部动作。扩大工作区，提供员工近景和全景切换。
- 设置 → 员工角色卡可编辑七张外观卡。办公室成员详情可显式绑定角色卡，显示名与真实 Agent 身份分别保留。实时员工不通过任务文字猜测岗位。
- 查阅、编写、视觉处理、工具执行、协作分派采用不同动作。实时具体动作必须有属于该员工的未配对工具调用；只有笼统运行状态时显示“具体操作未上报”。演示始终注明模拟。
- 工位屏幕通过 Canvas 纹理显示任务、操作类型、已上报工具名与状态；内容变化才重绘。资料夹、绘图板和笔按具体动作出现。选中员工的清晰屏幕展开区放在三维场景下方，展示同源任务与记录，不遮挡动物。画板图形是操作示意，演示文稿有明确模拟标识；真实模式不虚构产物正文，也不是远程桌面直播。
- 名牌布局同时避让其他名牌、人物、手部操作区域和全部工位显示器（含空工位）；连接线放在名牌后面。近景只保留选中员工名牌，空间不足的名牌隐藏，完整成员列表继续可用。
- 从成员列表切换时近景和详情同步；聚焦身份消失后退出近景；WebGL 重试恢复当前近景目标。
- 完成、错误、停止有独立状态和变化反馈；观测失败冻结旧画面并注明快照。前台约每次请求完成后两秒观测一次，不宣称实时事件推送。

## 思考与工作过程

点击员工头顶状态或详情中的“查看过程”，打开可用键盘操作的过程面板，支持 Esc 关闭及焦点归还。

思考正文只取精确主 Agent、会话、轮次匹配的模型返回记录或已保存消息；子 Agent 未上报内部思考时明确显示不可见。工具调用与回执通过不透明 operationId 和工具名配对，不展示原始参数或未上报输出，不把“返回”当成“成功”，不生成隐藏思考。

后续迭代已增加工具名/可见摘要搜索及状态筛选，完整配对共同保留，切换身份重置条件；新增验证见 [文本产出与调用检索](office-records-2026-10-01.md)。

当前筛选的调用/回执还可导出 JSON，产出监控增加本次观察的新发现与更新提示，见 [变化提示与导出验收](office-observation-export-2026-10-01.md)。

## 工作区产出监控

办公室增加全工作区近期文件、类型筛选、图片/视频/音频预览及文件下载入口。演示示例没有真实下载链接。

后续迭代补充 TXT/MD/SRT/VTT 的 UTF-8 纯文本预览：展开时按需读取，最多 64 KiB，支持超时、失败重试与取消；HTML/SVG 不内嵌渲染。正文可能与列表元数据快照不同，不能确认员工归属。

最新产出清单支持当前最多 20 项内的文件名/路径搜索及最近修改、名称、大小排序；已读计数与操作限定最终可见列表。媒体加载失败可直接重试，关闭或筛选移除时释放资源，排序保留播放状态；详见 [媒体与搜索验收](office-media-search-2026-10-01.md)。

`GET /api/workspace-outputs` 只扫描元数据，不读文件正文。最多返回 20 项；有目录、深度与条目上限；排除内部记录、隐藏文件、链接和已知凭据文件命名。现有项目元数据无法可靠证明员工或会话归属，因此所有文件明确标为工作区产出，文件存在也不等于内容已经验收完成。

## 模型与多 Agent 打断

- 员工详情的模型与执行区读取已经配置的渠道和模型，不暴露密钥。必须有准确会话、轮次、创建回执与网关身份才能操作。
- 模型分配使用不含管理员权限的会话级连接。目标须被网关确认为终态，且最近运行 ID 与当前观测对应；保存后影响该 Agent 会话的后续模型调用，不会重新执行已完成任务，也不自动创建员工。
- 单个子 Agent 停止使用准确 session key + runId；可能停止该员工的派生任务，不停止父 Agent 或同级员工。主 Agent 按整轮会话停止，按钮明确区分范围。
- 请求成功发送不代表停止成功。只有匹配的网关回执才显示确认；超时、旧轮次、身份缺失、权限未核验均不伪造成功。已确认的停止回执有界缓存，并重新核验同轮同运行及网关终态后才更新办公室状态。
- 当前网关模型配置 RPC 缺少运行状态的原子比较条件。本应用校验目标终态，并为主 Agent 模型保存使用本地及跨进程会话锁，但无法保证排除其他客户端在检查与保存之间重启同一会话。界面因此使用“后续模型调用”作用范围，不承诺热切换原子性。
- 不自动配对、不扩大已有设备权限。隔离预览没有真实模型配置，完整模型分配与停止依赖已配对且支持相应 RPC 的网关。

## 其他可靠性改进

- 对话草稿按会话保留文字和当前窗口中的已上传附件。刷新只恢复文字及需要重新附加的素材名称；只有明确接受发送才清空草稿。异步上传回到原会话，删除会话后不会被晚到结果复活。
- 停止对话期间保留流连接与正在运行状态，避免旧停止回执清理新任务。失败可重试，自然完成不重复插入停止消息。
- 选题与排期严格校验存储、原子写入、跨进程锁及版本冲突检查。损坏文件保留原样并返回错误，发布成功但排期写入失败会单独说明。
- CI 增加前端安装、测试、lint、构建。正式 Windows 打包在打包前重建并检查前端，固定安装器目录、版本名和自检退出码。远程 Actions 与本地检查分别记录，本轮未生成新安装器。
