# Easel 0.20.1 候选：任务工作区响应式

2026-10-26，基于585674f1。用户要求修复任务工作区缩窄后的布局，保留精简文字与紧凑目标菜单；完整大版本目标继续进行。

原样式只按整个窗口的900/650像素判断布局；侧栏展开后，内容区变窄仍可能使用两列，详情和控件被挤压。现在以任务页面本身为inline-size容器，布局内层只负责间距，不新增可见卡片或说明。

- 内容区大于860 CSS像素时，任务列表与详情左右排列；不大于860时上下排列，列表内卡片按宽度自动排布。
- 内容区不大于480时，顶部操作、详情标签、预算及验收信息使用窄布局；长标题和操作文字可换行，搜索框可收缩。
- 保留搜索、筛选、原任务身份、深链接、键盘操作和数据保护，不改变执行或恢复协议。

本批为patch兼容修复，产品和前端版本0.20.1，无数据schema变化。未来部署时仍须先备份现有静态资源与完整数据，按原隔离验收/切换/回退步骤执行；本批不自动部署138，不发布安装器，不调用付费模型。
