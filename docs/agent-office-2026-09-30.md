# 3D Agent 办公室与调用记录

更新：2026-09-30（Asia/Shanghai）。本轮承接 `83a9cd8`，先以 `e6e5df2` 同步上游二维码资源，再实现用户要求的三维多 Agent 展示。交付为网页工作台源码；现有 0.2.6 安装包未重新构建。

## 入口与使用

- 隔离预览：[http://127.0.0.1:7864/](http://127.0.0.1:7864/) → 侧栏「Agent 办公室」。该进程使用独立测试目录，未接入用户模型或平台账号；原 7863 进程未重启，新接口以 7864 为本轮验证入口。
- 默认「演示模式」：六个角色在 48 秒内依次分工、研究、设计、写作、检查、审阅与汇总，包含一次模拟问题和重新检查。角色、调用和时间均明确标为模拟，不会执行模型任务。
- 拖动旋转、滚轮缩放；点击人物或工位名牌选择 Agent，右侧查看任务、角色、上级与状态。可暂停动画、重播演示、复位视角。
- 「实时观测」选择普通会话，读取当前会话已存在的后台证据；备份副本不连接后台。可跳转到所选会话和运行记录。
- 调用记录支持「当前 Agent / 全部」筛选，最多展示最近 40 条。「已返回」只表示收到工具回执，不表示执行成功；子 Agent 的内部工具记录目前不可见。

项目没有自有管理员密码登录系统，`gaojitest / gaoji` 不适用；没有新增登录门禁。

## 三维实现与资源管理

`three` 0.186.x 的真实 WebGLRenderer、正交相机和 OrbitControls 渲染立体办公室，包括工位、显示器、椅子、植物、深色角色、灯光和阴影。DOM 名牌由三维坐标投影定位，人物选择使用 raycast。办公室至少有八个工位，更多 Agent 会扩展工位数量。

工作、思考、完成和错误状态驱动不同动作；等待、未知和已停止保留独立文字与颜色，已停止不继续驱动动画。演示进度和角色动作分别调度，标签更新限为每秒五次。隐藏页面停止演示计时，恢复时不跳过后台停留的时长；场景还按焦点、可见范围和减少动态效果偏好控制连续绘制。

静态家具按材质合并几何体；像素比最高 1.75。人物和建筑资源分开管理，切换 Agent 身份立即释放旧人物资源，保留工位屏幕和渲染器。离页回收几何体、材质、阴影、renderer、controls、监听器、observer 与 RAF。WebGL 初始化失败、上下文丢失或绘制失败会显示明确提示并允许重试，文字任务列表仍可用。

## 后台证据边界

只读 `GET /api/agent-office?sessionId=...` 在工作线程内读取会话 marker、当前轮次审计及至多四份精确映射的父会话日志，不扫描全部历史、不读取子会话、不调用网关或模型。

- 只有匹配的 `sessions_spawn` / `spawn_agent` 调用和携带子身份的结构化回执才能创建子 Agent。技能数量、自然语言描述和无匹配回执不能生成角色。
- 创建请求被接受，不等于子任务完成。仅已确认身份对应的 `subagents` / `sessions_list` 显式状态可以更新子角色状态。
- 会话与轮次精确匹配，并校验审计记录的日志前缀哈希、时间上下界和读取限额；已结束轮次始终截断后续事件。
- marker 在读取前、中、后做版本检查；线程返回后再次核对活动轮次、进程身份与运行状态。变化时丢弃整份未确认快照，显示轮次更新中，下一次轮询再读取。排队轮次不会被当成正在执行的轮次。
- 接口最多 32 个 Agent、40 条调用记录；前端额外校验身份、事件归属及字段。调用记录只返回工具名、调用/回执状态与已上报时间，不返回原始参数、输出、环境变量或配置。任务摘要对常见凭据格式做基础遮蔽，这不是任意敏感正文的完整脱敏器。
- 前端每次请求结束后等待 4 秒再轮询，12 秒超时；会话切换/离页取消请求并忽略迟到结果。更新失败保留上次快照、冻结动作并标记过期，成功刷新后才清除错误。
