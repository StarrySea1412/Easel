# 浏览器外壳、标签图标与0.3.0验收

本轮按用户参考调整浏览器面板，修复标签图标缺失，并将产品版本从0.2.8提升到0.3.0。源码交付和实际部署分别记录；不把编译或截图当作真实模型质量证明。

## 实现

- 单行48px工具栏包含前后退、刷新/停止、元素、居中地址、分析和更多操作；网页贴边占据剩余主体，正文/元素/日志按需覆盖展开。
- 面板尺寸变化通过受限resize指令调整真实Chromium视口，生成新观察版本，旧元素引用失效；界面不只缩放固定宽度截图。
- 所有面板标签有稳定类型SVG。网页favicon只接受后端受控获取的同源栅格图像（1秒、64KB限制）；空白、缺失、加载中或失败时保留默认浏览器图标，成功加载后替换。
- `pyproject.toml`是产品单一版本源。版本详情区分后端版本、部署build、界面版本和构建时间，不一致时提示。大模块新增或重构递增minor，兼容修复递增patch，纯文档无需升号。
