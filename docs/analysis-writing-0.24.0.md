## 行为

- 已回填且材料有效的分析结果提供“据此写一篇”；准备独立写作对话及可编辑的请求草稿，不自动发送。原分析继续展示原报告，新稿不回填为分析报告。
- 按原分析材料、结果轮次、画像名和引擎生成持久交接；重复接收同一组合返回同一写作对话，不覆盖消息或输入。来源账号保留为材料归属，不冒充当前平台在线登录身份。模型仍由原模型控件选择，本批没有锁定供应商模型或冻结画像文件内容。
- 写作来源与会话摘要同事务保存在现有tasks.sqlite3，重启可重读；正文与用户输入继续采用原会话和本机草稿机制。写作顶部以“原分析”返回来源，候选经验编辑默认折叠。
- 发送前重新核对材料/分析版本、画像、引擎和删除事实；冲突保留旧写作内容。删除写作对话后，用户再次从原分析准备会创建新对话，不复活被删ID。切换写作画像需回原分析重新准备，既有模型选择方式保留。
- 编辑分支复制已接收来源，后续发布准备稿自动绑定原分析及writingHandoffId；原有素材版本、人工确认、封存和发布回执机制继续使用。没有自动发布或绕过原发布确认。
