# 对话连接、逐轮导航与图标修复（0.2.6）

## 用户反馈与实际原因

用户在 7863 工作台看到 `gateway agent requires credentials before opening a websocket`，随后又收到“退出码 1，多半是超时或系统负载过高”的提示。实际读取的 `.scratch/skill-audit-qa/openclaw` 是此前隔离验收目录，没有 openclaw.json、网关 token 或已配对设备；本机原有 `.openclaw-easel` 配置和 18789 网关则存在。原代码同时漏传了 HTTP 请求和 CLI 备用路径的网关凭据，并把非零退出泛化成超时。

## 最终实现

- 仅解析当前网关明确配置的 token/password、环境变量引用或精确的本地 secret store 引用，不拿模型 API Key 或其他设备的 token 代替。凭据进入 HTTP Authorization 或子进程环境，不放命令行参数、前端消息或诊断日志。
- HTTP 空请求探针和对话请求使用同一凭据，凭据更改后旧探测缓存失效；流式与非流式 CLI 路径一致。
- 网关地址改变也会使探测缓存失效；CLI 子进程清除已失效的继承凭据，排队后的新请求重新读取配置。
- 区分缺少凭据、配对要求、凭据被拒、连接失败、真实超时和未知执行失败；错误作为独立对象保留，失败不会被当成模型正文或正常回答。认证失败停止无意义的自动续接。
- HTTP 空流、半截 EOF、错误对象/字符串和 CLI 启动失败均保存结构化终态，刷新恢复后仍能看到原因和已收到正文；只有完整结束才确认完成，触及长度上限继续保留截断提示。
- 对话按用户轮次生成节点，提供当前轮次、上一轮/下一轮、回到最新；桌面显示节点列表，窄屏使用轮次选择器，支持键盘与减少动态效果。用户上滚后暂停自动跟随，点击回到底部恢复。
- 轮次跳转期间保持所选节点，即使目标靠近底部也不会因平滑滚动误恢复跟随；实际用户滚动后继续同步位置。折叠内容和窗口尺寸变化同步滚动基准。
- SSE 收到完成或错误事件后取消剩余响应并释放 reader；复制操作等待剪贴板成功后才提示“已复制”，失败可重试，键盘聚焦与触屏也可访问消息操作。
- 生图工坊“查看历史作品 / 生图通道设置”使用文件夹 / 齿轮图标，保留可访问名称、提示和焦点。内容分析为柱状图，运行记录为历史时钟。
