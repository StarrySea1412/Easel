# 0.50.2 · 侧栏同平台多账号快照

本轮承接用户“可以，你开始修改吧”，只调整侧栏平台账号快照及其账号中心跳转；不重做账号管理、发布或分析系统，不自动部署138。

## 账号展示与状态

- 同时读取默认通道和独立账号，与账号中心复用名单规则、身份缓存及10分钟核验证据期限。没有账号的平台收至添加入口，不再显示七行灰色占位。
- 按平台分组，明确平台数和账号数；平台行分项显示在线、需处理、待确认、处理中，展开逐账号显示备注、昵称、默认通道标签及独立状态。一个在线账号不能掩盖另一个失效账号。
- 异常组优先并默认展开；单组默认展开，其他正常组可手动展开。不同profile不因同昵称合并；同名时补能区分的本地编号。
- 在线、需重连、身份变化、未连接、待确认、操作中分别处理。旧证据、未来时间或检查失败不能算在线；待确认不冒充已退出。核验时间留在行提示中。
- 只在快照打开时读取本地状态，15秒及健康事件刷新，不因悬停启动平台whoami；共享身份变化直接更新展示，避免hydrate→事件→HTTP循环。
- 两份名单采用同一有界请求：10秒超时、关闭/新请求取消，任一失败取消另一读并清掉旧成功；晚到响应不能恢复旧绿色状态。工作台认证过期与普通读取失败分别提供登录/重试。

## 跳转、隐私与布局

- 点击具体行携带实际accountId或default:platform进入原管理面板；不会选择发布目标、创建账号或提交内容。重复同一target可重新定位；“查看全部账号”清掉旧选中/筛选并废弃晚到历史。
- “添加账号”打开原新增表单并聚焦备注，必须用户再填写确认才创建。
- 隐私开关即时同步并在重开时读取；侧栏同时隐藏备注、昵称、title及无障碍标签中的身份。
- 弹层限制在视口内，标题和底部固定，长名单内部滚动；可用Tab、Enter、左右键及Escape，关闭恢复焦点。保留既有双栏默认折叠和导航行为。
