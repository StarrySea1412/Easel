# Easel 0.20.0 候选：原运行观察与逐轮恢复

2026-10-26，基于b4483dc9。继续完整大版本P0-R；138和安装器不自动更新，不调用付费模型。

## 行为

每个普通聊天轮次保留独立快照（`sessions/jobs/<turnId>.snapshot.json`，snapshotVersion 1）；会话最近一轮文件保留兼容。带turn_id读取最后回复时优先按该轮读取并校验所属会话。旧轮核对、迟到接受回执不覆盖新轮快照，已结束快照不退回running。旧数据无需批量改写，在正常保存或恢复时生成逐轮快照。

原请求派发前固定共享原始日志的字节边界、文件身份与边界字节摘要，元数据随运行账本保存；恢复游标及投影状态在逐轮快照内。Web重启后，其他进程仍持有会话OS锁则只读取其事件。没有活跃写入者且精确原运行支持核对时，按原身份读取后续日志、补正文快照与思考增量；只读`agent.wait`确认仍运行时，SSE继续观察，不再一律要求先停止。重复核对不重复拼接内容，不重新提交模型请求。

每次最多扫描4MiB新数据，单行上限1MiB；预算边界续读，半行留在原游标。外来run和明确属于其他runtime session的事件被忽略。文件替换、边界摘要不符、截断、坏行或超长行均不静默跳过为完整输出；保留原文件和已有回复，回到待核对。不会用原始流覆盖更新的规范最终回复，只补充能延伸已有正文/思考的前缀。缺失的规范终态、正文修订或不能匹配的前缀仍不能宣称无损恢复。

`assistant_message_end`只证明一条模型消息结束，`agent.wait=ok`只证明后台终态；两者都不自动证明原请求的完整交付。没有原本已保存的完整成功快照时，确认后台结束后仍以中断失败保留所收内容，而不是伪造完整成功。此批是原输出的持久观察，不是重新接入原WebSocket订阅、恢复全部工具帧或继续执行模型。

旧轮可独立保存、核对和释放自身占位。浏览器目前按会话持有作业：最近一轮已改变时，旧轮不能取消该会话的浏览器作业；只有已有该轮清理事实或确认会话没有页面才结算，否则保留待核对。独立图片资源依旧单独检查。

最近标记的JSON或UTF-8损坏时，已有独立轮次快照仍可观察与收尾；不替换损坏字节，不推定自己持有该会话的浏览器作业。只有独立轮次与资源事实满足原有门槛才释放占位。

## 同批修复的归属问题

- 排队请求在同时取得本进程和OS会话锁后才发布最近快照；未取得锁或取消的请求仅保存自己的轮次回执。
- 跨进程锁由线程等待时，取消本地Future不会取消实际线程；若线程晚获锁，它检查取消标记并自行释放。会话锁和渠道锁均沿用这一路径。
- 启动取消保存本轮终态，后台任务回调正常接收CancelledError；传输准备失败、锁等待失败不冒充已派发。
- 最终快照保存未确认时，资源即使已结束也不释放聊天占位；后续核对可重试写盘和收尾。初始排队/取消/超时分支也不提前宣布resourceSettled。
