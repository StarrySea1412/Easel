## 交付结果

右栏的总入口改为“新增面板”，辅助对话是其中一种工具。头部入口与标签条“＋”打开完整选择页，不会自动新建子会话。选择页按“工具 → 更多工具 → 推荐 → 重新打开”组织；文件、浏览器、终端、变更、辅助对话并列，目标位于更多工具。推荐只来自当前对话已有产物，不复制参考图个人站点或虚构已安装插件。

用户明确选择“先完成面板设计，接入现有文件与执行回执”。因此当前能力如下：

| 面板 | 本轮真实能力 | 保留边界 |
| --- | --- | --- |
| 文件 | 读取当前会话已登记产物；复用既有预览、下载与原轮次归属 | 不是磁盘目录树；不新增文件编辑器 |
| 浏览器 | 输入公网HTTP(S)地址、读取标题/地址/正文、显示来源和读取时间；“分析此页”显式添加证据与分析请求到主对话草稿 | 网页正文模式；不是共享可交互浏览器；本轮未调用真实模型 |
| 终端 | 当前运行轮或最近assistant轮的command执行回执及输出 | 只读；不能手动执行命令 |
| 变更 | 同一轮的file_change回执，保留原有错误和重试反馈 | 不是完整Git diff、暂存、提交工作区 |
| 辅助对话 | 复用上轮已交付的独立记录/草稿/模型/技能/流式反馈与关闭重开能力 | 不等同于Subagent调度内核 |
| 目标 | 保留既有目标查看/设置路径 | 本轮仅检查打开设置，不启动目标 |

同种普通工具复用一个标签，不同工具可并存，工具列表按父会话保存在本机。关闭一个普通工具不关闭其他工具。辅助对话仍支持多实例、重命名、排序、关闭与重开。浏览器读取结果在切换工具或返回选择页时保留；收起整个右栏、切换父会话、关闭浏览器标签或刷新会卸载页面快照。已经加入主草稿的引用按既有草稿规则保存。

## Easel本轮浏览器链路

1. 前端通过已有`POST /api/breakdown/link`读取网页，不调用模型。
2. 后端已有HTTP优先、正文不足/验证页面回退浏览器、站点规则与错误反馈。本机既有平台配置在相应读取分支可能被复用；不是新建隔离的共享浏览器会话。
3. 前端只以React文本展示标题、来源地址、正文和读取时间，不执行页面HTML。只接受HTTP(S)，拒绝在地址中携带用户名密码；返回来源也做校验。
4. 用户选择“分析此页”，将来源、时间、标题和最多12000字正文放入主对话引用，并追加分析请求。保留原文字、其他引用和附件，提示“发送后开始分析”。
5. 用户正常发送后沿用现有对话引擎、模型与草稿发送路径。读取页面和添加分析草稿都不自动触发模型请求。模型最终分析质量仍需真实调用另验。

验收发现旧HTTP提取会把文档站导航提前写入正文，引用上限可能截掉核心材料。本轮补充语义正文提取：优先使用达到既有正文门槛的`main`/`article`/`role=main`区域，去掉其中nav/aside/footer及脚本样式；没有足量语义区域时保留原全文回退。不改变URL、网络访问或平台登录配置规则。页面仍可能带有重复标题、标签式文档内容和正文内站点文案，并非完整Readability算法。

失败读取显示原因并保留上次成功页面，不以失败空壳覆盖有效结果。页面资料在引用中明确标注为外部证据，不作为执行指令。

## 下一阶段：从正文分析到真正可观察的浏览器

当前完成的是面板架构及有来源的正文分析入口，距离参考产品的共享浏览器仍有明确差距。建议按下面顺序推进，不把已有的链接提取接口无限扩展成浏览器内核：

1. **浏览器适配器与会话身份**：统一workspace/session/tabId、导航/后退/刷新/关闭、可见URL/标题、加载与失败状态；区分隔离配置与用户显式授权的平台配置，避免跨对话串页。
2. **页面观察接口**：同一tabId生成带时间与页面版本的正文、可访问性树/DOM摘要和截图，支持选区/元素带入对话；模型必须知道材料属于哪个页面版本。按需截取正文与读取日志。
3. **Agent工具闭环**：将导航、点击、输入、滚动、观察连接到已有网关工具调用；每次操作后读取结果并验证，支持取消、超时、重新连接和操作事件，避免仅显示“成功”UI。
4. **视觉/开发分析**：接入支持图片的模型处理布局截图；DOM、控制台和网络按需提供。验证码、凭据及提交等动作保留明确的人机边界；复杂交互验证与文本阅读分别验收。

原Subagent后续P0继续保留：持久子任务目录、打开原线程追问/steer、取消后的资源结算。本轮不将面板改造算作这些调度能力已经补齐。
