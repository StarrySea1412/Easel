## A：账号范围的数据与探索建议

已实现：

- `account_evidence.py` 将 live 与 import 账号分别写入按账号 ID 哈希分隔的目录；ID 只从本人创作页明确显示的账号号取得，昵称不作为身份凭据。没有可靠笔记 ID 的 live 卡片会计入遗漏数并跳过。
- 标准记录保留标题、标签、原始及数值互动指标、发布时间、实际采集时间、数据来源和字段缺失原因；URL 会去除查询令牌。每篇最多保留两次快照，最多保留 365 天。
- 小红书采集由 Web 进程接管快照写入，并使用账号上下文代次防止采集返回时覆盖用户刚切换或清除的数据。清除单一账号不会删除登录态或其他账号文件；旧的无主快照不会自动认领。
