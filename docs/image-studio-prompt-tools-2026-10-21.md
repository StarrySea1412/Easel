## 需求与调研

用户截图中剪贴板与提示词工具被“更多选项”隐藏，灵感示例也被折叠且输入后消失。本轮先更新两份需求清单，再读取 DESIGN.md、ImageStudioPage、ImageReversePanel、CreationWorkspaceHost、共享 ConfirmModal、已安装技能目录及对话草稿/技能持久化。

实际阅读 [WAI-ARIA Toolbar Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/) 对相关操作分组和键盘可达性的要求；Material 3 Chips 页面仅取得网页外壳，未据此宣称完成其组件规范调研。沿用本项目浅色表面、细边框、共享图标和按钮，不引入新 UI 库。

技能依据：本仓库 ecom-details-image 明确区分只输出视觉简报/Prompt 与实际 Generate；ai-image-gen 支持通用生图，但策划提示词不等于允许生成。反推仍独立使用图片元数据/视觉模型，不把 Skill 当成图片模型参数。

## 布局与交互决定

- 添加图片、从剪贴板粘贴、提示词反推并排常显，带共享 SVG 图标，自动换行。比例与生成保留原逻辑；仅蒙版/尺寸等低频设置留在更多选项。
- 灵感示例不折叠、不因已有输入消失。替换非空且不同的描述前使用应用确认框；取消保留原稿；任务锁定时禁用。
- 同一灵感区展示实际安装的提示词相关 Skill，点击携带当前描述/比例创建独立技能对话草稿，预选对应技能，不覆盖已有对话、不自动发送。打开其生图辅助面板，沿用“带入对话内容”将助手提示词带回工坊。参考图不伪装为已传入对话附件。
- 技能列表仅在工作区可见时读取，响应现有技能变更事件；读取失败保留旧列表，未安装的能力不显示为可用。普通示例不依赖技能接口成功。
