# 通知精修与夜间模式（2026-10-16）

本轮针对用户截图中的事件通知弹层改进信息层级，并在本机 `http://127.0.0.1:7880/` 增加夜间模式。通知入口保留左侧工具栏底部、设置相邻；不改历史消息编辑、停止恢复及上下文统计口径。

## 使用方式与行为

- **事件通知**：标题、未读概览、全部/未读筛选与批量已读分区显示；按今天/昨天/具体日期分组。每项显示来源、语义状态图标、完整通知文字、时间、详情和单条已读。已读项不再整体降低透明度；空列表与全部已读分别说明。
- **清空记录**：增加面板内确认，默认聚焦“取消”；确认清空不停止任务、不重放仍待处理的事件。实际通知目标继续按原路由打开；通知只标记已读，不冒充已解决任务。保留说明收至底部可展开区域：仅本标签页最近100条，刷新保留、关页期间不收录。
- **夜间模式**：进入“设置 → 外观 → 颜色模式”，选择浅色、深色·夜间模式、跟随系统。复用共享自定义选择控件，可用方向键/Home/End/Enter/Escape；没有新增浏览器原生下拉框。
- **偏好**：保存于当前浏览器 `easel:theme`，默认跟随系统。跟随系统监听设备主题变化；手动选择不被系统覆盖；同源标签页同步。存储受限时仍可切换并明确提示本次无法记忆。独立设置卡即时预览主题，无需另点保存。
- **首屏与覆盖**：主题初始化内联在页面头部、样式与React执行之前，避免额外脚本请求和固定静态文件缓存影响刷新。公共背景、文字、表单、弹层、代码、输入区和强调按钮采用配套深浅色；补旧办公室任务/协作/产出等UI表面，媒体、二维码和WebGL作品本身不强行反色。
