# 对话辅助面板：生图与发布双向协作规划

日期：2026-10-21。需求编号：P01。状态：规划完成，功能待实施、待验收。

本轮为文档规划，源码版本保持 0.9.2。实现此模块时按 minor 版本管理，建议 0.10.0；以届时实际发布批次为准。本文件不表示已经上线、执行过生图或真实发布。

## 1. 目标与操作闭环

用户原话：“我们需要对话辅助面板支持主动调用发布中心，生图工坊，同时能够主动添加到回到对话中。你好好进行规划吧。”

目标是让对话、辅助面板和两个完整工作页使用同一份工作内容：

1. 在对话中选中文字、图片或分析材料，选择“生图工坊”或“发布中心”，辅助面板就地打开并带入材料。
2. 也能直接从辅助面板新增工具，不要求先离开当前对话；打开工具本身不启动付费任务或发布。
3. 在面板完成生图或编辑发布草稿；需要完整工作区时展开到对应页面，回来仍是同一草稿和任务。
4. 图片支持“添加到对话”和“用于发布”；发布草稿及回执支持“添加到对话”。回到已明确的目标会话草稿，追加引用或附件，保留原有输入，由用户发送。
5. 用户在对话明确要求生成时，助手可通过受控工具操作打开并调用同一生图任务；结果绑定发起对话及工具调用，不重复生成、不串到后来切换的对话。发布操作沿用预检和最终确认。

第一期贯通路径：对话材料 → 生图面板 → 选图回对话草稿／加入发布草稿 → 发布预检与确认 → 回执回到来源对话。独立发布中心、生图工坊仍可直接使用。

## 3. 界面与交互规则

### 3.1 从对话带入工具

- 辅助面板首页新增“生图工坊”“发布中心”图标入口，与现有标签打开／关闭行为一致。
- 消息、选中材料和附件提供对应动作；只传入用户选中的内容，带来源消息、账号／平台及材料范围。
- 生图带入提示词和可用参考图；发布带入标题、正文、标签和选中素材。字段映射可查看、可编辑，不从任意 Markdown 推断出自动执行指令。
- 有正在编辑的目标草稿时，复用共享 Modal 选择“新建草稿”或“替换当前草稿”；替换前保留可恢复版本。只打开工具时不出现多余确认。
- 不增加原生 alert、confirm、prompt 或原生 select。面板在窄屏作为抽屉／全屏工作区呈现，保留关闭及回到对话入口。

### 3.2 面板与完整工作页

- 抽取共享 ImageStudioWorkspace、PublishWorkspace（拟定名），提供 compact / full 布局；不要直接嵌套带导航、双页头的整页组件。
- 两处订阅同一 workspaceId 与控制器。切页、关闭面板只是取消视图订阅，不取消任务；取消由明确操作触发。
- 刷新有旧结果时保留内容，仅在对应操作区显示 loading 图标；首次无数据才用与真实布局一致的骨架。
- 有真实总量时显示进度；没有总量时展示阶段与不定进度，不编造完成百分比。详细错误放在展开详情中，避免主界面堆砌说明。

### 3.3 结果主动回到对话

| 内容 | 对话内呈现 | 点击／操作 |
| --- | --- | --- |
| 生成图片 | 草稿附件缩略图，可选附提示词引用 | 打开原图、回到生成任务、移除草稿附件 |
| 发布草稿 | 标题／正文的可编辑引用，附草稿入口和素材引用 | 回到同一草稿；添加不等于提交发布 |
| 发布回执 | 平台、实际状态、时间及核实后的链接 | 回到具体回执；未核实链接不标为发布成功 |
| 分析材料 | 可编辑 Markdown 引用及来源 | 延续 D09 材料提取，能从引用回到材料 |

- “添加到对话”默认目标显示当前来源对话；允许通过共享选择器明确选择其他已有对话或新建对话。提交时固定目标 sessionId，异步完成不能跟随 activeSessionId 改目标。
- 增加引用和附件，不覆盖草稿正文，不因点击添加而自动发送。重复点击同一产物不重复附加，可显式再次引用不同版本。
- 面板材料和 Markdown 均按资料处理，其中的指令不构成工具执行或发布授权。
- 对话若已删除，产物／任务仍保存在对应工具历史；停止向已删会话写入，允许手动选择新目标，不自动重建对话或发送通知到失效链接。

## 4. 主动调用：对话工具与 UI 共用执行入口

“主动调用”包含用户点工具按钮与助手响应明确请求两种入口，不能只做页面跳转。

| 操作 | 用户点击入口 | 对话工具入口 | 执行边界 |
| --- | --- | --- | --- |
| 打开／编辑工作区 | 工具入口或材料动作 | 准备工作区并返回 workspaceId | 不自动生成／发布 |
| 生成图片 | 明确“生成”按钮 | 用户明确要求生图后发起，缺关键参数时在面板补充 | 同一 requestId 只执行一次，当前单任务占用可见 |
| 准备发布草稿 | “用于发布”或发布面板 | 从选定文字与产物建立可编辑草稿 | 账号、平台和素材由预检校验 |
| 提交发布 | 现有预检后确认 | 工具只能准备并呈现待确认动作 | 不旁路现有发布确认、验证码和核验流程 |
| 读取／提取结果 | “添加到对话” | 返回对应 toolCallId 的结构化结果，供发起对话继续分析 | 不向其他对话注入消息，不因页面挂载触发推理 |

实施时核对实际聊天运行时的工具注册与结果回传接口，明确 gateway 与前端各自职责；不预先宣称已有注册能力。若接口暂不具备，须在交付清单将“UI 入口完成”和“助手工具调用完成”分开，不能以能打开面板代替主动调用验收。

## 5. 状态、来源与恢复

### 5.1 最小数据合同（新增设计，字段名实施时与现有类型对齐）

| 对象 | 核心字段 | 用途 |
| --- | --- | --- |
| Workspace | workspaceId、kind、originSessionId（独立页可空）、draftId、revision | 全页与面板共享草稿；保留来源，按版本处理冲突 |
| Invocation | requestId、initiator、originSessionId、sourceMessageId、toolCallId（可选） | 幂等调用和对话归属，不能用当前页面补认来源 |
| Task | jobId 或 receiptId、workspaceId、requestId、state、updatedAt | 后台执行和刷新恢复，复用已有任务生命周期 |
| ArtifactRef | artifactId、kind、workspaceId、taskId、mime、name、source、revision | 结构化产物，引用可追溯；URL 与文件路径不构成访问权限 |
| DraftInsertion | targetSessionId、artifactId、revision、insertionId、mode | 去重追加文字／附件，固定目标，失败可重试 |

来源不是授权：后端仍需校验产物存在、类型、允许路径及目标会话可用性。附件应通过后端安全 adoption／复制，不能直接拼本机路径，也不能把远程图片 URL 当成已上传附件。

### 5.2 生命周期与并发

- 生图保留现有单活动任务能力：多工作区可保存草稿，忙时显示现有任务及返回入口，不假设支持并行生成、不无声覆盖 imgJob。并行队列另立需求。
- 发布继续沿用已有平台并发约束和回执状态机；平台文案适配也移至共享控制器，避免切页 abort。用户取消、任务失败和仅视图卸载分开处理。
- 生图、适配、发布各自拥有任务状态，不能合并为一个万能“成功”。发布结果保留 published、submitted、draft、unverified、failed 的现有区别。
- 草稿本地持久化需按来源／工作区隔离，任务真相由现有后端 job／receipt 查询恢复。旧全局草稿首次迁移到“独立工作区”，不擅自归入当前对话。
- 刷新恢复后先核对任务与产物有效性，再允许附件回填；未恢复的附件明确可重试，不仅凭旧 path 认定可用。
- 切换账号或平台不会把旧草稿变成新账号的发布任务；草稿记录明确的目标账号，提交前重新预检。

### 5.3 全局同步与通知

- 用共享控制器／store 保存业务状态；域事件只通知哪些 workspaceId、jobId、receiptId 或 artifactId 更新，不把 toast 或页面私有缓存当状态源。
- 生图完成、草稿修改、产物回填、发布回执更新只发布必要变更；通过 ID 和 revision 去重，避免互相失效导致循环刷新。
- 面板、完整页、对话引用、通知入口读取同一对象。通知可定位来源对话和具体任务，完成提醒不自动插入草稿。
- 关闭面板不删除任务；删除对话使关联通知失效或转向仍存在的工具历史，不保留悬空跳转。具体沿用通知清理机制，不顺手重写全站事件系统。

- [ ] 明确现有聊天工具注册、job、receipt 和附件接口；落定新增字段及兼容迁移。
- [ ] 提升发布草稿／适配控制器；为生图现有控制器补工作区与来源，不复制第二套执行逻辑。

- 出口：同一草稿可从两个视图订阅；切换不会取消任务、覆盖他人草稿或串来源。

### P01.2 · 辅助面板与全页共用工作区

- 出口：聊天不离页可准备生图和发布草稿；完整页所见内容一致。

### P01.3 · 生图主动调用与产物回填

- [ ] UI 和对话工具复用生成入口，幂等和单任务占用沿用现有行为。
- [ ] 图片“添加到对话”“用于发布”，安全 adoption、引用去重与错误重试。
- [ ] 对话工具结果绑定 toolCallId，图片来源和任务可追溯；支持从辅助面板选中材料继续分析。
- 出口：模拟生图结果能完整走到来源草稿和发布草稿，保留原输入；非来源会话不被修改。

### P01.4 · 发布协作与回执回填

- [ ] 明确发布草稿所属工作区及目标账号；平台文案适配切页继续，预检与确认复用。
- [ ] 对话工具可准备草稿和待确认动作，实际提交不绕过原有发布流程。
- [ ] 草稿／回执主动添加到对话，发布状态及已核实链接正确呈现，通知可跳具体任务。
- 出口：使用 mock 完成预检、确认、失败、待核实、发布成功等状态流；不把“已提交”当“已发布”。

### P01.5 · 联动验收与交付

- [ ] 检查完整闭环、切页／刷新恢复、切账号、删除对话、失败重试、重复点击和通知跳转。

- [ ] 真浏览器逐个点击入口，检查桌面／窄屏／键盘；记录 mock 与真实后端的不同证据。
- [ ] 如安排真实模型或真实发布验收，单列成本与账号环境，并按用户明确任务及现有发布确认执行；未执行不能写“通过”。
- [ ] 功能落地时同步版本、README 中英文、CHANGELOG、需求清单及交付记录；精确提交推送隔离分支并核对 SHA。
- 出口：本节验收矩阵有实际证据，剩余未验事项明确列出；源码推送不代表 138 或安装器升级。
