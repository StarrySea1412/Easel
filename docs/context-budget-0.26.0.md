## 行为与范围

共享实现为easel/context_budget.py，web/chat_budget.py保留兼容导出。估算版本unicode-weighted/1：ASCII每4字符约1单位，非ASCII每2个UTF-8字节约1单位，合计向上取整。这是可复现的启发式估算，不是服务商tokenizer，也不保证是实际token数上界；不能用来推算费用或原生剩余上下文。

经验参考只传profileId、revision与选中entries，不把诊断回执或读取策略循环注入。选用时同时检查原5000字（最高12000字）上限、完整序列化参考的token分配及最终本地提示包准入；超额条目跳过后继续考虑后续匹配，最多8条。不截用户正文、附件、历史或必要指令；必要内容本身超额时拒绝提交模型请求。选定后保存无正文回执，固定同轮版本与预算；已绑定轮次不因重试重新选择。

- Web流式：包含历史、附件描述/文本、写作来源、技能/角色/浏览器及交付/生图/发布指令；交付票据用同长度占位做选择，登记后仅替换末尾指令并复核。非流式与技能入口同样准入。
- Codex：按轮去重后选择经验，包含本轮开发指令、动态工具声明和附件路径清单；创建后台任务前及turn/start前检查。派发前预算变化导致的拒绝为rejected，不伪报外部运行未确认。插话按其本地载荷检查，不能测量正在运行的原生完整历史。
- 程序化CLI：画像提示和harness console入口共用估算；API每轮按当前查询选经验，在已加载系统/历史的最终请求体中评估，实际HTTP前复核。API模式不会加入技能/本机文件操作提醒。Web内旧_run_direct_chat/_run_harness_chat仅保留兼容定义，当前路由未调用；不把它们宣称为已启用Web通道。
- 外部OpenClaw原生TUI后续输入由外部引擎控制，本批不拦截；原生隐藏历史、工具/系统增补和图片token未知。预留仅为运行余量，不是隐藏用量实测，也不承诺避免所有提供商上下文错误或输出截断。
