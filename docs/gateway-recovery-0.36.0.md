# OpenClaw 原运行恢复 · 0.36.0候选

2026-10-27。原生接收连接断开后，旧运行器会自动abort；服务重启后的孤儿运行即使结束，也只能保留部分正文并判连接中断。本版继续观察原runId，不因连接丢失主动取消、不重发提示词。明确停止仍使用原runId取消。

## 结果证据

agent.wait的runId必须一致；pendingError、yielded或非终态继续等待。明确矛盾的终态会话/运行身份不结算。旧网关ok/error只证明provider已结束，不能证明回复完整。完整回复另需terminalReceipt中的原runId、实际runtime sessionId、非空provider turnId、visible disposition，有效endedAt，以及terminalReply的visible正文。限长、工具中断、过滤、失败和abandoned等不转成功；错误回执使用短的归一化原因，不输出原生错误内容。

本机安装的OpenClaw 2026.9.2分发源码包含agent.wait、terminalReceipt及terminalReply；该摘要由生产者截至4096 UTF-16单元。本版为避免把截断长文当完整结果，达到4095单元边界便保留已有部分正文，不采用RPC摘要。未达到边界的短正文按终态回执恢复，可替换过时的流式前缀。没有改变或升级OpenClaw，也没有验证138当前网关能力。

恢复按原会话OS锁串行，先保存脱敏结果证据，再完成有界raw读取、正文快照和运行账本，资源清理确认后才释放占位。快照失败可用原证据重试，清理失败只重试清理；旧轮次不覆盖新轮次，也不取消新轮次的浏览器资源。原生完成只代表本轮回复结束，任务人工验收、暂停/停止和图片资源结算仍独立。

沿用原SSE、最近一轮和目标恢复入口，没有新增常驻说明块。原生工具事件在已连接时继续采集；断线期间缺失的工具/附件事件不补造。本版不承诺恢复全部长回复、全引擎在途订阅、原生权限对话或不可变历史文件字节。
