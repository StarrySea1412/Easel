## 问题与改动

2026-11-05用户截图中的发布标题、正文区域按1280px居中，草稿操作区creation-actionbar漏了相同宽度及居中约束，因此在宽屏上贴到页面左边。0.46.2为操作区补齐与正文相同的宽度、居中和900px单栏约束；独立卡片整理带入对话、助手草稿及回填操作，保持原入口。

只读核对正式草稿库：截图同名草稿来自同一轮两次准备，正文分别3472和3478字，完整内容SHA不同，准备时间相隔约28秒。两份均保留，不按标题合并。列表补准备时间、正文字数、目标平台及已载入状态，载入按钮可访问名称区分版本。当前编辑内容、草稿备份、平台选择、素材和后端校验逻辑保持。

成品浏览器进一步发现，这两份10月22日历史草稿没有schemaVersion，现行checked接口连纯文字也拒绝载入。补丁仅允许无素材、无分析来源、字段有效且属于当前会话的旧文字稿作只读规范化投影；不改原数据库记录、ID和正文。旧媒体、未固定分析来源、未知协议版本及非法字段仍拒绝载入。后续确认稿的内容、账号与素材封存校验保持。
