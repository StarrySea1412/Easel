## 实现

- 对话产物和图片任务均按“图片 → 文件操作 → 折叠提示词”展示，提示词默认收起，失败及原任务核对操作保持可见。配对只认明确任务归属，刷新只读取原结果。
- 点击图片使用共享原图modal，支持下载、关闭、遮罩关闭、Escape、Tab焦点约束及返回原控件；锁定背景滚动，图片完整适配弹窗。
- 顶部工作进度读取同会话同轮次卡组回执，区分已保存数量和助手审图。读取失败保留已有计划和图片状态，错误在展开区域可见；结束后的瞬时失败最多自动重试三次，也可主动重读。图片完成不自动勾选其他步骤。
- 本机已安装技能详情新增“修改提示词 / 保存提示词 / 取消”，支持Ctrl/Cmd+Enter。正文和历史保存在持久数据目录skill-prompts.sqlite3，不修改安装包或ClawHub来源哈希；并发冲突返回409并保留输入。本轮选用时注入已保存正文，脚本和参考路径仍指向原安装目录。保存不调用Agent或生图。
- 小红书卡组默认调用专用image生图；只有用户当前明确要求HTML/网页时才交付该格式。既有数量、费用、幂等、参考主体和审图规则保留。旧任务不会自动重做。
