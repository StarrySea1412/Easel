# ComfyUI 模拟运行与说明信息悬浮展示（2026-10-17）

## 起因

用户原话：“comyflUI应该是有模拟页面，而不是说完全就是用不了啊。。我们一些解释，为什么是折叠展开呢？你应该看看如何通过info的icon，hover展示信息”。两点要求：①未配置 ComfyUI 时面板要有可用的“模拟页面”而不是整体禁用；②解释性文案不要藏进折叠展开（`<details>`），应使用 info 图标 + 悬停浮层（项目已有的 `InlineInfo hover` 模式）。

## 现状核查

- ComfyUI 面板（并发工作，本轮先将其收口为 `bd26881c`，并把被零上下文补丁错放到文件尾部的技能表条目归位为 `fd3f058b`）在未配置 `COMFYUI_BASE_URL`/`COMFYUI_WORKFLOW_PATH` 时提交与测试连接全部禁用，没有任何可体验路径。
- 解释性文案藏在折叠里的位置：ComfyUI 面板说明（标题下短句以外的细节此前无处可放）、镜头语言参数说明、视频工坊“模型与生成说明”、通知面板“本机记录”存储说明。
- `InlineInfo` 组件已内置 `hover` 模式（ⓘ 按钮 + 指针悬停/键盘聚焦打开 portal 浮层，Escape 关闭，触屏不触发悬停），引用草稿等处在用。

## 实施内容

**ComfyUI 模拟运行（fail-closed 不变）**

- 后端 `web/comfyui.py`：`ComfyVideoRequest.demo`；`ComfyVideoService` 增加可注入 `demo_render`（测试不依赖 ffmpeg）与 `demo_delay`；`_start_demo`/`_run_demo`/`_render_demo`：模拟任务走与真实任务相同的作业生命周期（`mode: 'demo'`、稳定 jobId、状态文件、取消事件），用本机 ffmpeg 生成 4 秒 `testsrc2` 占位视频，`validate_mp4` 校验后按 `source='comfyui-demo'` 登记到原对话产物（描述“模拟输出：本地占位视频（非模型生成）”）；取消在渲染前不留文件、渲染后清理半成品；ffmpeg 缺失时任务失败并给出明确原因；`config()` 增加 `demoAvailable` 与更新后的 note；真实提交仍要求已配置工作流（未配置时 400，不触发任何付费通道）。
- 前端面板：新增“模拟运行”按钮（未配置时也可用，配置后与“提交到 ComfyUI”并存）；运行中提示“正在本地生成占位视频（不调用任何模型服务）”；结果区显示琥珀色“模拟”徽标、可播放/下载，并注明“不是 ComfyUI 或任何模型服务的产物”；“取消模拟”使用模拟专用文案（后端 `cancel` 按 mode 区分）。

- ComfyUI 面板标题旁 ⓘ（悬停/聚焦）：工作流用途、两项配置（`COMFYUI_BASE_URL`、`COMFYUI_WORKFLOW_PATH`）、提示词节点自动识别、fail-closed 与模拟运行的语义边界。
- 镜头语言参数摘要旁 ⓘ（阻止点击冒泡以免触发展开）：字段如何并入提示词节点。
- 视频工坊“模型与生成说明”折叠块移除：改为行内的“模型与生成说明 ⓘ”，悬停展示当前模型、计费提示与快捷键/字数限制。
