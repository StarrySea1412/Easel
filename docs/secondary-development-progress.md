## A：数据与热词建议的后端初版

已实现：

- `account_stats.py` 读取可得的标题、标签、发布时间和点赞/收藏/评论；缺指标保留 `None`。
- `outputs/_analytics/<platform>-notes.jsonl` 保存版本化逐篇记录；每个笔记保留最近两次采集，写入时裁剪 12 个月前的数据；清除入口不删除登录态。
- `/api/analytics/notes/{platform}` 返回快照和采集时间范围；账号登录失效时 `/api/analytics/{platform}` 附上次成功时间及 `stale` 标记。
- `/api/analytics/insights/{platform}` 提取标题/标签候选词，给出关联笔记标识、样本量、点赞均值与证据说明；小样本或缺指标降级。
- `/api/analytics/insights/idea` 写入现有选题存储，按来源和标题拒绝重复项。

已有测试：`tests/test_xhs_account_data.py`、`tests/test_xhs_insights.py`，覆盖快照、保留期、缺字段、登录失效、提取、入库、重复及错误输入等模拟场景。`0524768` 的历史提交记录声明两项 Skill 校验与 `account_stats selftest` 通过，并注明全量 pytest 存在与基线相同的环境失败；本轮未在这些分支重跑。真实账号端到端验证仍未完成。

与规划的实质差距：

- 采集只将当前页面上限从 8 篇增加到 20 篇，未实现分页；标题仍截断为 100 字。API 的 `window` 是采集时间范围，不能当作笔记发布历史的覆盖证明。
- 快照按平台保存，缺稳定账号标识与账号切换隔离；缺分享指标、字段缺失原因和完整的指标时间窗契约。
- 目前的建议引用只有笔记标识和标题，没有逐篇指标、原文 URL 与采集时间；排序使用原始点赞均值，未做发布时间/曝光机会校正或同义词归并。
- 两个分支均未改前端，尚无热词建议展示、清除历史、加入选题后的导航与失败重试界面。没有公域趋势来源；现有输出仅适用于本人历史主题的探索。

结论：后端初版已提交，A 的完整用户路径尚未交付。

## C：预设、发现及本机配置导入

已实现：

### ⑦本轮交付与验证

`codex/windows-installer` 已实现以下交付项，使用方法见 [Windows 安装说明](windows-installer.md)：

- EXE 内置版本、官方 Release ZIP 地址与 SHA-256，拒绝命令行替换；仅临时网络故障有限重试，校验失败、永久 HTTP 错误、证书或权限错误停止。
- ZIP 路径/Windows 设备名/大小写冲突/链接检查，临时解压后原子发布；版本并排、已校验版本恢复与引导器并发锁。
- 八阶段 `setup.ps1` 实际执行与 Python runner 接线，状态绑定版本/安装路径；日志脱敏、成功阶段复用、失败和中断恢复。
- `.env`、画像、产物、素材及相关登录 Cookie 的持久数据路径；递归补缺迁移、文件完整后再发布、拒绝目标目录链接，版本目录 Junction 兼容已有技能。CLI/Web/子进程共用路径，并传递实际 `EASEL_PYTHON`。
- 显式迁移来源对应的旧 workspace Junction 可安全改向，失败恢复原链接；未知目标不覆盖。升级后重启所属 Easel Gateway 更新代码与数据环境，严格区分 `easel` 与其他 profile。
- 最终执行 `doctor --install-mode` 及本次安装目录的真实 Web 首页 HTTP 检查；成功后才切换启动器，保留上一个成功版本入口。首次模型配置可在安装完成后填写。
- PyInstaller EXE、源码/预构建前端 ZIP、精确 Python 版本锁、固定 OpenClaw 版本、校验文件与许可证的构建流程；手动 Actions 工作流只产出构建候选，不自动公开发布。
