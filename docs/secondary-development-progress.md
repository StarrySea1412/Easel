## A：账号范围的数据与探索建议

已实现：

- `account_evidence.py` 将 live 与 import 账号分别写入按账号 ID 哈希分隔的目录；ID 只从本人创作页明确显示的账号号取得，昵称不作为身份凭据。没有可靠笔记 ID 的 live 卡片会计入遗漏数并跳过。
- 标准记录保留标题、标签、原始及数值互动指标、发布时间、实际采集时间、数据来源和字段缺失原因；URL 会去除查询令牌。每篇最多保留两次快照，最多保留 365 天。
- 小红书采集由 Web 进程接管快照写入，并使用账号上下文代次防止采集返回时覆盖用户刚切换或清除的数据。清除单一账号不会删除登录态或其他账号文件；旧的无主快照不会自动认领。
- 账号页提供本人数据采集、JSON 导入预览与确认、实际覆盖范围、逐篇证据、失败重试、加入待做选题和按账号清除。导入数据会明确显示未经平台核验；选题保存引用、指标与覆盖说明。
- 建议只从当前账号的标题/标签提取，逐条列出引用笔记、指标、时间和缺失项。指标不全时不按零计算；所有建议保持探索性，不声称关键词带来增长。

定向测试包括 `tests/test_xhs_account_data.py`、`tests/test_xhs_insights.py`、`tests/test_xhs_evidence.py` 和 `tests/test_account_lifecycle.py`，覆盖账号切换、采集与清除竞争、导入失败原子性、指标/URL 归一化、保留期、证据追溯和选题入库。真实账号端到端验证仍未完成。

与规划的实质差距：

- live 采集目前仍只覆盖创作者笔记管理页当前可见的最多 20 篇，未分页；采集时间范围不表示笔记发布历史覆盖范围。
- 目前没有可靠的分享指标和曝光分母；点赞均值未按发布时间或曝光机会校正，也没有同义词归并。无公域趋势来源。
- 真实本人账号验证依赖用户登录后进行；模拟数据测试不证明平台 DOM 长期稳定。

结论：账号隔离、静态建议、证据展示和选题入口已实现并有离线测试；分页与真实账号验收仍未完成。
