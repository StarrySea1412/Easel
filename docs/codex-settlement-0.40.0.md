## 行为

恢复已确认的原生终态时，旧实现逐条保存正文、执行记录和终态；第一条就会保存完成状态。如果中途写盘失败，可能留下缺失终态的回放，却允许下一轮发送。故障回归已实际重现。

现在先保存仅含已核实事实的私有结算日志，再提交事件和最终快照，最后移除日志。任一边界失败都保留待确认占位。执行进程重新启动时，在原会话OS锁内补交已保存的事实，不再次读取原生历史、不执行工具、不追加模型调用或用量。重复核对不重复生成事件。

日志保存会话/轮次身份、原事件前缀长度及摘要、确定的事件序号和最终快照。提交前核对原始或已提交的完整事件内容，外来修改、损坏日志或非尾部破损均保留待核；只清理明确未完成的最后一次事件写入。单轮恢复事件上限64MiB，超过时保留待核，不能冒称已完成。文件写入flush/fsync后原子替换，覆盖进程退出恢复，不提供断电或文件系统损坏保证。

SSE在日志未清理前不发送新的成功/失败终态，旧连接错误在恢复回放中被屏蔽。读取器在yield前关闭文件，避免Windows慢观察者阻止日志替换。页面复用原有核对入口和待确认状态，不增加新的提示面板或嵌套。

0.39.2消息内补充块的鼠标/键盘及重绘状态修复继续保留。输出下载测试遗漏`private_output`依赖已修，正式服务本来有此导入；没有删除或放宽路径守卫。
