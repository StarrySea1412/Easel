# 会话备份与安全导入

日期：2026-09-30。范围：网页工作台源码；本轮未重新构建 Windows 发行包。

## 使用入口

打开「设置 → 更多设置 → 会话备份」，或点击页面顶部存储异常提示中的「备份会话」。

1. **导出会话备份**：导出当前页内可用的会话，包含未保存的更改、归档记录、正文、思考与活动文字、错误说明。正在生成时，导出已收到的全部文字（包括打字显示缓冲），标记为未完成快照。
2. **选择备份文件**：文件只在本机解析；校验后显示会话数、消息数、未完成数、归档数和部分标题。此时尚未写入会话。
3. **确认导入只读副本**：新增独立记录，保留现有会话、当前选择和正在执行的任务。导入后可打开首个记录，复制文字、逐轮浏览或新建对话；不续跑原任务。归档状态保留，可在历史会话的归档区查找。
4. **存储失败**：副本仍在当前页内，页面提示尚未保存。重试只重写最新可重试的待保存内容，不重复导入，也不解除损坏历史的保护状态；关闭或刷新前可先导出会话备份。
5. **原始存储备份**：排障入口只读当前与两个旧版会话键，原样保留损坏 JSON，并区分“键不存在”和“读取失败”。这是独立排障格式，不能直接通过会话导入入口恢复；全部读取被阻止时明确报错。

下载提示表示浏览器已收到下载请求；实际文件是否保存成功，需要在浏览器下载列表确认。本轮未进行真实浏览器文件选择和下载落盘验收。

## 数据规则

| 项目 | 规则 |
| --- | --- |
| 可移植格式 | `format: easel-conversation-backup`、`version: 1`，包含导出时间与会话列表；下载使用紧凑 JSON |
| 上限 | UTF-8 文件不超过 20 MiB、5000 个会话、合计 100000 条消息；超限整份拒绝，不截断记录 |
| 校验 | 格式、版本、时间、字段类型、角色和非空消息列表逐项验证；未知字段不透传，错误文件不部分导入 |
| 空会话 | 无消息占位不导出；全空时明确提示。仅有用户提问、仅有助手消息及未完成会话也可备份 |
| 身份和执行 | 每次导入生成新 UUID；不带入 `sessionKey`、`pendingTurnId`、`turnId`、画像、所选技能或可执行附件引用 |
| 重复规则 | 一次预览只允许确认一次；重新选择相同文件再确认，会新增另一批副本，预览文案明示 |
| 只读范围 | 不显示发送/重试/问答执行控件，不恢复任务，不请求旧用量或 Skill 证据；原有对话和生图控制器保留 |
| 内容展示 | 保留常用 Markdown 文本、表格、代码和安全链接；备份图片/音视频、内嵌资源、样式及事件不会自动载入或执行 |
| 证据口径 | 导入的思考、活动和错误是备份中的文字，不视为本机真实后台核验结果 |
| 原始值保护 | 读取失败或损坏数据仍受保护；导出不改保护状态，导入不自动覆盖或清空损坏原值 |

备份含用户的对话内容，应妥善保存。可移植备份不读取模型配置、平台凭据或后台数据库，也不包含附件文件；对话中用户自行填写的敏感文字仍可能存在。原始排障备份还可能保留旧后台关联、附件路径或历史诊断。

- 纯逻辑与合成存储：往返、全部字段白名单、损坏/未知版本/超限拒绝、UUID 冲突、原值保护、配额失败及保存重试。

- 真实 HTTP：对最终构建的首页、动态页面与引用资源逐字节比较，不等同真实菜单点击。
