# 0.45.7：把自动继续放入通用偏好

## 用户需求

将聊天输入框上方的自动继续开关移入设置页面。

## 实现

- 设置入口位于「设置 → 通用偏好 → 对话」，显示当前会话标题、仅对当前对话生效、最多自动继续2次，以及等待确认/手动停止时暂停的规则。
- 保留现有 `easel_chat_auto_continue:<sessionId>` 存储键和发送时读取方式，因此原有会话偏好继续生效；没有当前对话时不创建会话或显示可误改的开关。
- 正在运行、导入只读记录和 Codex 原生对话均禁用该设置并说明原因。持久化失败保留已保存状态，显示错误，不把失败值排队后延迟写入。
- 聊天输入区移除自动继续开关；有可继续的助手回复时仍显示独立的「继续任务」按钮，运行中禁用。

## 验证

- 前端定向回归89项通过，覆盖当前与已有会话偏好、会话隔离、设置导航往返、运行/只读禁用、写入失败及不排队、手动继续保留。
- `npm.cmd run build`：退出0；Vite报告已有的单chunk超过500KB提示。
- `npm.cmd run lint`：退出0，包含仓库既有warning，无错误。
- 本地浏览器 `http://127.0.0.1:5173/`：实际进入通用偏好并确认当前会话说明；鼠标关闭、Space重新打开并恢复原设置；空白聊天输入区不显示开关或手动继续按钮。
