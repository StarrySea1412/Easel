# R43 便携包与安装逻辑预审（2026-10-09）

本记录用于在本轮功能全部完成后执行最终审查。当前只完成仓库脚本、测试、已有产物与历史验收记录的核对，**未生成或验收包含 R40/R42 等本轮修改的最终包**。R43 不因本文或脚本测试通过而关闭。用户要求先更新计划后行动；R43 已由主任务登记在持续要求清单，本文不改写该清单。

## 当前判断

现有便携候选在结构上具备免安装运行条件：应用、预构建前端、嵌入 Python、Node、OpenClaw、FFmpeg 和指定 Playwright 浏览器位于同一目录，启动器仅使用包内运行时和 Windows 系统工具，初次打开不调用 pip、npm 或 winget。数据、配置、缓存和日志归属解压副本。已取得的隔离首启、随包 Chromium、本机 HTTP、部分真实浏览器入口与旧包搬迁证据支持这一结论，但仍不能报告为所有 Windows 用户已验收。

联网安装器具备分阶段执行、断点恢复、归档校验、安全解压、数据补迁和成功后切换版本入口的核心逻辑。它仍需联网安装依赖；程序版本回退与数据回滚范围不同。便携包没有自动升级/回滚命令，安装器也不注册系统卸载入口。若“完整安装包逻辑”指新用户安装、失败恢复、升级、数据保护、回退和移除全部实际走通，当前证据不足。

## 已核对的实现

| 范围 | 代码实际行为 | 已有边界 |
| --- | --- | --- |
| 便携装配 | `scripts/build_windows_portable.py` 校验五组件、固定浏览器修订、许可文件、相对 Python 路径和前端构建回执；排除个人状态、venv、符号链接和私有配置 | 依赖输入在构建机事先准备；最终包必须重新核对最新依赖和锁 |
| 便携环境 | `scripts/portable_launcher.py` 配置包内 PATH、独立 HOME/APPDATA、模型缓存、Chromium 路径、OpenClaw 配置与日志 | 可选模型权重未预装，模型/平台功能仍需网络与本人凭据；Windows/.NET 属系统前提 |
| 首启与配置 | 空数据初始化，不下载依赖；仅更新启动器曾托管且未被用户更改的文件 | 自定义包外工作目录不会自动迁移，启动会保留配置并给出提示 |
| 生命周期 | `start/status/stop`，同副本锁，HTTP 就绪验证；PID、创建时间、执行路径和命令行共同核验进程归属；部分启动失败清理本次子进程 | 原生按钮与关闭窗口须实际操作；仅关闭浏览器不停止服务 |
| 多副本与搬迁 | 新副本独立动态端口；再次启动优先保留原 Web 地址；停止后整体移动可重绑托管路径 | 地址冲突时会更换端口，浏览器草稿/会话绑定原地址；跨电脑迁移不由 `data` 自动覆盖浏览器本地数据 |
| 原生入口 | `scripts/portable_entry.cs` 调用包内启动器，提供启动、打开、停止、日志；正常关闭等待安全停止 | .NET 编译和无窗口探针不能替代 Explorer 双击与按钮验收 |
| 安装校验 | `scripts/bootstrapper.py` 核对内嵌 ZIP SHA，安全提取并校验清单；不一致版本拒绝覆盖 | self-test 仅验证内嵌内容及 GUI 初始化，不执行安装 |
| 安装恢复 | `easel/install_core.py`、`install_runner.py` 和 `setup.ps1` 连接 system/openclaw/pydeps/frontend/chromium/profile/skills/gateway 八阶段；瞬时网络故障重试，状态绑定版本及路径 | 中断和网络失败恢复需要在最终 EXE 实际验收；契约模拟不代替 |
| 数据与升级 | 版本目录、共享 data；只补缺失数据，已有文件保留；健康检查通过后切换入口并保存 `Easel.previous.ps1` | 上一版入口回退不恢复 data 时间点；数据结构迁移仍需备份及兼容验证 |
| 移除 | 文档要求停止服务、备份 data 后手动移除安装目录；共享 winget 工具独立管理 | 未注册系统卸载程序，也没有便携自动更新/回滚动作 |

当前 `.github/workflows/windows-installer.yml` 做安装器契约测试、前端检查、打包和 EXE `--self-test`，上传 Actions 产物；它不自动创建 Release，不实际走通全新安装、升级或回退。构建 CI 使用 PyInstaller 6.16.0，安装器文档示例为 6.22.3，最终发行前应统一并记录工具链版本。安装器文档把 Web 描述为 `127.0.0.1:7860`，实际启动脚本遇端口冲突会选空闲端口，交付说明应以实际地址为准。

## 最终包验证清单

功能完成并冻结提交后，以下顺序执行并保存每项来源、退出码、截图/HTTP/进程证据；失败修复后重新冻结版本并复测受影响范围。

1. **固定版本**：记录源码提交、是否 dirty、前端回执、组件版本与精确依赖锁、许可证、ZIP/EXE 大小和 SHA；确认新功能所需模块已在运行时内。新增源文件须纳入构建索引。不能重用相同发布版本替换不同字节。
2. **归档与空数据**：实际完整解压新 ZIP，核对全部分发文件集合和 SHA、唯一空 data、无凭据/登录态/个人产物；记录分发文件与运行数据边界。
3. **首启与依赖**：在无主机 Python/Node/npm/FFmpeg PATH、空白用户环境和 System32 工作目录下启动；记录执行路径、模块来源、端口和 HTTP 身份；随包 Chromium 做实际页面交互，PDF 做解析与渲染。断网下验证工作台就绪，不把联网平台功能当作离线能力。
4. **生命周期与迁移**：同副本重复启动不产生额外进程；停止后本副本 PID 全退出；重启、中文/空格目录及不同盘符搬迁、端口冲突与两份实际 ZIP 解压副本隔离逐项检查。对照配置/作品数据摘要，验证用户自定义内容不被覆盖；浏览器本地历史以真实备份导入范围说明。
5. **失败与恢复**：运行文件缺失、损坏记录、Gateway 超时、端口属于外部进程、忙碌时退出均给出可操作提示；不关闭其他服务、不留下本次失败启动的孤儿进程、不改写原配置。实测恢复后可用。
6. **原生入口**：Explorer 双击、启动/打开/停止/日志按钮、重复打开、启动中关闭和停止失败时保留控制窗口；命令入口的 start/status/stop 另测。真实图形路径不能用探针替代。
7. **联网安装闭环**：在干净 Windows 10/11 x64 验证普通用户目录、工具缺失、winget 允许/拒绝、网络中断、关闭进程后重试、真实 Gateway/Web 就绪；数据补迁、从既有版本升级、失败不切入口、成功后上一版可启动、共享数据兼容和备份恢复各自记录。移除后无本安装残留服务，不删除共享系统工具。
8. **产品功能与发布**：新包浏览器中核对菜单/链接和 R40/R42 数据/选择控件；真实模型、平台登录/发布和 SMTP 只在本人凭据及相应授权下各自验证。公开发行还需处理签名、完整许可审查、Release 下载及校验文件可达性；源码推送不能替代新安装包发布。

当前未取得干净 Windows、完整原生交互和最终新包条件时，应保留这些项为未验收，并给出已取得证据的便携预览结论，不宣称最终包全部通过。
