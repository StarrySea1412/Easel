| 多作品导航 | 共享作品选择列表替换横向截断标签，支持上一篇/下一篇及序号，总数、指标、来源随选择同步 |
| 侧栏与导航 | 图标随字号缩放，长标题自动省略并保留完整名称；从其他页打开会话时切换主内容 |

| 发送阻断精简 | 模型状态与上传错误分开，清除旧版写入草稿的模型报错，恢复后自动撤销提示。按用户最新要求删除“刷新模型状态”“模型设置”以及替代的“重试连接”按钮，仅保留必要的一行状态与加载图标 |
