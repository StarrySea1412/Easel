# 推理观测与画像记忆管理 0.13.0

日期：2026-10-21。由[接入方案](inference-memory-integration-plan-2026-10-21.md)进入第一版源码实现；基于0.12.0发布回执交付分支的 d85334a6，隔离分支为 `codex/inference-memory-0.13.0`。主工作区的未提交修改保留。

## 使用方式

1. 选择画像，打开“更多 → 画像 → 经验沉淀”。旧 memory.md 先展示原文和哈希；确认导入保留原文，旧内容变成待确认候选，观察日期/来源未知时不伪造。此时尚未作为有效经验注入。
2. 新经验选择“当前画像，跨平台”或指定平台与稳定账号ID；写明结论、适用条件和局限，保存候选后确认生效。候选可拒绝；有效条目可修订、失效、恢复、查看版本或永久删除。偏好与红线继续保存在 preferences.md，不被经验自动替换。
3. 分析对话辅助面板可选取已保存报告中的结论，或填入报告原文片段，保存到当前画像候选。服务端重新读取分析绑定、作品材料、结果和会话，强制原平台账号，重算来源哈希。保存不发送聊天、不调用模型、不发布内容。
4. 对话“来源”面板展开“本对话使用的经验”，查看当前画像最近20轮组装时选用的ID/版本；可读取对应历史正文。删除后的条目不恢复正文。记录表示传给模型的引用，不代表模型采纳或经验有效。
5. 原用量面板及项目模型卡展示“缓存读取占比”和有效样本数；统计口径可展开或悬停查看。未知为“未上报”，不把0%解释为无上报，也不推算费用节省。
6. 会话列表及页头通过图表、编辑笔、气泡图标区分分析资料、生成内容和普通对话，悬停显示类型。类型来自已保存的分析绑定、拆解标记或明确创作入口，改名不改变类型；刷新、编辑分支和新导出的备份保留类型。旧会话缺少来源标记时保留普通对话，不凭标题猜测。热点创作并入分析对话时保留分析身份。
7. 输入框上方的分析材料摘要默认收起，只显示账号、作品数和“查看材料”；展开显示作品及日期。Enter/空格可切换，完整材料弹窗和原绑定/草稿保持。

CLI/Skill与Web共用服务：`easel memory list --profile "画像名"`、`easel memory propose --profile "画像名" --text "结论和局限"`、`easel memory context --profile "画像名" --query "当前任务"`。账号范围加 `--platform douyin --account "稳定账号ID"`。CLI只读/提案，无激活命令。模型提案仍在画像页确认；用户明确修改偏好仍走原偏好维度，不新增同义确认。

## 数据与执行边界

- 主库为 `EASEL_DATA_DIR/memory/profile-memory.sqlite3`（源码运行未设置数据目录时使用项目数据根）。稳定profileId映射、候选/有效状态、条目修订、原文快照、轮次引用与删除摘要在同一库。删除摘要仅存去重哈希，拒绝或删除的候选不会被相同来源的晚到提案复活。
- 导入确认后 memory.md 为兼容投影，仅含画像级有效经验，不混入各平台账号正文。数据库先提交，锁内原子替换投影；写入失败保留旧文件并提示，后续重读重试。外部修改会暂停经验注入，必须先预览原文，明确保存为候选并重建。旧整文件PUT返回409；完善画像不覆盖 memory.md。
- 当前Web按服务端已保存的分析会话确定平台/账号，普通对话与CLI聊天只注入画像级经验，不凭模型猜测账号。先过滤范围、active和来源可用性，再按英文词/中文二字词匹配任务，最多8条、正文5000字符；无关经验不注入。该预算是当前经验预算，并非新增通用上下文预算引擎或embedding检索。
- 分析材料变化或来源会话删除后，已确认条目保留并显示需复核，停止注入；不会跳转到其他会话。编辑经验保留修订标签，分析结论始终为假设。复查日期是待复核提醒，不自动失效或删除。条目删除清理版本、兼容投影及关联旧文快照；轮次元数据不存正文。
- 请求和读取在共享前端服务中去重，跨页与多标签通过元数据事件失效，重挂/焦点恢复后补读。慢GET不能覆盖较新的变更；409保留编辑草稿，用户对照当前版本后才重新提交。切画像由组件key隔离草稿。
- 激活/修改要求原工作台写保护、匹配Origin与same-origin fetch元数据；确认绑定条目/画像版本、正文哈希和范围哈希。这是本机工作台的应用流程与CSRF保护，**不是Agent强隔离**。当前同OS身份的任意exec可以改SQLite或伪造本机请求；未引入受限独立服务身份或秘密审批凭证，不能宣称彻底防绕写。公网认证仍由已有部署代理负责，本次未新增管理员系统。
- Web、CLI和Skill使用版本化消息组装接口，用户原文保持，附件/历史/经验作为JSON引用，策略和运行信息单独标识。OpenClaw仍是单字符串兼容传输，没有独立高权限角色保证；序列化不保证模型永不受诱导。原发布授权、文件交付和每轮规则提醒保留，尚未启用稳定规则缩减/缓存优化开关，也未启用新推理引擎。
