# 功能验收清单（2026-10-09，R29）

这份清单供使用者逐项操作，勾选框保留给实际验收结果。开发侧已经做过的检查与未覆盖范围见 [便携版记录](windows-portable.md) 和 [持续任务清单](user-requirements-2026-10-08.md)。

## 使用哪个版本

- 当前候选：`Easel-preview-76bbaf6-3fb7.zip`，固定源码 `76bbaf690d224cf2c60496847402426a4619b5c3`。后续验收文档提交不改变这个 ZIP。
- 本机测试入口：[打开便携工作台](http://127.0.0.1:50636/)。该地址只适用于本次构建机副本，R28 启停和搬迁测试完成后保留运行。
- 另一台 Windows 10/11 x64 电脑：完整解压到较短、可写的目录，使用目录内的 `Easel.exe`。若图形入口不可用，可使用 `启动 Easel.cmd`；地址以启动入口显示为准，不能照抄本机端口。退出时使用 `停止 Easel.cmd`，仅关闭浏览器不会停止服务。
- 图形双击/按钮和没有开发环境的 Windows 仍需实际验收；本轮命令入口测试不替代这两项。当前没有公开 Release 下载地址，本地候选文件与现有 0.2.6 联网安装包分别记录。

## 再检查真实业务

下列操作需要使用者自己的模型服务、平台账号或 SMTP 配置。发布前确认内容与目标账号；模型生成按所选服务计费。本轮开发侧尚未完成这些真实业务验收。

### 小红书登录当前源码入口（R39）

开发侧在隔离数据目录启动当前源码入口 `http://127.0.0.1:50777/` 并完成 HTTP/进程级检查：首页、`/api/accounts` 和 `/api/login/xiaohongshu/status` 均返回 200；小红书卡片显示 `supported=true`、`loggedIn=false`。登录核验进程占用时重复提交得到 409，核验结束后平台明确返回 `state=error` 的网络风险分类；随后重复读取状态仍保持同一终态，没有重新打开轮询，也没有二维码。

这次环境被小红书判定为风险网络，二维码未生成。真实浏览器视觉入口、扫码/短信验证和账号登录成功尚未验证；不能把这次 HTTP 可达或错误分类检查当作登录成功。服务已停止，隔离验收目录未纳入交付。

## 便携性与反馈

- [ ] 使用同目录的停止入口，确认服务已退出后再次启动；重复点击启动不应启动重复服务。
- [ ] 先停止服务，再移动整个解压目录（包括 `data`），重新启动并检查配置、草稿和技能。跨电脑或端口变化时，会话历史可通过会话备份迁移；未发送草稿、技能选择和补充要求不在当前备份内，需要事先手工保留。
- [ ] 在没有预装 Python、Node、npm 的 Windows 10/11 x64 上验证图形入口、浏览器打开及停止流程。

遇到问题时记录：所在页面、操作步骤、预期结果、实际结果以及候选文件名。启动问题可附错误文字和时间；如需分享日志或截图，先移除 API Key、Cookie 和个人内容。发现问题继续追加到同一份 [任务清单](user-requirements-2026-10-08.md)，不覆盖已有未完成项。
