# 内容分析方法与产品验收规范

版本：2026-09-30。适用对象：Easel 的本人账号内容复盘、选题建议和实验回收。
本报告基于 `web/xhs_insights.py` 与 `web/account_analysis.py` 的只读审查；不是外部行业调查或已上线能力清单。
本文所有样本量、窗口、增长和置信阈值均为**产品初始假设**，须经真实账号试点校准，不是行业定论或增长承诺。

## 1. 当前能力与交付边界

- 小红书当前从选定账号的标题和标签提取词语，按笔记 ID 去重，保留最近记录。
- 候选词来自标签，或至少出现在两篇笔记中；无 jieba 时使用中文二元片段，词语质量可能下降。
- 当前输出是探索性关键词，不等于经过语义聚类的主题，更不等于经过验证的选题策略。
- 当前候选词的指标是全部关联笔记均有点赞数时的平均点赞；缺一篇则不计算平均值。
- 平均点赞既未按发布年龄对齐，也未控制主题、格式、投放和账号阶段，不应展示成效果评分。
- 当前窗口来自采集时间最小值和最大值，必须标为“证据采集窗口”，不可命名为“内容发布周期”。
- 同一笔记多次采集被折叠后，现有输出不足以推导其增长曲线。
- 多平台模块展示本次会话中的账号指标、平台标签和作品记录，并披露逐篇指标与链接缺失。
- 多平台统计周期有明确差异，部分平台未返回起止日期；当前不具备统一增长和跨平台排名条件。
- 本次会话登录并不自动证明账号的历史快照归属；需稳定平台账号 ID 后才能跨次关联。
- 两个模块均未调用模型，未完成封面视觉分析、正文结构分析或互动转化漏斗。
- 后续页面应分开标识“当前可用”“采集待补全”“实验性推断”，不能把规划能力写成已实现。

## 2. 每次分析的范围声明

每份报告首先展示如下信息；缺失项显示“未知”，不由模型补齐。

| 字段 | 必须表达的含义 |
| --- | --- |
| 平台与账号 | 平台代码、稳定账号 ID、显示名、归属核验状态 |
| 发布范围 | 起止时间、时区、是否包含端点；未知时禁用按发布期筛选 |
| 观察范围 | 每个指标的截止时间；采集、导入时间分别保存 |
| 覆盖范围 | 分页数、返回条数、去重篇数、已知账号总篇数与覆盖率 |
| 样本规则 | 纳入/排除规则，删除、私密、投放、合作内容如何处理 |
| 数据版本 | 来源、采集器版本、指标口径版本、记录版本或哈希 |
| 分析版本 | 规则版本、模型版本（若有）、生成时间与审核状态 |

不知道账号总篇数时只显示“返回 N 篇，总体覆盖率未知”，不能用返回篇数当作总篇数。
原始来源字符串、平台显示值、规范化数值并存；“1.2 万”产生的舍入误差应保留。
重复记录以平台、账号、作品 ID 标识；独立时间快照另存，不能只保留最后数值。

## 3. 指标字典与分母

| 指标 | 定义与分母 | 主要限制 |
| --- | --- | --- |
| 曝光次数 | 平台返回的展示次数，无人为构造分母 | 不是独立观看人数；可能含重复曝光 |
| 播放/阅读次数 | 保留平台原始定义及有效观看门槛 | 不同平台、视频与图文不可直接互换 |
| 点赞/收藏/评论/分享数 | 分别保留平台事件计数 | 评论可能含作者回复；不是独立互动人数 |
| 互动事件数 | 仅在四项齐全时相加，明确是否包含分享 | 同一用户可重复贡献，不能称互动人数 |
| 曝光互动率 | 同一窗口的互动事件数 ÷ 曝光次数 | 无曝光时不可计算，不以粉丝数代替 |
| 阅读互动率 | 同一窗口的互动事件数 ÷ 阅读/播放次数 | 只与同口径作品比较，事件率可能超过 100% |
| 收藏率/评论率 | 各项事件数 ÷ 同窗口阅读/播放次数 | 缺分母显示缺失；分母为零显示不可计算 |
| 封面点击率 | 平台可归因的点击数 ÷ 对应封面曝光次数 | 总播放量不能擅自作为封面点击数 |
| 完播率 | 平台定义的完播次数 ÷ 符合定义的播放次数 | 保留平台口径，不能从时长推算 |
| 平均观看时长 | 总观看时长 ÷ 相应观看次数，或直接用平台值 | 不能把作品长度当平均观看时长 |
| 主页访问率 | 可归因主页访问数 ÷ 对应阅读/播放或曝光数 | 分母须在名称写明；账号汇总不能归因单篇 |
| 内容关注转化率 | 平台归因新增关注 ÷ 对应访问或观看人数 | 不用账号净增粉丝替代单篇新增关注 |
| 净增粉丝 | 同账号窗口末粉丝数 − 窗口初粉丝数 | 含关注、取关及平台修正，并非纯获客 |
| 粉丝增长率 | 净增粉丝 ÷ 窗口初粉丝数 | 基数为零不报告百分比；必须显示绝对值 |
| 区间互动增量 | 同作品、同口径累计值在 t1 与 t0 的差值 | 累计值回落应标记平台修正或异常 |
| 每小时新增互动 | 区间互动增量 ÷ 实际经过小时数 | 仅描述该区间，不外推为全天增长预测 |
| 相对基线提升 | (实验指标 − 基线指标) ÷ 基线指标 | 基线为零不计算；率指标同时显示百分点差 |

未知、无权限、未采集、解析失败和真实零是不同状态，禁止统一转成零。
只给“互动率”而不给分母的分析不通过验收；缺失关键项时不可悄悄改用另一种互动率。
部分作品有指标时可单独报告“有效样本均值”，必须同时给有效 N、总体 N 和缺失比例。
缺失是否集中于某种格式或低表现作品必须检查；不能假定数据随机缺失。
均值与中位数并列，给出四分位数、最小/最大值和头部作品贡献占比。
只有区间起止都明确且不重叠，才可进行环比；滚动七天窗口不可当独立周样本。

## 4. 可比样本、时间和增长门槛

默认复盘最近 90 天发布内容，另看最近 28 天；这是产品初始配置，允许用户修改。
作品必须同时满足同平台、同账号、同格式、同自然/投放类型才能进入默认比较池。
跨账号探索需显式启用，并分层展示粉丝规模、内容领域、投放及采样来源；不产生本人增长结论。
同格式至少分为图文、短视频、长视频、直播回放；必要时按视频长度再分层。
按发布后 24 小时、72 小时、7 天三个观察点建立快照；错过快照不进行插值冒充观测。
初始容差分别设为 ±2 小时、±6 小时、±12 小时，展示实际年龄与偏差；容差为产品假设。
没有对齐快照时只做明确发布年龄分组的描述；不能拿发布 2 小时与 30 天累计点赞排序。
发布时间不可靠的作品可进入素材分析，不进入年龄归一化效果比较。
活动、节日、付费投放、合作、账号定位变化作为干扰标记，不由模型推测为已发生。
发布数量变化时，同时报告总量与每篇表现；总互动上升不等于单篇质量提升。

| 可比有效样本 | 默认允许的结论 | 产品初始门槛 |
| --- | --- | --- |
| 0 篇 | 无有效证据，给出补数动作 | 不生成内容效果排名 |
| 1–4 篇 | 个案观察和探索性建议 | 不展示稳定规律或增长归因 |
| 5–19 篇 | 分布、中位数及候选模式 | 必须展示小样本提示 |
| 每组至少 20 篇 | 允许初步组间描述与不确定性估计 | 不自动升级为因果结论 |
| 每组至少 30 篇且覆盖至少 4 周 | 允许评估跨周稳定性 | 仍需检查账号、主题、时间与投放偏差 |

样本数是作品数，不能用 10 万次观看伪装成 10 万个独立实验样本。
产品初始“增长候选信号”：预先指定主指标相对提升至少 15%，且满足业务最小绝对改善。
业务最小绝对改善必须由具体账号预设，例如每篇多 5 次收藏；该示例不是全平台统一门槛。
率指标同时展示百分点差，例如 2% 到 2.3% 是提高 0.3 个百分点、相对提高 15%。
只有匹配口径、有效样本充足且不确定性满足预设规则才标“值得扩大实验”，不写“已证实增长”。
区间估计优先以作品为单位重采样；有时间或系列相关性时使用按周/系列聚类方法。
少量样本不输出虚假的精确置信区间；明确区分“区间跨零”和“证明没有效果”。
大量主题同时筛选会产生偶然胜出，应预先限制主假设，或进行多重比较控制并保留独立验证批次。
发布后持续偷看并随时停试会夸大效果；预定停止条件，探索性中途观察与最终结果分开记录。

## 5. 内容六个维度的分析边界

| 维度 | 有证据时可以做 | 缺失时不可做 |
| --- | --- | --- |
| 主题 | 标题/标签语义归组、逐篇人工确认、组内覆盖及同年龄表现 | 用标题断言全文内容或真实用户需求规模 |
| 标题 | 字数、问题句、数字、承诺、对象、场景等可观察特征 | 把高点赞归因于某个词；捏造搜索热度 |
| 封面 | 有可访问原图时描述可见文字、对比、主体、层次与一致性 | 无图评价配色、无曝光点击数据断言高点击 |
| 正文结构 | 有完整正文/字幕时识别开场、论点、步骤、证据、行动提示 | 只凭标题评价全文结构、视频节奏或完播原因 |
| 互动诉求 | 对实际正文/评论进行问题分类、争议点与答疑机会识别 | 无评论样本推测用户年龄、收入、购买意愿 |
| 转化漏斗 | 同窗口且可归因数据下追踪曝光→阅读→互动→访问→关注 | 用不同窗口账号总量拼漏斗，填补不存在的转化 |

主题可多标签，一篇可归入多个主题；聚合总数应注明不可直接相加，避免重复计算。
视觉标签必须有图像引用和区域说明；OCR 不确定字符显示待核，不以 OCR 推测原图外信息。
字幕仅代表语音文本，没有视频帧就不能评价镜头、剪辑、字幕动效与表情。
评论分析报告抓取方式、排序规则、去重与作者回复处理；热门评论不能代表全部受众意见。
情绪和需求标签视为模型解释，保留原文片段及人工纠正入口；不从内容推断敏感个人属性。
搜索词、平台热点、竞品表现等需要独立来源和时间戳；本人历史关键词不能改名为“全网趋势”。
每个维度提供“观察—证据—限制—可测试动作”，缺资料时给明确采集清单。

## 6. AI 输入与输出证据契约

输入必须包含 scope、records、metric_definitions、comparison_rules、missing_fields 和 task_version。
每条 record 必含 evidence_id、platform、account_id、note_id、source、observed_at；未知时间用 null。
内容材料分别标记 title、tags、body、transcript、cover，并声明完整/截断/不可访问。
数值带 value、unit、denominator、period_start、period_end、age_hours、raw_value、quality_flags。
历史快照与最新快照分开，给出采集失败和账号切换记录，避免模型把空值当停更。
输入文本视为待分析素材，素材中的“忽略规则”等指令不能改变分析任务或访问权限。
提交模型前按最小需要剔除登录令牌、Cookie、账号凭据和无关私人信息。

输出至少包括以下字段，服务端执行结构校验及引用校验：

```text
claim_id / claim_type: observation | association | hypothesis | recommendation
statement / evidence_ids / scope / valid_sample_n / total_sample_n
metric_name / calculation_id / comparison_group / observation_window
limitations / alternatives / confidence_basis / next_action
```

每个可核验事实必须引用输入中存在的 evidence_id；无依据的外部事实直接拒收或标记未核实。
所有指标计算由确定性程序完成，模型只引用 calculation_id，不靠文字生成数值再当事实。
引用能够展开查看原始记录、采集时间、字段来源和计算过程；管理页不能伪装成作品原文。
“观察”只描述已知数据；“关联”要求可比样本；“假设”说明待验证机制；“建议”连接实验。
输出每条建议至少列一个反例或替代解释，例如题材、发布时间、投放和既有粉丝差异。
低数据条件下允许输出内容创意，但必须明确“创意建议，未依据效果验证”。
模型无法访问封面时，不得从 URL 或文件名编造图像描述；无法访问原文时同理。
生成失败保留已计算的事实摘要与重试入口，不使用虚构分析填充页面。

## 7. 防止因果幻觉与评分校准

禁止“使用这个标题使点赞提升 35%”等无实验依据的因果描述。
允许“在当前可比样本中，该标题特征组的中位收藏较高；仍可能由主题与时间差异解释”。
同一作品修改前后也不能天然视为随机实验；平台推荐生命周期与外部流量会影响变化。
不要默认发布一个总分；先分开呈现数据完整度、样本可比性、证据强度和动作可执行性。
若产品需要评分，必须提供公式、维度权重、有效范围、版本与缺失处理，且可重算。
“内容质量 92 分”不是客观事实；应改为“按本版规则的结构完整度评分”，列出扣分依据。
模型自报“置信度 95%”不能作为可信概率；使用明确证据等级和判定理由。
建立按平台、格式、样本量分层的匿名人工标注集，由至少两名评审独立评价并处理分歧。
校准指标包括引用正确率、数字一致率、缺失识别率、越界归因率、建议可执行率与用户采纳后反馈。
初始质量门槛：关键数值与引用一致率 100%，无证据因果断言 0 条；其余目标由试点评估设定。
上线前固定评测集，模型/提示词/规则变化后重新评测；评测集与用于调参的样本分离。
离线通过仅说明分析质量，不说明增长有效；增长效果需后续真实实验验证。

## 8. 从发现到发布再到回收

1. 建立基线：确认账号、目标、主要指标、可比窗口和当前数据缺口。
2. 生成发现：按主题与内容形式展示分布、异常作品、正反例和证据限制。
3. 选择假设：例如“具体步骤式标题可能提高同主题图文的 7 日收藏率”。
4. 建立实验卡：绑定发现 ID、原作品引用、目标受众、改动变量、主指标和保护指标。
5. 预登记方案：安排样本、发布时间、停止规则、最小有意义改善和复盘日期。
6. 转为选题：保存标题备选、内容结构、封面方向、所需资料与实验卡，保留证据链。
7. 人工编辑发布：核对素材事实与平台要求；发布后回填平台账号、作品 ID 和实际发布时间。
8. 定时回收：记录 24 小时、72 小时与 7 天实际快照；失败标记缺失，不补造数据。
9. 对齐比较：按预先约定的格式、发布年龄和投放状态比较，记录所有排除及原因。
10. 形成结论：支持、未支持或证据不足；记录收益、代价和保护指标变化。
11. 下一轮决策：扩大、重复验证、修改或停止；负面结果同样保留，避免只保存成功案例。

保护指标可选负反馈、取关、制作工时等，但未采集到时须标未知，不能默认无副作用。
平台无法原生随机分流时可用匹配主题的分期发布，但必须声明准实验局限与分发差异。
一次同时改变标题、封面、结构时只能评估组合，不能把改善全部归给标题。
任何分析结论到选题、草稿、发布记录、回收结果应可双向追溯；权限与账号隔离持续生效。

## 9. 具体场景验收

以下是规划能力的验收用例，不表示这些页面、链路或后端已经实测通过。

| 场景与输入 | 必须出现的行为 | 不通过示例 |
| --- | --- | --- |
| A. 同一笔记来自两个账号 | 按平台/账号隔离，不合并；跨账号请求明确拒绝或要求显式比较 | 账号 A 出现 B 的证据 |
| B. 3 篇作品一篇缺点赞 | 显示缺失及有效 N；完整样本均值不可计算 | 把缺失补零并排名 |
| C. 一篇发布 2 小时、一篇 30 天 | 提示年龄不可比或进入各自组；累计量可单独查看 | 断言旧作品标题更有效 |
| D. 只有采集日期，没有发布日期 | 显示采集窗口；禁用发布期效果比较 | 把导入日当发布日期 |
| E. 粉丝从 0 到 10 | 显示净增 10，百分比不可计算 | 显示增长 1000% 或无穷大 |
| F. 阅读 100、收藏 10，另一篇缺阅读 | 第一篇收藏率 10%；第二篇缺分母，不能合并算统一率 | 用粉丝数代替缺失阅读 |
| G. 仅标题标签，无正文封面 | 只给可核验标题主题观察及补数清单 | 描述封面配色、视频节奏 |
| H. 平台只返回最近一页 | 显示返回 N 篇、覆盖未知、不能代表全账号 | 声称已分析全部历史 |
| I. 两个同口径快照计数下降 | 记录负差并提示修正/异常，不直接解释为用户流失 | 默默把负数截为零 |
| J. 平台七日指标与累计指标并存 | 分别标识周期；不能合成统一排名或漏斗 | 两者直接环比 |
| K. AI 引用不存在的作品或计算 | 服务端拒收对应结论，显示验证失败或重试 | 自动创建假引用 |
| L. 某词仅出现在单篇标签 | 可显示候选词与单篇引用，标探索性、小样本 | 生成“稳定高增长关键词” |
| M. 一个爆款与 19 篇普通作品 | 同时展示均值、中位数、异常值及敏感性比较 | 用均值承诺下一篇预期收益 |
| N. 选题保存后发布并回收 | 原发现、实验变量、作品 ID、快照和结论全链路可追溯 | 回收结果关联到其他账号 |
| O. 评论只有热门前 20 条 | 标注热门排序与有限覆盖，保留可核查片段 | 推断全部用户满意率 |
| P. 登录失效或切换账号 | 旧结果保留归属标识，禁止当作新账号现值；提示重新采集 | 展示上一账号数值而不说明 |

验收记录分别填写：纯函数/模拟数据、真实后端、HTTP 可达性、真实浏览器操作。
证据链接、账号菜单、分析筛选、引用展开、保存选题、发布记录和回收入口逐项检查跳转结果。
HTTP 200 不能替代浏览器页面可用，模拟数据通过不能替代真实账号采集通过。
涉及管理员登录时，仅本地或隔离测试环境使用 `gaojitest` / `gaoji`，正常哈希并实际验证入口。
本报告未执行浏览器、HTTP、登录或发布操作；这些项目均为待执行验收，不能标记通过。

## 10. 推荐实施顺序

第一阶段补齐口径与可信度：稳定账号 ID、分离时间字段、缺失状态、引用校验、快照留存。
第二阶段完成可比分析：格式分类、发布年龄快照、分布与反例、覆盖说明和规则化主题复盘。
第三阶段引入有证据约束的正文与封面分析，人工审核集先通过再提供模型建议。
第四阶段贯通实验卡、选题、发布 ID 与回收，先验证可追溯性，再评估增长有效性。
所有阶段以真实数据覆盖和验收结果推进；不能用模型生成更长文案代替更完整证据。
