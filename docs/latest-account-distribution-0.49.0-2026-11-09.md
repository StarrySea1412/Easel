## 整合后的功能

账号中心管理小红书、抖音、快手、视频号、知乎、B站与公众号的多个独立账号。每个账号保留独立登录目录、稳定平台身份、核验状态及登录/发布记录；默认账号入口独立保留。登录态、Cookie和凭据不进入Git。

发布中心按照准备内容、选择账号、确认发布、查看结果四步展示，数字采用1、2、3、4；平台网格与对应账号分组、逐账号稿件、未知结果冻结、只重试明确失败目标继续生效。页头草稿状态/回执/默认账号入口统一对齐。

新版确认稿的来源对话、验收标识、封存素材与账号身份检查保留，并带入批次逐项回执；人工发布模式同时约束默认账号、批次和独立账号入口。B站执行器使用新版`skills/builtin`定位，独立账号身份校验模块采用独立名称，避免覆盖新版Web账号身份模块。

对话产物与创作工作区的图片任务按明确artifactIds/paths对应提示词卡片，刷新图片/任务只读取原结果；失败单张重试和卡组状态保留。生图工坊及新增创作面板工具区可折叠，已挂载输入及任务不丢失。
