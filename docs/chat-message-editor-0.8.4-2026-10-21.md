# 0.8.4 消息编辑布局修复

用户截图反馈编辑区糟糕：固定两行文本框截断长消息，原生缩放角标与焦点框形成双边框，按钮和冗长提示缺少间距，底部又重复旧轮次模型。

- 沿用聊天页面颜色、圆角、字体与按钮样式；编辑卡片有清晰边框、内边距及底部操作栏，取消/发送并排对齐。
- 文本按内容自动伸展，初始至少112px、最多40dvh；超长文本内部滚动，视口和容器宽度变化后重新计算。移除手动缩放角标和内层焦点框，外框focus-within反馈保留；按钮保留键盘焦点环。
- 可见提示精简为“发送后创建分支，原对话保留。”；快捷键通过textarea title保留，说明使用aria-describedby关联。
- 编辑期间收起旧轮次模型注脚，取消后恢复；不修改模型选择、编辑分支、草稿、取消和网络请求语义。
