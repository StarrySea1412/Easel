## 修复边界

- 修复Agent是规则控制器，不是额外付费模型；仅处理图片读取的已知allowed-directory错误。
- 源图片必须位于配置的outputs目录、扩展名受限且不超过20MiB；目标只能位于实际OpenClaw workspace的_inspect/easel-repair内。
- 每调用一次、每轮最多一次、每会话最多三次；会话文件锁串行化预算判定。先fsync并原子替换repairing占位，再复制文件。
- 崩溃留下的repairing会占用预算并在下一轮显示人工接管；复制失败也保留占位预算，不靠重启获得无限尝试。
- 用户停止后只写manual回执，不再启动复制；已在进行的系统文件复制不提供抢占式取消承诺。
- 模型、浏览器、认证、发布和未知失败只记人工接管，绝不重放请求。现行0.45.9自动继续的零工具操作限制继续保留。
- 回执校验会话与路径轮次、排除符号链接和超过24小时的记录；引用字段再次脱敏，序列化进入现行prompt envelope的reference-data区域。
- 工具生命周期保留原status，并增加admitted/running/succeeded/repairable/manual/stopped/unknown及最多8条历史；前端拒绝冲突状态，失败不会伪装成成功。
- HTTP/CLI轨迹导入也触发已确认失败的修复控制器；重新读取不得覆盖已有修复证据。
