# Easel + OpenClaw：ChatGPT → Gemini 产品视频工作流接入方案

日期：2026-10-22。状态：源码核对与方案完成，工作流功能尚未实施。

后续进度：0.13.4已补网页桥接认证；0.14.0已实现[网页下载识别、会话落盘与本机取回](browser-downloads-0.14.0-2026-10-22.md)，通过本地与138隔离跨容器验证。下文能力表保留最初0.13.3核对结果；其中主动取消下载的缺口已在0.14.0源码解决，真实目标站附件、上传、生成与完整工作流仍未验收，138正式服务未由本轮升级。

## 1. 结论与范围

可以接入，适合做成 Easel 的「产品营销视频」工作流模板。Easel 负责资料、阶段状态、人工接管和交付；OpenClaw 根据阶段调用浏览器与工具；ChatGPT/Gemini 通过网页账号完成生成；宿主媒体工具检查、剪辑与导出。

操作人员无需安装 Python/Node。集中执行时依赖放在服务器；使用本机浏览器时，交付扩展与已封装的连接程序，不能要求操作人员安装开发环境或执行 npm 命令。

本次核对基线为 `codex/shared-browser-0.13.3` / `228d8989a3d584fe3958c00545dedf2838d9b0cc`，已核对 `starry` 同名远端分支 SHA；主工作区有其他未提交工作，未混入本方案。这里证明的是源码能力与缺口，未检查138当前部署、目标电脑或两个平台登录后的端到端流程。

## 2. 已有能力与实际缺口

| 能力 | 核对结果 | 接入方式或限制 |
| --- | --- | --- |
| 共享浏览器、画面与人工接管 | `easel/browser_runtime.py`、`web/browser_api.py`、`ChatLiveBrowser.tsx` 已有 | 复用观察、元素引用、动作回执、接管与恢复前重新观察 |
| OpenClaw 操作共享浏览器 | `easel/browser_bridge.py` 已有 exec/CLI 桥接 | 不把 Codex 的原生工具注册误认为 OpenClaw 已注册同名工具；可先复用已存在桥接 |
| 当前共享浏览器上传下载 | **缺失** | `ACTIONS` 无上传动作；新 context 设置 `accept_downloads=False`，下载事件主动 `cancel()`；必须新增受任务范围约束的文件传输 |
| 共享浏览器登录持久化 | **缺失** | `new_context()` 为内存会话，持久化只保存标签/事件；重启恢复为断开页面，不保存 Cookie/profile |
| OpenClaw 原生远程浏览器 | 部署配置已有专用 CDP profile | 这是另一条浏览器链路；现有 `browser_sidecar.py` 使用临时 profile、禁用扩展，不能假设与 Easel 共享画面、账号或文件目录相通 |
| 文件上传到 Easel、产物交付 | `web/app.py` 的 `/api/upload`、`easel/artifacts.py`、`artifact_api.py` 已有 | Easel 收到附件不代表附件已上传 ChatGPT/Gemini；下载落盘后才能登记真实产物 |
| 任务记录与未知状态处理 | `easel/task_store.py`、`web/task_service.py`、`web/run_ledger.py` 已有 | 复用身份、租约和失联后不自动重发；仍需新增业务阶段、站内请求与文件之间的绑定 |
| 跨层产物清单 | `skills/shared/scripts/manifest.py` 已有 `.easel.json` | 保留内容库唯一项目元数据；现有 done/failed 记录不足以承担生成中、待登录、状态未知等完整执行状态 |
| 视频检测与合成 | `video_ops.py`、`skills/builtin/auto-short-video/scripts/assemble.py` 已有 | 复用 ffprobe/FFmpeg、字幕和混音；仍需围绕本工作流验证输入、时长、音轨与语义 |
| 现有生视频页面 | `web/videogen.py` 已有服务商 API 路线 | 本次是新增网页执行方式，不能把已有 API 生视频配置当作能使用 Gemini 网页会员 |
| 服务端运行时 | `deployment/138/Dockerfile` 已封装 Python、Node、Chromium、FFmpeg | 用户电脑可只开 Easel 网页；镜像定义不等于当前运行服务已验收 |

因此，新增 Skill 可以固定业务规则，但还不足以形成可靠工作流。需要同时补文件传输、浏览器账号会话和阶段恢复。

## 3. 浏览器执行位置

### A. 集中执行：操作人员只用 Easel 网页

复用 Easel 共享浏览器，在工作流所属的专用账号 profile 中登录 ChatGPT/Gemini。文件生成、下载、交接和剪辑均发生在服务端，操作人员在 Easel 看进度、接管网页并下载结果。

这是依赖最少的交付形态，但有一个前置实验：用目标服务器出口和目标账号验证两站登录、参考文件上传、生成入口与下载。需要验证码时交还人工；服务器网络或平台登录限制不能靠写 Skill 解决。本次没有执行此实验。

账号 profile 需要与当前普通浏览器会话分开管理：按实际用户/账号隔离、避免同 profile 并发写入、登录失效时明确阻塞。当前没有多租户账号认证，首版应按单操作员或隔离实例交付；多人隔离需要另行实现，不能仅靠 sessionId 宣称安全隔离。

### B. 本机执行：扩展使用操作人员已登录的浏览器

若必须复用用户本机登录态，或集中执行的前置实验失败，使用 OpenClaw 浏览器连接方案，文件和操作通过明确配对的本机执行节点连接 Easel。媒体处理仍可放在服务器，传输完成后校验文件一致性。

本次实际读取的 [OpenClaw 扩展文档](https://docs.openclaw.ai/tools/chrome-extension)说明：支持通过 `chrome.debugger` 操作已登录 Chrome；浏览器所在机器需要 OpenClaw 或 browser node；Windows 路线使用自包含 `OpenClaw.BrowserBootstrap.exe`。所以这条路线有机会满足不安装 Python/Node，但**只装扩展并不自动连接远程 Easel**，仍需配对、连接程序及文件通道。

项目当前 `deployment/138/runtime-package.json` 固定 OpenClaw `2026.9.6`；官方当前文档不证明这个固定版本已有相同扩展协议或 Windows helper。本次未安装、升级或实测该 helper。实施前核验具体版本、可分发产物和兼容性，再决定复用官方组件还是封装自己的轻量连接器。

首轮只实现一种浏览器执行方式，并保证 Agent 与人看到的是同一页面。不得在用户接管 Easel 面板时，后台切到另一个 OpenClaw profile 继续执行。

## 4. 操作人员实际使用流程

入口放在现有创作工作台，新增「产品营销视频」模板；首版不建设通用拖拽编排器。

1. 上传产品原图、功能说明和可选真实动作视频，选择约20秒/9:16等目标规格。用户提供不了的功能事实标为未知。
2. OpenClaw 操作 ChatGPT，整理卖点、生成独立营销图和分镜；导出脚本 Word，保留“脚本不插图”。用户可在产品事实或脚本需要确认时介入。
3. 每张图及文档逐项下载到工作流目录；检查文件存在、内容类型和大小，登记来源与哈希，再由宿主组包。页面上有图片或“打包成功”文字不算完成交接。
4. 以 `handoff.json`/Markdown 为机器交接来源，Word 为人读副本；上传 Gemini 可接受的参考资料，确认网页内已接收后提交生成。
5. 保存提交与站内会话关联，进入“生成中”；按退避间隔观察，不持续消耗模型做无意义轮询，也不占用其他会话的操作锁。
6. 下载实际视频，检查片长、尺寸、音轨和关键画面，识别它是新片段、整片修订还是延长版本，再决定补生成、替换或剪辑。
7. 复用现有媒体工具处理字幕、混音和目标导出；播放验收后在 Easel 内容库与会话中交付 MP4、脚本和所需素材包。

工作流详情展示每阶段的真实状态、产物、缺失项和下一步。提供“查看网页 / 我来操作 / 核实状态 / 继续 / 重试本阶段 / 下载结果”；每个操作的可用状态清楚，不把生成中显示成报错或凭空递增进度百分比。

## 5. 交接、恢复与成片规则

### 文件契约

项目目录继续使用 `outputs/<主题>/`，`.easel.json` 仍是内容库元数据。原始下载、参考图和中间片段放 `assets/`，交付文件放项目根；私有浏览器 profile 和运行记录不进入对话产物。

`handoff.json` 建议包含：schemaVersion、workflowId、productFacts及来源、未知功能、禁止虚构项、目标规格、分镜、配音/字幕文本、参考文件ID/哈希和已批准的内容版本。不能存 Cookie、登录凭据或以分享链接替代真实附件。

阶段运行记录作为现有任务存储的扩展保存，而非再建一套内容库元数据：阶段ID、尝试ID、稳定requestId、输入版本/哈希、浏览器执行节点、profile引用、站内会话、提交时间、外部生成证据、实际产物与检查结果。执行记录是状态依据，页面计划和 `.easel.json` 只投影阶段结果。

### 状态与恢复

业务阶段至少区分 `pending / running / waiting_generation / waiting_user / unknown / failed / completed / cancelled`。这些是拟新增的业务状态，不冒充现有 TaskStore 已支持的全部状态。

- 浏览器动作的 requestId 仅在现有进程内提供去重，不能保证跨进程或平台侧恰好执行一次。提交后断线进入 unknown，先返回原会话查证，不换新ID直接再点生成。
- 页面刷新只重连；后端重启需要重开浏览器/原站会话并核实生成状态。不会把保存了 tabs.json 解释成浏览器恢复完成。
- 已完成阶段复用已验证文件。修改原图、产品事实或脚本时，仅使相关下游阶段失效，保留历史版本。
- 停止表示停止本地后续操作/等待；平台任务可能仍在生成或消耗额度，只有平台真实取消回执才能显示远端已取消。
- 同一账号/生成会话使用资源锁；生成等待不锁住全部 Easel，但同一站内会话不得并发修改。

### 成片质量

目标是约20秒，不强制10+10。此前分享页的第二个播放器曾显示约20秒，实际文件仍需检查；不能将它与首个约10秒视频直接拼成30秒。Gemini 当前帮助说明支持多轮编辑，但目标账号能力仍以实际可用入口为准。

原始产品图提供外观事实，真实动作视频提供功能事实。生成的操作图不能作为真实机械结构证明。媒体检测可验证编码、片长和音轨，产品动作、字幕准确性与声音连贯仍需关键帧和播放验收。

精确字幕和时间线交给媒体工具。配音优先复用已验收的生成音轨或用户提供音频；如果缺少可用配音，显示缺失项，不默认调用额外收费TTS。导出1080×1920时记录原素材分辨率，不能将720p上采样称为原生1080p。

## 6. 实施顺序与验收关口

| 阶段 | 交付内容 | 通过条件 |
| --- | --- | --- |
| P0：执行路线试点 | 目标服务器/账号连通、登录、普通参考文件上传下载；如不满足则验证本机节点 | 在同一可见浏览器中完成真实文件往返，核对下载字节/哈希；有结论后才定浏览器主路线 |
| P1：浏览器文件与账号基础 | scoped上传/下载、profile生命周期、与人共用页面、传输回执 | 用户已有附件可上传站点；站点下载真实落盘；重启/登录失效有明确行为；普通浏览器回归不破坏 |
| P2：工作流模板 | 专用Skill、阶段持久化、交接包、原会话核实、内容库交付 | 先用受控页面与本地素材验证失败恢复、去重、输入变更失效和文件关联，再做真实平台测试 |
| P3：真实成片与交付 | 目标账号的一条真实产品工作流、媒体检查、播放验收和操作说明 | 逐项验证产品事实、独立图片、无插图Word、实际视频时长/分辨率、字幕/声音与下载；用户无需开发环境 |

真实视频试验需使用目标账号可用额度；本轮问题是可行性评估，没有执行生成。OpenClaw 调度依赖现有可用模型通道，与 ChatGPT/Gemini 网页生成是两层：可以不使用两站的生图/视频API，但不代表Agent推理和网页额度免费或无需配置。

功能实施属于新增模块，届时递增minor并同步产品版本、前端、双语README、更新/进度/部署说明，隔离提交推送并核对SHA。新增功能合并、138部署与安装器交付分别验收。本次仅文档，无需改号。
