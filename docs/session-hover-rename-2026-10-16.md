# 对话悬浮重命名

日期：2026-10-16。用户要求“支持悬浮重命名”，截图标注会话预览卡片的标题。

## 使用

- 在本机 http://127.0.0.1:7880/ 展开对话列表，鼠标移入会话行后点击铅笔，直接修改名称；键盘聚焦会话标题后也可按 F2。
- 悬浮预览卡片中的标题现在可点击，在卡片内修改。鼠标从列表移向卡片时不会立即关闭；编辑期间移出仍保留，点击外部或收起侧栏会取消未保存的浮层修改。
- Enter或“保存标题”确认；Escape或“取消”放弃。空白标题显示提示并保留编辑，中文输入法组合期间的Enter不保存。保存/取消后焦点回到原会话标题。
- 改名不选择其他对话，不发送消息，不改变草稿。标题沿用原有会话持久化方式；已有保存失败提示继续保留。本次不引入服务端普通会话同步。
- 铅笔在悬浮或键盘聚焦时显示；窄屏和无悬浮设备常显。原“更多→重命名”、置顶、归档和显式Agent命名建议仍可使用；手工改名不调用模型。
