# 0.14.0 分步发布、页头对齐与创作卡片

日期：2026-11-09。开发分支：`codex/multi-account-distribution-0.13.0`（分支名沿用，本次源码版本递增为0.14.0）。

## 用户所见变化

- 发布中心分为“准备内容 → 选择账号 → 确认发布 → 查看结果”。每次只展开当前阶段，返回保留通用稿和各账号独立稿。默认账号发布从页头单独进入，不再同时堆在独立账号流程下面。
- 步骤参考[Ant Design Steps官方示例](https://ant.design/components/steps/)，使用普通1、2、3、4、细连接线和当前步骤样式。共享组件`ui/Steps.tsx`支持键盘方向键、Home、End移动焦点，Enter进入；完成状态由真实状态显式传入，单纯访问结果页不算发布完成。
- 草稿状态、全部发布回执和默认账号入口统一为36px高度。移除旧回执样式额外12px底部外边距；桌面与390px浏览器回读同排三个外框的顶部、高度一致。320px时整齐换行，页面不横向溢出。
- 每个生图任务的提示词、状态和明确归属图片放在同一张卡片。长提示词保留完整展开入口；一个任务多图放在同卡内，不强行按数组顺序一对一配图。
- 配对仅接受同会话、同轮次的`artifactIds`，旧记录可使用任务明确记载的完整`paths`。冲突、多任务同时声称、跨会话或跨轮次归属均不猜测，原文件仍独立显示。
- 图片旁保留“刷新预览”，只重读已有文件；没有图片时可就近“刷新任务状态”，不触发生图模型。现有未知结果解除占位保护保留。
- 生图页“创作工具”及新增面板首页“工具”支持原生展开/折叠，内容不卸载。生图工具收起时仍显示结果画布，展开保留提示词；键盘Enter可切换。
