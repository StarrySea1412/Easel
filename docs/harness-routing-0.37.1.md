## 修复

- 主聊天入口重构遗漏了API直连和通用原生适配器的路由，设置选择与实际执行可能不一致。恢复API、ACP、OpenCode及旧Codex底座入口；用户明确选择的原生Codex会话继续使用独立CodexService，不通过旧适配器替代。
- 普通消息经持久轮次账本首次受理，重复turnId拒绝派发；流式观察与后台执行分离，断开浏览器后继续原运行、保存逐轮快照和可回放事件。已确认的模型配置在排队后再次核对，变化时拒绝发送，不自动换模型或底座。
- API直连传递真实文本/图片附件和持久历史，不拼接不存在的本机工具能力；经验召回按最终系统/历史/正文预算选择。该路径不启用0.37.0依赖原生结算的经验提案。直连保存、模型列表自测按实际底座路由，原生底座不写OpenClaw配置，私网目标仍须匹配已配置地址。
- 聊天选择器、工作台快捷发送、侧栏状态和设置渠道跟随实际底座。API不显示技能或发送思考档位覆盖，原生默认模型由CLI解析；读取失败阻止误发。设置页恢复API模型、地址和Key编辑，允许无Key服务读取模型列表，不展示该路径未支持的容量覆盖或删除操作。
- 轮次执行面板以原账本中的运行器身份隔离证据，API/兼容适配器不套用OpenClaw工具记录或Agent行为；结束后显示“本轮记录”，旧思考事件不再冒充当前执行。
- 原轮次停止、超时与异常清理沿用适配器；服务正常关闭时回收本机HTTP请求、CLI进程池及权限等待。先保存终态与资源收尾，再释放持久会话占位；写盘失败保留待核实。未取得精确原生恢复协议的服务重启保持未知，不重新发送提示词、不调用OpenClaw等待或中止其他底座。
- 旧删除URL与当前持久删除服务统一：保存删除事实、停止原轮次、禁止复用原会话；审计身份、历史与产物保留。删除不是原始数据清除，备份也不删除。
- 目标和定时计划仍只接入受保护的OpenClaw/原生Codex。全局底座为API/ACP/OpenCode/旧Codex时，不得通过普通入口绕过目标预算保护。适配器终态只说明协议完成，本机资源收尾不保证远端供应商已停止所有计算或业务质量通过。
