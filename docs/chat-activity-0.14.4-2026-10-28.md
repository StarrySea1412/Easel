# 聊天行为提示精简0.14.4

用户指出138每轮展示的“本轮尚无计划更新回执”“复杂任务应先建立计划”“未开放子Agent，选择启动模型并保存”和“未收到回执不代表后台一定未执行”没有帮助，授权直接修改。该块只是静态配置说明，不会触发计划或启动子Agent。

## 修改后的行为

- 普通问答不显示空计划、未配置协作和重复回执说明。
- 真实计划继续在“工作进度”展示步骤、状态与完成数量，不增加第二份清单。
- 已观察到的子Agent继续显示名称、任务、动作和实际模型身份；配置不冒充调用身份。
- 委派失败或拒绝仍在本轮工具记录展示，并能展开原回执核对原因；观测错误的重新读取按钮保留。
- 不自动开启子Agent，不更改模型、权限或后端执行/计划机制。
