## 排障环境说明（不构成本产品缺陷）

ZCode 内置浏览器（IAB）标签在本机被系统级节流：合成帧 rAF=0、事件循环平均延迟约 800ms、React 状态提交可延迟数秒。最初"点击全部无效"的观察源于该环境；改用页面内脚本 + 充分等待后，全部面板流程在真实 DOM/React 中正常走通。此现象不代表桌面正常浏览器中的交互表现。

## 解决与复核（2026-10-20 09:35 后）

- 用户实例后端已被重新启动（新进程 09:35:36 启动，源码 0.6.1；非本轮排障方发起，属工作区并发交付动作）。`GET /api/browser/sessions/{sid}` 返回完整状态 JSON，不再 404。
- 在用户实例（7880）上复核：
  - 浏览器面板正常打开，显示"从一个网页开始"，整轮操作**零失败请求、零控制台错误**；
  - 通过面板后端管线真实打开 `https://example.com`：job `completed`，返回 `tabId` 与 `snapshotId`，快照标题"Example Domain"、正文可读；UI 面板同步显示"页面快照 · 可点击与滚动"、地址栏为 `example.com` 且渲染出页面快照图像。即：面板 + 内置浏览器全链路可用。
- 遗留与发现：
  1. 本地/内网地址（`localhost`、`127.0.0.1` 等）默认被浏览器服务拒绝（SSRF 防护），需由运行环境以 `EASEL_BROWSER_ALLOWED_ORIGINS=http://127.0.0.1:<端口>` 显式放行；`/control` 接口无法为本地来源放行（其校验逻辑自身先拒绝）。
  2. 小缺陷：对纯 IP 的本地地址（如 `http://127.0.0.1:7880`），拒绝原因被误报为"网页域名无法解析。"。根因在 `easel/browser_runtime.py::_validate_url`：`BrowserError` 继承 `ValueError`（第 30 行），try 内抛出的 403"该来源未获准访问…"被同函数 `except (socket.gaierror, ValueError)` 捕获后包装成另一条消息。`localhost` 分支在 try 之外，消息正确。建议把该 403 判断移出 try 或先捕获 `BrowserError`。
  3. 前端构建仍为 0.6.0 常量（源码 0.6.1），UI 会显示"版本不一致"，重建前端后消除。
- 防复发：面板接口随后端代码新增，**每次后端代码更新后必须重启对应实例**（本机命令：`cd /c/project/Easel && EASEL_PORT=7880 EASEL_DATA_DIR="C:\project\Easel\data" .venv/Scripts/python.exe web/app.py`）。

## "网页无法操作"交互模型复核（当日 10:15 后，百度实例）

用户在百度页面上报"没有办法对网页进行操作"。经事件回放（该会话浏览器事件全部 `completed`）与在实例上按正确协议（每次操作携带当前 `snapshotId`，后端每次操作后自动重新观察）实测，结论为**交互模型限制与站点行为**，非面板故障：

1. **新窗口链接会被静默拦截**：`easel/browser_runtime.py:342-343` 对每个页面注册 `popup` 监听，**弹窗/新标签页一律立即关闭**（设计如此，防止弹窗绕过面板身份与 Agent 控制）。实测：点击百度顶部导航"新闻"（`completed`），主标签页 URL 不变，本页网络日志中**没有任何主框架导航请求**——跳转发生在被关闭的弹窗里，界面表现为"点了没反应"。国内门户大量链接（含百度导航/热搜）使用新窗口。
2. **页面内不能直接键盘输入**：快照是无障碍树+截图，不接受文本键入（仅上下键/翻页键滚动）。输入文字必须走：工具栏"查看页面元素" → 选中 textbox 元素 → 在填写框输入 → "填写"（可选"按Enter"）。实测 `fill`+`press Enter` 全部 `completed`。
3. **百度反爬**：按上述正确路径输入并回车后，百度将自动化浏览器导向"**百度安全验证**"（`tieba.baidu.com/f?fr=wwwt`，空内容），即站点识别并拒绝自动化会话；这是站点行为，换普通浏览器无此问题。
4. **失败后进入"过期"状态**：任何失败的操作（含外站导航超时，如 iana.org 不可达）都会把快照标记过期；此后每个点击都被拒绝（"页面证据已过期，请重新观察后操作。"，HTTP 409），需要先"重新观察"。状态栏同时显示"页面已变化，需重新观察"。
5. 同窗口链接点击本身可用：点击会触发主框架导航并等待加载（超时才报"页面操作未完成"）。

改进建议（未实施，供排期）：点击触发弹窗被拦截时给用户明确回执（当前完全静默）；快照上点中文本类元素时直接引导到"填写"；被 409 拒绝时以提示条显式提示"先重新观察"。
