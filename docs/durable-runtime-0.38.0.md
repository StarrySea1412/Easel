# Easel 0.38.0 候选：独立执行服务

2026-10-27。继续完整竞品对标与大版本迭代。本批让网页进程与执行服务分离，保留紧凑定时页；不部署138、不发布安装器或调用付费模型。

## 行为

`python -m easel web`、源码启动器和直接运行`web/app.py`默认启动轻量网页转发进程。完整后端留在独立执行服务中：聊天、原生Codex、唯一TaskService调度者、问答、停止、生图和文件接口仍使用原实现、原会话与原turnId。不新增模型请求队列或第二套目标调度权威。

关闭或重启网页进程只断开观察连接，执行服务及其原生连接继续存在。重新启动网页先核对私有握手、数据目录、代码/全部构建资源摘要和启动配置；只有匹配的服务才复用。请求流、上传与下载按原字节转发，不跟随重定向，不重试写请求，不将截断SSE伪造为成功终态。

数据目录下的`.execution-service`保存私有实例记录、日志与OS锁。Windows控制目录只授予当前运行身份及SYSTEM，Unix目录0700/身份文件0600；控制凭据不传给Agent子进程。服务只监听127.0.0.1，独立认证后才接收请求。公网/本机页面均不能访问管理路径；原Host、scheme、客户端地址、Origin、登录Cookie、上传及服务器准入限制保留，不能把远程用户伪装成本机CLI。

整个后端生命周期另持有`application.lock`，直接uvicorn启动也不能同时启动第二个调度者。探测超时不等于进程死亡，不会杀掉原服务或另开后端；原服务暂不可达时网页返回503，用户仍应连接原运行。

## 关闭、升级与迁移

在对应的数据目录环境下使用：

```text
python -m easel runtime status
python -m easel runtime stop
```

`status`读取经过私有握手确认的实际PID/实例摘要，不输出认证凭据。`stop`只在空闲时关闭，拒绝在途HTTP、普通聊天、原生任务、目标、生图和未结算任务。停止前原子关闭新调度/生图认领，不能在检查空闲之后又接受一项生图。仅结束网页或按Ctrl+C不再表示后台全部停止。

升级前结束并核对所有在途运行，关闭网页观察者，再执行`runtime stop`。备份完整数据目录，以同一提交安装代码并重建前端，再重新启动。新旧代码或启动配置不一致时拒绝复用，不能只替换dist后继续连接旧后端。`.execution-service`含私有控制资料，备份按凭据保护；不能将活锁/旧PID文件当作新机器上的运行证据。

源码启动器显式`--restart`用于完整重启/待执行内容迁移，需先关闭空闲执行服务；普通网页重启不会应用内容迁移。回退也先关闭执行服务，使用同批代码/静态资源及升级前完整备份；此前画像记忆数据库的回退限制继续适用。本批不改变业务数据库schema。

服务器入口在`EASEL_DURABLE_RUNTIME=1`时使用相同转发层，138 supervisor源码已默认启用：网页子进程退出只重建网页，60秒内连续三次重试后失败退出；Gateway退出仍交由容器重启。显式停止整个容器通过认证管理接口请求执行服务正常关闭。整个容器/主机/执行服务退出会失去进程内原生连接，这与单独重启网页不同。服务器源码尚未在138部署或进行Linux容器实测。

直接`uvicorn web.app:app`或显式`EASEL_DURABLE_RUNTIME=0`保留进程内兼容模式，仍受数据目录执行锁约束。原生连接在执行服务自身死亡后能否恢复，继续依赖具体引擎的精确协议；未知运行不重发提示词，不据进程替换宣称已经完成或质量通过。
