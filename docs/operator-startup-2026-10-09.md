# 启动与交接

Windows 10/11 x64：完整解压便携ZIP到可写短目录，例如 C:\Easel。双击 Easel.exe，等待就绪后打开控制窗口显示的地址。窗口不可用时双击“启动 Easel.cmd”；使用“检查 Easel.cmd”查看状态、“停止 Easel.cmd”停止本副本。

请配置自己的模型与平台账号。不要共享 data；备份/搬迁前先停止本副本。包内没有开发者密钥或登录态。工作台可离线打开，在线模型、生成与平台功能需要联网。可选工具/模型权重可能另需安装或下载。

没有管理员登录系统，无管理员测试账号。
