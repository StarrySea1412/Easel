# 工作台入口、技能检索与消耗明细精修（2026-10-16）

本轮接续用户三次截图反馈：技能选择框缺少 ClawHub 搜索、首页生图入口过小且与内容卡片割裂、消耗明细层级粗糙。仅更新本机 7880；138、安装器及便携包均未更新。

## 实现

| 入口 | 调整 | 数据与行为边界 |
| --- | --- | --- |
| 工作台 → 最近产物 | 生图工坊入口整合进卡片，增加整行点击区域、图标、标题、说明、箭头及焦点状态 | 仍进入 `image` 页面，不发起生成 |
| 输入框 → 技能 | 区分“本机已安装 / ClawHub”；公开检索、作者/slug、摘要、版本、时间、详情与官方页面 | 不安装、不执行、不把外部同名技能当作已选本机技能；关闭/切换来源取消请求，详情 Escape 返回结果 |
| 对话 → 上下文容量 → 消耗与费用明细 | 无记录显示专用空态，可转有记录的项目汇总；有记录显示覆盖度、总览/请求明细切换；缓存、费用估算、速度和统计口径分层 | 未上报保持未知；记录费用返回 0 明确提示不代表免费；渠道估算不代表账单，累计消耗与上下文占用分别统计 |

ClawHub 在 650px 以下改为全宽列表，点开后单独阅读详情。用量弹窗复用共享主题变量，增加两列窄屏指标和筛选布局；范围与内容切换支持方向键、Home、End。保留原刷新、分页、请求与轮次明细、渠道区分、计价编辑和流式读取。

消耗弹窗原先依赖 `ActivityPage` 才会加载的趋势/请求样式，首次从聊天打开会出现原生三角和散乱标题。本轮将必要样式放回用量组件自身，使入口加载顺序不再决定展示是否完整。界面不再显示设计参考代码库链接；此前参考归属仍保留于[信息架构记录](final-iteration-2026-09-30.md)和[成本/速度记录](ccswitch-cost-speed-2026-10-09.md)。

没有发送聊天、重试生成、启动 Agent 或调用付费模型；ClawHub 作者说明作为外部不可信文本展示，没有执行其中命令。本机标准启动器曾因网关冷启动未就绪退出，使用相同项目、data 和隔离网关配置重新启动后，7880 与网关已恢复；没有修改138。工作台未新增认证系统。
