# 页面加载、历史存储与运行记录优化（2026-09-30）

本轮在已验收的 0.2.6 之后继续优化源码，预览地址为 `http://127.0.0.1:7863/`。现有 0.2.6 EXE / ZIP 保留原样，未重新打包；本页新增结果不能写成已进入这些安装包。

## 改动

- 工作台首页保留同步加载，其余 14 个页面按需加载。页面有加载提示和局部错误边界；重试重新创建 React.lazy 对象以摆脱已缓存的拒绝 Promise。聊天流与生图控制器仍留在 App。
- 页面重试不自动刷新整个工作台。若旧页面代码在部署后永久不可用，重试同一资源地址仍可能失败；用户可以从侧栏打开其他页面。未实现旧资源长期保留或自动热迁移。
- 移除 store 导入时根据历史重置标记删除会话的逻辑；兼容旧存储键并逐项规范消息字段，不因一条坏记录隐藏全部有效历史。
- 迁移必须写入新键成功后才清理旧键；当前键损坏而旧键可读时，只恢复到内存，不覆盖或删除任一原值。初始读失败也不会被当作“空历史”。
- 保存失败不再中断 React 更新，当前会话/发布草稿留在内存；顶部显示未保存状态，可重试每个键的最新失败写入。其他键保存成功不会掩盖会话保存失败。原始数据保护状态下重试不会强行覆盖。
- 不再静默截断超过 100 条的真实会话；仍合并多余空占位会话，进行中的轮次保留。
- 运行记录列表和详情共享筛选结果。无匹配显示空态，清除筛选可恢复用户首选；外部精确轮次跳转重置旧筛选，目标会话不可用时明确说明。
