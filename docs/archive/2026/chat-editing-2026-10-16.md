# 历史消息重新编辑（2026-10-16）

本轮按用户截图增加历史用户消息的原位编辑。刷新本机 `http://127.0.0.1:7880/`，进入对话，在已发送消息下点击“编辑”，修改后选择“取消”或“发送”。桌面悬停或键盘聚焦显示操作；触屏直接显示。

## 发送后的行为

- “取消”恢复原消息，Escape 同样取消并返回编辑按钮焦点；Enter 发送，Shift + Enter 换行，中文输入法候选确认不会误发。附件准备中仍可取消，切换会话/页面会中止待处理的前端请求。
- “发送”创建独立编辑分支，原会话和其后全部回答继续保留。新分支仅显示编辑位置之前的消息与修改后的请求；顶部“查看原对话”可返回。原会话已删除时明确提示，当前分支仍可使用。
- 底层 OpenClaw 和 Codex 会话以追加为主，本轮不改写原生历史。新运行首次接收此前可见用户/助手文字的 JSON 快照与本次修改消息。快照按普通用户上下文处理，不转成系统权限，不重放历史工具操作，不复制隐藏思考、原生运行标识、原任务状态或 Codex 工作目录。之后正常轮次继续使用新运行上下文；初始失败重试仍保留快照。
- 已上传的结构化附件复制到新会话的独立归属目录并重新生成引用，包含此前轮次与被修改消息的附件；原文件不变。文件缺失、跨会话引用、复制失败均阻止发送。只有旧版隐藏附件路径、没有结构化引用的历史会提示重新上传，不冒充已迁移。
- 每条被修改消息保留其已选择技能、技能补充要求、指定模型和思考档位。保留原会话草稿与队列；有待发队列时先要求处理队列。生成、停止处理或待恢复期间禁用编辑；重复提交与会话变化受保护。
- 历史快照最多 200 条 / 200000 字；附件最多 200 个、合计 500 MB。超过限制明确报错，不静默裁剪。浏览器无法保存分支时不发送模型请求。仅准备附件的接口不调用模型；取消后已复制的附件可能留在本地，但不会创建或重放运行任务。
