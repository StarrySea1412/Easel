## 首版交付（历史，摘要布局由上述修正覆盖）

聊天中的 OpenClaw 和 Codex 使用同一套操作卡，区分终端、阅读、文件变化、搜索、浏览器与未知工具。标题使用可读动作摘要，完整命令在详情内换行显示；文件 diff 和工具输出同时保留，命令、输出、差异分别复制。

- 终端详情显示引擎实际提供的工作目录、退出码、信号、后台进程会话及耗时。执行中可暂停或恢复输出跟随；后台工具返回不会直接判定进程完成，后续 process 回执关联原命令。
- 文件卡显示写入/新增/修改/删除、路径、真实差异及增删统计；没有差异回执时保留实际输出。成功回执中的 outputs 路径或工作目录内相对路径，经目录边界检查及实际存在/非空核验后才提供内容库入口。输出目录根部的真实文件也可在内容库打开。
- 服务返回的思考摘要、Agent 工作进度、结构化计划与最终文本分别展示。等待响应和连接心跳只说明已知连接状态，不能当作思考或任务仍在推进的证据。
- 状态区分执行中、工具已返回、执行已结束、失败、结果未确认、已停止和已拒绝；缺失字段不补写。
- 默认最近三项，同时保留运行中/失败项；支持全部、终端、文件、网页筛选，以及读取较早操作记录。HTTP 快照默认40项，上限100项；实时事件最多携带最新100项。

## 事件及恢复

OpenClaw Gateway 的 tool start/update/result/end 事件先归一化并写入当前数据目录 `outputs/_execution/`，再通过现有聊天 SSE 发送。运行、会话、轮次和工具 ID 限定事件归属，去重及迟到部分结果不能复活已结束操作。CLI/HTTP 路径缺少实时 tool 来源时仍可读取会话回执，并标注其来源。

Codex 保留 App Server 接入方式；从命令输出增量、文件变化、reasoning summary、计划及 agentMessage 的 commentary/final_answer 生成同一执行视图。持久 SSE ID 用于断线后继续读取原任务，避免重复 POST。已有未提交的接入、计时与自适应最高实现已保留并整合进当前源码；原工作区保持原样。

共享前端收到本轮执行事件立即更新，并用3秒快照轮询兜底。会话切换中止旧请求，早于实时事件的 HTTP 回应不覆盖新回执，已展开详情保持。终态保存/发送后结束；恢复历史时没有活跃本地任务的运行中记录显示未确认。Codex 服务重启保留已完成证据，将未结束项和轮次标为未确认，不自动重发模型请求。

输出及 diff 各最多保留64,000字符、命令16,000字符；截断明确标注。分页加载的是操作记录，不能找回已经截掉的日志后缀。已知凭据脱敏，配置/凭据文件的工具输出及差异隐藏。去重序号集合有界；整轮操作快照和 JSONL 的总量/保留策略仍需优化。
