# 本地角色建模、手部与神态优化

更新：2026-10-02（Asia/Shanghai）。功能位于 `codex/creator-workflow`。

## 实现范围

参考 [pasie15/meshy-ai-mcp-server](https://github.com/pasie15/meshy-ai-mcp-server) 将几何、材质和绑定分阶段处理的思路，在已有 Three.js 程序化模型上直接优化；本轮没有调用 Meshy、下载生成模型或消耗生成额度，也不提供任意文字生成 3D 模型的能力。

- 身体：将肩胸腰腹轮廓接入实际可见的连续蒙皮；猫、兔、狐狸、熊分别设置体型、脸型与眼鼻比例，增加头颈连接。
- 耳尾：四物种使用有厚度和内凹的耳壳；狐狸尾巴采用连续曲面与尾尖颜色过渡。
- 手部：纠正左右拇指朝向，以指垫、握柄及笔尖定位接触；修正肘部过高和手腕横折，持纸手掌随纸面旋转。笔座移出前臂工作区域。
- 动作：身体正对工位，视线跟随屏幕、纸面或笔尖；键鼠、阅读、书写与画板操作保持各自节奏和停顿，保留取放道具及暂停/恢复。
- 神态：六类表情覆盖中性、专注、思考、等待、完成与错误，通过眼睛开合、眉形和嘴部曲线表达。未知状态不虚构专注或完成；终态不随时间继续工作。
- 兼容：保留现有角色卡、换色、配饰和动作骨架。外观与表情仅是展示，不改变真实 Agent 的指令、权限或执行状态。
