# 共享浏览器运行时：实现与验收

日期：2026-10-19。接续[新增面板与浏览器调研](../../panel-home-browser-research-2026-10-19.md)的四步路线。本轮实现导航与会话身份、页面观察、Agent工具闭环和视觉附件链路；真实模型分析质量单独保留待验。

## 使用方式与实际能力

对话 → 新增面板 → 浏览器，默认进入“交互浏览”；“正文读取”保留上一轮链接提取功能。交互浏览实际启动隔离 Chromium，而不是嵌入目标站点的 iframe。界面展示当前视口截图，每次操作后重新观察；它是按操作更新的截图界面，并非视频流或完整远程桌面。

- 每个对话独立浏览器 context、网页标签及站点控制许可。支持新建/关闭标签、地址导航、后退/前进/刷新、滚动和显式重新观察。关闭工具面板、切页或刷新前端不会重放网页操作；后端重启只恢复断开的标签元数据，由用户显式重开。
- 页面、正文、元素、日志四个视图共用 tabId、snapshotId、递增版本、来源地址和观察时间。保留最近三张截图；元素引用绑定实际 DOM 节点，过期快照、断开节点或名称变化会拒绝动作。截图与文本收集时还核对文档身份，避免同 URL 重新加载造成错配。
- 可在截图上用鼠标点击，或从元素列表点击、填写和按键。键盘激活截图会进入元素列表，避免误点页面左上角。坐标点击触发导航时等待新文档，不重复点击。
- “分析此页”“带截图分析”“引用页面选区”“引用元素”显式加入当前主草稿，保留已有文字、引用及附件。选区可在正文视图真实拖选。按钮不自动发送，也不自动调用模型。
- Agent读取与操作同一浏览器；点击/填写/按键前须由用户在面板开启当前站点控制。Agent工具没有授权开关。密码、验证码和卡号输入按敏感字段拒绝工具填写；当前没有用户账号配置的导入和完整人工登录交接界面。

正文最多24000字、元素最多120个、截图1280×800、日志最近40条；带入草稿的全文引用最多12000字。元素列表为顶层文档交互元素摘要，未实现完整可访问性树、CSS检查器、跨 iframe 元素操作或 HAR 导出；截图包含可见 iframe。日志是有界的控制台/异常/响应摘要。

## 工具与视觉链路

`easel/browser_runtime.py`将Playwright放在专用线程及事件循环，UI与工具通过同一个服务访问。网页操作具有固定requestId、去重指纹、进行中/完成/失败/取消回执及事件；失败或中断后快照标为过期，必须重新观察。取消不撤销已经发生的站点动作。

新Codex线程在`thread/start`注册`easel_browser`动态工具，宿主固定绑定当前会话。`state`列举标签和事件，`observe`返回正文/DOM/日志摘要，`image`通过`inputImage`返回当前实际截图；操作返回新的页面观察。停止或结束轮次时取消未完成的Agent浏览器操作。

已有Codex线程的`thread/resume`不接受新增dynamicTools；它与OpenClaw复用现有exec能力调用`skills/shared/scripts/browser_page.py`。脚本通过本机HTTP桥接到同一个服务，不另开浏览器。支持`--args-json`或UTF-8 `--args-file`，修改操作必须提供固定requestId；CLI截图保存为当前会话附件，并返回实际imagePath供现有图片/read工具读取。旧线程CLI发起的操作也在Codex停止/轮次结束时结算；OpenClaw显式停止及supervisor收尾会取消Agent操作，不取消用户手动操作。

截图沿用现有上传归属：`outputs/_inbox/<session-scope>/browser-<batch>/…png`，发送时再校验附件标识和会话。Codex将图片复制进其工作目录并通过`localImage`输入；OpenClaw提供当前附件清单和图片读取指引，仍依赖实际渠道/模型及现有image/read工具支持，不声称所有模型自动具有视觉能力。

协议依据为实际打开的[OpenAI官方App Server文档](https://learn.chatgpt.com/docs/app-server)及本机Codex CLI 0.147.0生成的实验协议schema：新线程动态工具、工具调用回执的inputText/inputImage、localImage输入及resume参数。schema生成和假App Server回归没有调用模型。第三方对照来源继续见前一轮调研，未把本地ZCode组件名推断为服务端能力。

## HTTP与运行环境

| 接口 | 用途 |
| --- | --- |
| `GET /api/browser/sessions/{sid}` | 读状态，不导航或重新截图；空状态不占用浏览器会话名额 |
| `POST …/commands` | 用户面板操作 |
| `POST …/agent/tool`、`POST …/agent/commands` | Agent操作，受站点控制许可限制 |
| `POST …/commands/{requestId}/cancel` | 中断指定操作 |
| `POST …/control` | 用户开启/关闭站点控制 |
| `GET …/tabs/{tabId}/snapshots/{snapshotId}/image` | 读取指定版本PNG |
| `POST …/tabs/{tabId}/snapshots/{snapshotId}/attachment` | 保存为本会话附件 |
| `DELETE /api/browser/sessions/{sid}` | 取消任务并关闭浏览器context |

沿用项目Playwright依赖，优先本机已安装Chromium，缺失时尝试Edge/Chrome；不在请求过程中自动下载组件。最多8个浏览器会话、每会话6个活动标签；闲置30分钟的会话在申请新会话时回收，关闭标签的重连历史有界。页面快照和cookie保留在内存，重启只保存标签元数据及有界事件摘要至`outputs/_browser`，该目录禁止普通文件接口访问。

默认允许公网HTTP(S)，拒绝URL用户名密码、file协议及解析为本地/内网地址的目标；Chromium Fetch对HTTP请求和每一跳重定向在发送前校验。`EASEL_BROWSER_ALLOWED_ORIGINS`为运行环境指定的精确例外来源（逗号分隔，含端口），本地预览需显式配置，例如`http://127.0.0.1:5173`。这是应用层DNS/URL校验，不是完整网络沙箱或DNS重绑定防护。弹窗关闭、下载取消、对话框取消，未加入下载管理器或任意页面脚本执行入口。

CLI默认使用`EASEL_PORT`（未设时7860），`EASEL_BROWSER_URL`可指定本机HTTP地址及前缀；拒绝将桥接请求发送到远端服务。常规`easel web --port`会设置EASEL_PORT；自行启动uvicorn时应设置对应值。
