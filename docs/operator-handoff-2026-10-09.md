# Easel 运营交接手册

更新：2026-10-10。适用源码分支 `codex/upstream-compat-2026-10-10`。开发机入口为 http://127.0.0.1:7880/；其他电脑使用其启动入口显示的地址。旧0.2.6安装器及76bbaf6便携候选不包含本轮全部功能，不能按这份手册认作最新版。当前没有管理员登录系统，无管理员测试账号入口。

## 启动、停止与备份

便携版完整解压到短、可写目录，例如 `C:\Easel`。双击 `Easel.exe`，等待就绪再打开其显示的地址；图形入口不可用时运行 `启动 Easel.cmd`。`检查 Easel.cmd`检查本副本，`停止 Easel.cmd`停止本副本；关闭浏览器或启动窗口不等于服务已停。原生双击和干净Windows仍需对最新版单独验收。

源码安装/运行遵循项目README和启动器，不能用系统Python代替已经配置依赖的项目运行环境。当前7880由项目 `.venv` 运行，网关与Web是不同进程；不要结束全部Python/Node来重启。Web更新前等对话、媒体、安装和发布任务结束，只停止已核身份的本副本。没有就绪回执时查看日志，而不是重复启动。

备份或搬迁前先停本副本，再复制完整目录及 `data`。源码开发环境的数据在配置指定的位置，不能直接套用便携目录约定。会话备份不包含全部未发送草稿/浏览器文件对象；先手工保留重要草稿和素材。发布前再次确认附件真实存在。平台登录态、Key、个人作品与运行日志不交给其他运营人员，也不纳入干净发行包。

## 模型与渠道

1. 设置→模型配置，展开对应通道。每项默认折叠，按需编辑。对话使用“保存并使用”，其他通道使用其“保存配置”。
2. CC Switch导入先看候选并确认。**渠道名称是导入渠道的可编辑显示名**，OpenAI/Anthropic是协议，两者不能混为一谈；修改名称不改Key/地址/协议。未知名称不补造厂商。
3. 模型名称前的有色状态图标表示读取渠道模型列表的结果：连通、读取中、失败或未知。点击查看原因并重试；读取列表成功不等于这个模型真实推理成功。
4. 模型ID可手工填入合法值；自动读取失败不会把已保存Key掩码写回为真Key。真正更换服务地址时需要匹配凭据。
5. 思考强度按网关声明开放，灰色斜纹表示不可选，小info解释声明来源。这是能力声明，不是本轮实测。Ultra才有紫色粒子，减少动态偏好会停动画。供应商拒绝时查看实际错误，不重复盲试最高档。
6. 图片/视频/转写/配音等通道分别配置；图片服务不借用聊天Key。视觉模型名本身不证明具备图片理解。生成前核对服务价格和实际模型。

渠道名编辑已实现。运行时声明与实际运行分开显示；没有发起调用就不能记作推理通过。

## 对话、队列、引用和置顶

首次打开/刷新工具栏与会话列都收起。点击已有对话应同时打开主对话页；不是只改变侧栏选中态。切页保持会话列收起，可主动展开。

会话item悬停/键盘焦点可看标题、时间及技能，使用置顶操作固定到置顶分组，再次操作取消。预览中的已选技能与实际执行证据分开。更多菜单、hover预览和置顶按钮不能互相遮挡。

输入框Enter发送，Shift+Enter换行。运行中提交的新消息进入当前会话队列；队列在主输入框外侧上方、左右内收。拖最左抓手时整条消息随指针移动，原位占位，释放后保存顺序。编辑复用主输入框，保存/取消后再继续；删除、引导和更多同排，更多一次只开一个菜单，Esc或外部点击关闭。

空闲或暂停时，引导直接发送所选消息；运行中先等待停止确认再发，成功后剩余队列继续按原顺序发送。主动暂停、发送失败、仍在编辑或缺素材才阻止自动继续。看Toast/错误原因；失败会保留消息，不静默删除。“继续排队”不是绕过素材缺失或编辑确认。刷新恢复文件名称后仍需重新附上真实文件。

选中对话正文后点击“引用”，或使用 Ctrl+Shift+Q，引用进入输入框上方。展开看原文，在主输入框写评论，移除独立引用。加入引用不自动发送。引用旁info仅悬停/焦点显示，离开隐藏，Esc关闭；显示说明时收起展开引用，避免重叠。引用按会话隔离、刷新保留。

左侧轮次刻度只有一组；hover/focus看同轮问题与回复，点击/Enter定位，Esc收起预览。回最新位置按钮空闲直接向下箭头，运行中三点loading，hover/focus变箭头，点击到底部。

“＋”提供已实现的媒体、文件、文件夹素材与技能入口；文件夹会展开为支持素材，不保留目录层级。图片缩略图可放大，文件显示名称与格式。已选技能有类型icon，点击查看详情、独立移除；图标表示能力分类，不代表执行成功。

## 主动提问、工具证据、tokens与成本

Agent可以调用提问工具显示选择卡片。选择答案并提交后续跑；卡片等待期间不替用户选择。真实DeepSeek链路已通过并刷新保留，但模型是否每次主动提问取决于其判断和工具调用，不能承诺每个疑问都弹卡。

工具执行与活动摘要可以展开，读SKILL只证明读了说明；执行成功以工具回执和产物为准。消息hover中的技能/Skill核验不能把助手正文提到的技能算成已调用。

思考用量优先显示真实reasoning tokens，缺失时标“≈”估算，不能称为服务商计费量。运行记录查看同会话同轮模型、渠道、速度与费用来源；未知量不是0，网关报告费用0不证明免费。渠道四项价格与倍率使用实际报价，历史记录保留当时来源快照。详细口径见 [成本速度说明](ccswitch-cost-speed-2026-10-09.md)。

## 生图、技能与办公室

生图/视频输入区有明确底色与聚焦边框；比例选择前的小矩形表示实际宽高。选择媒体后核对缩略图和文件，未授权或未配置服务时不发起收费生成。生成失败显示实际原因，排队不等于出图。

技能说明可用滚轮查看，390px已实测到末尾且卡片不横溢。能力与配置状态同排，空间不够再换行。环境安装info解释用途、影响与范围，任务显示真实阶段/输出/耗时/终态；失败看原因再重试，不重复启动并行安装。

办公室按同会话关联运行记录。工作、茶水、休闲、健身、卫生间可近看，员工近看和全景复位保留。漫游开关是**独立模拟角色**，不改变真实员工任务；暂停、失焦/隐藏、过期或减少动态时停推进，关闭移除。不把模拟走动说成真实员工执行。

## 热榜与内容分析

知乎热榜优先实际来源，失败保留具体来源错误、时间和旧缓存，不造榜单；可手动重试。公网源可能限制访问，解析用例通过不等于持续可达。旧缓存应看其时间，不能当今天实时榜。

内容分析先核账号和作品稳定ID，再看材料完整度。当前真实小红书材料包含标题，缺正文与基础指标时不能做效果归因。跨作品解读保留事实引用与数字校验；截断、空正文、JSON解析与事实拒绝分别报错，并提供重新生成，不覆盖已有有效结果。此次实际截断已增加输出预算并成功保存五条标题观察。新采集时间产生材料版本变化时旧解读可能失效，保存行仍在，不等于丢失。

## 多平台发布与回执

1. 发布中心填写通用标题/正文和媒体，勾选目标平台，可按平台分别调整。每个平台单独展示字数限制、登录和准备状态。
2. 多选时预览tabs切换对应平台，一次只显示一个预览；不代表只发当前tab。提交面向全部勾选平台，分别生成结果，可能有成功、失败或审核中并存。公众号是保存草稿，不冒充公开。
3. 先预检，再核对账号、内容与目标平台确认提交。发布/核实时按钮和状态有loading；不要因为等待就重复提交。
4. 回执从发布页“查看全部发布回执”打开，不常驻全站顶部。切页/刷新后仍可查记录；公开结果、候选预览、平台管理和邮件分别显示。
5. “核实发布结果”只查询；自动核实有限次、可暂停/恢复，不负责再次投稿。候选预览不等于已确认公开，平台可能要求App；人工核实单独记录，不改自动匹配事实。
6. 内容日历“待发”是排期记录，尚无独立定时首次发布执行器。没有自动加邮件或定时任务；SMTP只有按实际配置收件验证后才算通过。

本次唯一授权发布《Agent到底怎么帮你干活？》523字、4图，用户已在App确认公开且内容正确。Web预览提示需在App查看，自动回执仍“结果待核实”；不再次发布。此项是用户App验收通过，不是自动读回通过。

## 常见问题处理

| 现象 | 检查与处理 |
| --- | --- |
| 切设置/对话仍停旧页面 | 查看是否发生旧模块加载错误；预览构建保留旧哈希。先保留草稿，必要时刷新；记录页面与时间 |
| 点击没反应 | 看loading、Toast、按钮不可选说明和任务状态；不要反复创建重复任务 |
| 引导未继续/队列暂停 | 看停止确认、发送错误、编辑中或缺素材；先补齐阻止条件再继续 |
| 模型显示连通但发送失败 | 连通只代表列表读取；核对档位、地址/凭据及真实错误，网络连接被关闭不等于免费重试 |
| 账号/发布查询很久 | 等当前任务终态，检查平台风险提示与管理入口；验证码/扫码由本人处理 |
| 有预览但回执待核实 | 按标题在平台/App核对；可能审核或网页限制，保留候选，禁止盲目再发 |
| 解读“未保存” | 展开具体截断/空响应/格式/事实校验原因；材料不足先补材料，不能关校验造结论 |
| 知乎热榜失败 | 看来源错误、缓存时间并重试；缓存不标实时；记录错误给开发排查 |
| 依赖安装失败 | 查看阶段、输出和终态，修正原因后重试；不执行任意复制来的安装命令 |
| 首启/停止失败 | 检查本副本日志与端口/进程归属；不要结束不相关Python/Node |
