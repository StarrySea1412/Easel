## 1. 启动、停止与版本

1. 从当前源码目录使用项目启动器，不要混用旧便携目录和源码数据目录。
2. 等待窗口报告 Web 就绪，再打开它显示的本地 URL。端口被占用时使用实际输出，不能假定固定端口。
3. 首次欢迎页可选“先用通用模式”。未配置模型时仍可浏览、选技能、维护本地选题和日历，但不代表 AI 生成已可用。
4. 停止使用控制窗口的停止入口或项目停止命令；只关闭浏览器标签页不等于服务停止。备份或搬迁前先停止。
5. 验收前核对源码 SHA 和构建时间。旧 `76bbaf6-3fb7` 包和公开 `0.2.6` 不包含本次代码，不作为新功能验收依据。最终 ZIP 的完整解压、首启、搬迁、停止/重启、安装与恢复逻辑由 R43 独立审查。

## 2. 模型、CC Switch 与测活

1. 打开“设置 → 模型配置 → 添加供应商”，填写供应商名称、协议、Base URL、模型 ID 和自己的 API Key，保存并核对主备顺序。不要将配置文件、登录态或含密钥截图提交到 Git。
2. 若使用 CC Switch，打开“设置 → 配置导入”，选择 CC Switch / OpenClaw 来源，预览条目后选择导入目标通道并确认。自动发现失败时指定配置文件或目录；协议不支持或模型不可识别时保留原配置，按错误原因处理。
3. 导入后回到模型配置核对实际模型 ID、协议与主备顺序，再打开“模型测活”。配置已读与接口可达分别记录。
4. 在“文本测试提示词”填写短而可判定的请求，选择模型并点击“测试文本”。“测试图片识别”使用后台生成的四格图检验颜色、位置和排列顺序；成功只证明这次请求通过，不保证所有图片任务或未来调用。
5. 自动文本测活默认关闭。需要时勾选启用，选择每 15 分钟、每 30 分钟或每小时并点击“保存自动测活”。限额为滚动 60 秒最多 2 次、每渠道最多 2 个自动模型，多标签和重复点击也受限。状态过期只表示结果超出时效。
6. 对话输入框选择当前渠道/模型。状态区分未测、测试中、最近成功、失败与过期；不要把“已选模型”写成“模型已可用”。
7. 输入框的思考强度有关闭、极简、低、中、高、极高、自适应、最大与 Ultra，缺省中。选择随本次请求发送、浏览器偏好可恢复；真实模型是否遵守该强度需独立验证。

## 3. 小红书登录与扫码

1. 打开“账号中心 → 小红书”，发起登录并扫描当前二维码。
2. 在手机端按平台要求完成确认、短信或风险验证；等页面登录状态更新后再采集。
3. 平台明确 IP/安全风险时按平台提示处理；普通网络失败、二维码过期和本地检测失败分别记录，不自动换代理或绕过风控。
4. 关闭弹窗后旧轮询不应重新打开提示；需要重试时重新点击登录。
5. “二维码可见”“登录状态更新”和“采集拿到稳定账号 ID”是三个状态。本次代码/界面回归不代表真实扫码成功，也不代表后台采集已验证。

## 4. 账号分析与题材实验

1. 进入“内容分析 → 我的数据”，选择平台和记录所属账号。没有记录时先读“我能分析作品的什么问题”，按卡片准备标题、正文/逐字稿、封面文字、评论及指标快照，再录入或导入。
2. 能力矩阵解释标题承诺、正文结构、封面文字、读者追问、曝光衔接、观看质量、互动与归因关注。缺少材料显示缺口，不填演示统计；没有实际图像/音视频/留存曲线时不评价配色、镜头或具体流失位置。
3. 核对平台名、账号、来源、样本数和最近观察时间。切换后旧报告先清空，新响应必须同时匹配平台和账号；晚到请求、旧保存回调和旧文件读取不会进入新上下文。没有同步变化时刷新记录并记录实际 URL。
4. 读官方资料卡的 URL 和核对日期。七个平台的公开资料不提供可复现的推荐权重、推流阈值或流量保证。平台事实、账号假设与编辑建议分别阅读。
5. 指标保留原生定义、单位和窗口。缺失与 0 分开；缺曝光分母不计算点击率；缺完播/平均观看秒数/视频长度不判断观看质量；账号净增粉不归因到单篇；每日人数合计不当区间独立人数；跨平台不合计播放或互动。
6. 比较仅限同平台、账号、形式、窗口、投放状态和同整日作品年龄。查看排除原因与比较组；实际入库样本不是账号全部历史。
7. 在“先看结论”或“找内容方向”核对题材卡：引用样本 N/总 N、比较条件、窗口、同条件对照作品、缺失、指标公式、引用作品、单变量行动、7 天回收日期和停止规则。题材只来自真实标签或实际评论问题，相关模式仍可能由流量、投放或样本选择造成。
8. “保存题材与证据”固化当前 scope、题材对象和引用到选题库，后续采集不会改写旧版本。“预填 7 天实验”固定原生主指标和引用作品；保存前服务端按题材 ID 重核验，跨 scope 或过期题材拒绝。
9. 实验结束前导入新的真实同口径观测，再填写结论与反例。样本不足、窗口不齐、缺分母或投放条件改变时按停止规则停止效果判断，保留编辑复盘。

## 5. 对话刻度与发布回执

对话右侧刻度的长标记指示当前轮。悬停或 Tab 聚焦查看原请求预览；方向键、Home/End 在刻度间漫游，Enter/点击定位；Escape 收起预览。“轮次目录”仍提供上一轮、下一轮和跟随最新。在会话列表点击“重命名”，再点“Agent 命名建议”：将调用已配置的缺省文本模型，可能产生费用。建议只填入标题草稿，按 Enter 或“保存标题”才采用；手工编辑、取消或切换后迟到建议不会覆盖原标题。失败后可手工命名，不自动重试。

发布先执行预检，再由用户确认。回执记录平台结果、任务状态、可信作品链接与通知状态；排队、提交审核或按钮点击不等于公开成功。平台未提供可信公开 URL 时显示缺失，不猜测地址。SMTP 只有用户实际收到邮件后才能报告送达。本次没有真实发帖、模型推理或外部发信验收。

## 6. 故障与日常验收

| 现象 | 先做什么 | 记录什么 |
| --- | --- | --- |
| 显示旧平台/账号 | 核对平台、账号和来源，刷新当前记录 | URL、scope、响应来源与样本 |
| 专业字段升级提示 | 保留原作品功能，更新服务后重新读取 | 当前源码 SHA、是否返回 professional |
| 题材保存被拒绝 | 重新读取报告，核对引用仍属于当前账号 | 题材 ID、错误原文、scope |
| 模型测活失败 | 核对协议、Base URL、ID、Key 后单次测试 | 文本/图片模式、时间、状态，避免泄露密钥 |
| 二维码失效/风控 | 重新发起登录，按平台验证 | 二维码/网络/平台明确风险分类 |
| 发布没有公开链接 | 保留回执、等待可信结果或手动核实 | 平台状态、核实时间、地址是否真实可打开 |
| 包启动或搬迁失败 | 停止副本，检查启动日志和完整目录 | 包名、SHA、目录、是否全新 Windows |

每次日常验收逐项记录菜单、跳转、作品入口、导出、键盘与 390px 布局；未实际操作不能标通过。回执字段包括日期、源码 SHA、启动器 URL、scope、数据来源、返回样本、缺失、窗口，以及是否真实账号/模型/发布/SMTP。代码、模拟回归、HTTP 可达、真实浏览器和真实业务结果分别记录。

本次 Git 最终 SHA 和新源码实际入口由主任务完成构建、启动与推送后补充；源码推送不代表新安装器发布。
