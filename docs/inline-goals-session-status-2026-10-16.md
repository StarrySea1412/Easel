# 输入区目标模式与对话状态

日期：2026-10-16。对应用户要求“目标设立门槛太高，不需要额外 modal；对话列表显示多少个在跑，并支持完成或失败 Badge”。

## 使用

- 在当前对话点击“目标”，或输入 `/goal 要完成的事`、`/目标 要完成的事`，直接进入原输入框位置的目标模式。没有遮罩、弹窗或焦点锁定；只需描述目标并点击“开始目标”。
- 默认沿用当前模型，显示实际模型标识；高级执行选项默认折叠，初始为5轮、20分钟、40次工具、0张生图。模型不可核验或所选模型不可用时显示具体错误，可刷新/主动更换；不会静默回退到其他模型。
- Enter 开始、Shift+Enter 换行、Escape 或右上角退出返回普通输入；中文输入法组合期间 Enter 不启动。普通草稿、附件和待发送队列留在原存储。修改已有目标同样在输入区进行；已有累计限额不重置。
- 保存成功但启动失败时保留错误和“重试启动”，复用已保存的目标ID；后台同步“目标已建立”消息不会卸载编辑器或重复创建目标。运行中查看目标会打开原进度面板，暂停与停止入口保留。

## 列表状态口径

列表顶部显示“X个运行中”，折叠时“对话”图标保留数量角标。普通流、活动目标及其运行按会话ID去重；停止等待确认仍计入，已归档活动会话也计入。排队和后台待核实不计入正在运行。零运行时隐藏图标角标，展开列表显示0。

| 标记 | 来源及含义 |
| --- | --- |
| 运行中 / 停止中 | 当前流、活动目标/任务运行，或停止确认尚未结束 |
| 已完成 | 普通会话最近一轮有结束回执，或目标已经完成并验收；不代表普通回答质量已验收 |
| 失败 | 最近一轮持久错误，或对应目标运行明确失败；悬浮可见原因 |
| 已停止 / 已暂停 | 显式停止回执、取消或暂停状态 |
| 待输入 / 待验收 / 需处理 | 目标已停在相应阶段；单轮工具完成不会冒充整个目标完成 |
| 待核实 / 排队中 | 恢复中的pending轮次，或服务端未确认/排队状态 |

标记随新轮次更新，刷新后由消息回执与目标快照恢复。旧无回执正文、后台注入说明和导入备份不推测为完成；新用户消息也不会继承上一轮的完成标记。既有重命名、F2、置顶与菜单保留，标题与标记采用两行避免争抢操作空间。
