# 社媒发布回执与提醒（2026-10-09，R25/R27）

用户要求：内容发布到小红书、B站等平台后，自动提醒并附作品链接。Web 发布页保留持久回执、跨页提醒和可选邮件；R27 增加小红书／视频号结果读取和五平台审核后核实。上传结束、提交审核和公众号草稿分别显示，只有明确公开的作品才触发成功提醒。不同平台能提供的凭据不同，真实平台发布和邮件送达仍待用户验收。

## 如何使用与验收

1. 在「发布中心」准备内容并确认发布。工作台顶部「发布回执」会保留处理进度；需要短信验证的任务可从该入口继续处理。
2. 平台确认公开后，回执显示「已发布」及平台提供或由已验证作品 ID 生成的公开链接。切页或刷新后仍可查看；没有可信地址时会明确提示，不生成猜测链接。
3. 「已提交」「草稿」「待核实」「失败」分别展示。已提交不等于审核通过；待核实应先到平台确认，避免重复发帖。只有已发布回执才写入已发布日历。
4. 希望收到邮件时，在「设置 → 通知中心」配置收件人和 SMTP，开启自动通知并保存。未开启时只使用站内回执；手动测试邮件仅验证邮箱设置，不代表真实发布成功。
5. 发布成功邮件包含回执编号；有可信公开地址时附作品链接，否则明确说明未取得地址。排队、已交给 SMTP、失败独立显示。SMTP 接受不保证收件箱送达，仍可能被邮件服务拦截或进入垃圾邮件。
6. 小红书、视频号、B站、抖音和快手的「已提交／待核实」回执支持「核实发布结果」「暂停自动核实」「开启自动核实」。这些按钮只查询已有作品，不会重新上传或提交。自动核实首次等待 60 秒，之后逐步延长间隔，最多 24 小时、12 次；达到上限后，有可靠作品编号的回执仍可手动查询。手动查询至少间隔 30 秒。

站内提醒在工作台打开时更新；审核结果的查询要求 Web 服务运行。离开发布页不会取消查询，关闭服务会停止本服务拥有的核实进程，重启后按保留设置恢复。私密／有限可见或登录失效时停止自动核实，需调整可见性或重新登录后手动核对。中断的发布任务保持待核实，排队邮件改为发送结果未确认，不自动重新发布或重发。该查询工作器不是独立定时发布执行器。

## 本轮平台范围

| 平台 | 公开成功的判断 | 当前限制 |
| --- | --- | --- |
| B站 | 上传前作品快照、上传后读回匹配新作品；状态明确公开且 BV 号有效才显示成功并生成作品链接 | 首次读回仍审核中时显示已提交；无读回、未知状态或仅 AV 内部号时待核实 |
| 抖音 | 作品读回明确公开、合法作品 ID；区分视频和图文地址 | 审核中/定时发布只报已提交；私密和未知状态不能报公开成功 |
| 快手 | 作品读回明确公开且作品 ID 有效；仅可分享的作品 ID 生成公开链接 | 有效的内部数字 ID 可对应已发布结果，但不猜成公开 URL；没有可信地址时说明缺失 |
| 知乎文章 | 发布操作后观察到精确的公开文章 `/p/<id>` 地址 | 本次未验知乎回答的独立 CLI 发布链路 |
| 小红书 | 观察创作者页面自己的作品列表响应；明确已发布、公开、非定时且无受限标记，作品 ID 合法并匹配时才显示公开成功及 `/explore/<id>` 链接 | 状态规则已对照官方公开 JavaScript；没有已登录真实响应样本，缺字段或未知状态保持待核实。链接不携带平台令牌，本轮未验证外部作品访问 |
| 视频号 | 创作者作品列表明确 `handleStatus=2`、`visibleType=1`、非定时且无已知会员／受限标记，匹配作品后确认公开状态 | 状态规则已对照官方公开 JavaScript；缺字段和未知标记不作公开证据。保留作品编号，**未取得可验证的公开 URL，不提供猜测链接** |
| 微信公众号 | 成功创建草稿显示草稿 | 当前接口没有代替用户在公众号后台正式群发，不发送公开发布成功提醒 |

五平台会按回执安排只读后续核实，经过多久不是公开成功的证据。知乎文章和公众号暂不进入此工作器。既有定时队列仍仅派发发布计划，独立常驻的自动发布执行器尚未完成。

## 状态依据与作品匹配

R27 通过匿名 HTTP GET 核对官方公开前端资源，没有登录账号、调用写入 RPC 或复制鉴权签名。只读脚本打开当前账号的创作者列表，观察页面发出的指定列表响应；响应必须同时提供正确身份和明确公开状态。

- 小红书列表为 `/api/galaxy/v2/creator/note/user/posted`。官方 [状态枚举](https://fe-static.xhscdn.com/formula-static/ugc/public/resource/js/async/4108.3845b8c8.js) 中，`tab_status` 的 1/2/3/4 分别表示已发布、审核中、未通过、定时；`permission_code=0` 才为公开。[卡片打开逻辑](https://fe-static.xhscdn.com/formula-static/ugc/public/resource/js/async/98.18cd1a69.js) 还要求无定时、审核／拒绝、受限可见标志。脚本据此保守判定，保留缺失或未知状态。
- 视频号列表为 `/cgi-bin/mmfinderassistant-bin/post/post_list`，读取 `data.list` 的 `objectId`、`desc.description`、`createTime`。[官方枚举](https://res.wx.qq.com/t/wx_fed/finder/helper/content/finder-helper-content/res/static/js/async/537.9bd4b6c6.js) 定义处理成功、可见范围与会员限制；[官方列表逻辑](https://res.wx.qq.com/t/wx_fed/finder/helper/content/finder-helper-content/res/static/js/async/97.98a20fe5.js) 说明列表及作品 ID 的用途。存在短链接接口不等于已验证其公开域名和 ID 绑定，因此没有接入猜测地址。
- 已有作品 ID 时必须精确且唯一匹配，标题修改不会切换到其他作品。没有 ID 时只接受完整标题、原提交起止时间窗内的唯一新作品；允许一秒时间精度差，排除提交前作品。历史回执若既无 ID 又无完整时间窗，不开启自动核实。
- 同平台同作品只归属最先取得该 ID 的回执；即便落盘失败后恢复，另一个回执也不能据此写成功日历或发成功邮件。查询中的平台与登录、退出、账号在线检查互斥，防止同时使用或删除浏览器登录目录。

官方资源可能更新；上述规则不是固定不变的开放 API 承诺。来源 URL、SHA-256 和短摘录保存在本机忽略的验收记录中；未将整份第三方脚本或账号数据纳入源码。

## 回执与恢复边界

- 回执存于当前产出目录的 `_publish/receipts.json`；默认产出目录位于数据目录的 `outputs`。页面默认读取最近更新的 50 条，接口最多选择 200 条历史，活动任务另外保持可见；核实工作器读取完整待处理历史，较旧作品通过审核后会重新出现在最近结果里。GET 状态接口不启动查询、发布或邮件。
- 每次任务有独立随机编号、进度及短信文件；同平台已有活动任务时拒绝重复启动。验证码只提交给当前对应任务。
- 公开成功须来自版本匹配、平台与任务编号匹配的结构化回执，退出码 0、日志文字和用户正文中的地址不是成功证据。
- 公开链接在脚本、后端及前端校验平台与路径，拒绝平台控制台、伪造域名、非 HTTPS 和携带认证字段的链接。
- 平台执行结果与邮件结果分开保存。存储故障时保留当前进程已知结果并显示警告，不能承诺该结果在服务重启后仍能恢复。
- 成功处理先持久保存领取状态，再写日历／启动邮件；同回执不重复领取，同作品不跨回执重复提醒。重启会恢复未领取的完成处理；已领取但结果不明的邮件不自动重发。领取后进程崩溃可能留下未确认的处理结果，页面保留相应提示，不能承诺邮件必达。
- 直接运行技能 CLI 会输出结构化回执；本轮常驻站内与持久邮件状态接在 Web 发布页，不能将 CLI 或队列派发当成同一链路已经验收。
