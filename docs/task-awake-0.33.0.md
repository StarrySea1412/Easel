# 定时任务运行时防休眠 · 0.33.0候选

2026-10-27。定时任务页新增默认关闭的“任务运行时保持后端主机唤醒”开关，偏好写入任务SQLite设置表。服务每次启动恢复该偏好；仅当任务已通过派发前检查、即将启动会话时申请系统防休眠，并在该任务结束、失败、取消或服务关闭时释放。并行任务共用系统请求，最后一项运行结束后才释放。

Windows使用`SetThreadExecutionState`；Linux需要`systemd-inhibit`；macOS需要`caffeinate`。能力不支持时禁止开启，但仍可关闭从其他系统迁移来的旧开启偏好。系统请求失败会通过运行状态和页面提示错误。Linux辅助进程通过父进程管道EOF退出，macOS辅助进程通过`-w`绑定后端PID，避免后端异常退出后残留防休眠请求。开关只影响运行Easel后端的主机，浏览器可关闭；服务仍须运行。它不会唤醒已休眠设备，因此主机在计划触发前已休眠时，任务仍不会准时启动。
