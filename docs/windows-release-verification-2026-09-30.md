# Windows 交付验证记录（2026-09-30）

本轮版本 **0.2.3**，交付形态是 **图形安装器 + 网页工作台**。验证环境为 Windows 10 专业版 10.0.19045 x64 开发机的隔离目录，不是干净虚拟机。未执行 Git push 或公开发布。

## 用户入口

- `Easel-0.2.3-Windows-GUI.zip`：完整解压后双击其中的 `Easel-Setup-0.2.3.exe`。
- EXE 默认打开图形安装向导，选择位置、查看进度、失败重试，成功后点击“打开工作台”。
- 日常启动：安装目录的 `打开 Easel.vbs` → pythonw 图形启动窗口 → 浏览器工作台；错误和重试在图形窗口内处理。
- 设置保存位置后，再运行图形启动器并确认“重启并迁移”。取消确认只复用已有工作台；关闭浏览器不会自动停止后台。
- `Easel-0.2.3-windows.zip` 为源码载荷，保留命令行排错入口，普通用户使用上面的 GUI ZIP。
- 首次需联网下载依赖；不是完全离线包。测试版未签名、不注册系统卸载项，移除和恢复方法见 [使用说明](../WINDOWS-START-HERE.md)。

## 源码与回归

- 修复 Gateway / 安装进程继承 PIPE 导致无法结束；Gateway 冷启动等待上限 300 秒。
- 仅停止具有明确 root / PID / 监听端口 / 启动命令 / 页面证据的工作台；并发启动有锁，失败的新建 Web 子进程会回收，不影响其他应用。
- VBS 使用 UTF-16，正确传递空格、中文和 `&` 路径。真实 WSH → pythonw 测试检查参数和零控制台窗口。
- 目录联接保留逻辑 data/outputs 路径，安装后再次迁移时旧技能仍写入新位置；复制 SHA-256 校验，保留原目录，失败回滚。
- 前端 build / lint、15 项 Node 回归通过；最新前端为 `index-Bs3NbQ9K.js` / `index-gy2gacAG.css`。
- Python 3.11 全量 **989 passed / 1 skipped，64.15 秒**；仅跳过会修改用户 PATH 注册表的 Windows 检查。发行安装使用锁定依赖的 Python 3.12。
