2026-10-30。承接完整大版本和回归任务；本批为兼容修复，不代表完整目标、全仓回归或真实平台业务已验收。

## 原因与修复

笔记采集在登录墙和两次选择器超时处提前返回空列表，未执行空状态核对；上层创作概览又吞掉列表异常。实际CLI及Web刷新因此可能将失败记为成功，改写成功快照、账号覆盖元数据或采集时间。

- 导航后及异步等待结束后均核对精确官方HTTPS笔记管理页，拒绝登录墙、异站、用户信息网址和中途跳转；残留卡片不能绕过检查。
- 选择器超时不再直接返回空列表，只有实际可见“暂无笔记”等明确空状态才能确认空列表；加载中或未确认结果抛出原有采集失败异常。
- 列表采集移出概览的可选回退捕获范围，失败传到CLI非零退出及Web错误响应，现有保存代码不再提交这次失败结果。原概览回退、缺指标留空及历史保留规则不变。
- 监听器在finally中清理，资料关闭及锁释放保留。未新增页面或说明块，保留0.39.2补充展开及0.40.1账号修复。
