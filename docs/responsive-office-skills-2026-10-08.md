# 响应式、工作台技能与办公室任务验收（2026-10-08）

本记录对应用户清单 R16–R23。功能代码位于 `codex/creator-workflow`；源码、浏览器验收、真实模型和安装包分别记录，不互相替代。

## 本轮实现

- 工作台与对话共用 `ComposerSkills`、技能状态和详情组件。首页常驻技能入口、已选标签及“本次创作补充要求”；首页草稿独立保存，提交被接收后把正文、技能和要求移交新会话，拒绝、断连或保存失败保留草稿。
- 设置导航采用多行网格；创作导航、日历和选题操作按实际内容宽度换行。工作台统计卡在窄内容区为两列；分析、账号、运行记录、生图与办公室按容器宽度调整。月历保留紧凑日期/数量，点击日期打开完整清单；弹层限高并允许纵向滚动。
- 办公室前置任务输入、成员任务、已上报步骤、回执及过程/产出入口。支持新建任务或继续主会话，每次提交可指定渠道和模型；请求、重试和恢复保留选择，失败不静默更换模型。
- 整轮中断沿用当前会话的活动任务接口，等待后台确认；停止失败保留已收到内容与恢复标识。单独成员控制另行核验 `expectedRunId` 和网关回执，不能把整轮接口也描述成已升级为精确网关 runId 停止。
- 明确模型指定只开放已审阅的 OpenClaw **2026.9.2** 严格协议，检查实际版本、已批准身份/权限及本次选择。能力查询不触发推理，不自动配对或扩大权限；登记配置不代表实际模型验证。
- 每次用户追加或打断先更新需求清单和执行顺序；最终验收增加新用户首次运行条件。

## 关键操作

- 首页实际选择“金句卡 / 数据卡”、编辑并保存补充要求，刷新后正文/技能/要求仍在；离线提交显示草稿保留。成功移交、保存拒绝和迟到响应由模拟接口回归覆盖。
- 技能详情实际使用点击与键盘聚焦验证。独立鼠标 hover 分支由模拟 DOM 回归覆盖，未声称实际鼠标悬停已验收。
- 日历编辑器末尾 Tab 回到关闭按钮，Shift+Tab 回到保存；保存回到原日期按钮。当天清单可进入编辑；截图复核发现长标题省略后，补修为自然换行，实际 261px 文本区完整显示两行、无横向溢出。本轮新建的日历与选题样本在检查后清理。
- 办公室切换指定渠道/模型时实际显示不可用原因及禁用选项；模型管理入口实际到达设置模型页。过程面板可打开、Escape 关闭；产出定位实际滚动并聚焦“工作区产出与文件位置”。角色编辑可打开和取消，补拍底部确认保存/取消可通过键盘和正常纵向滚动访问。生图和发布操作区也补拍核对。
- 主验收页已清理本轮首页技能、要求和文本样本，恢复窄工具栏、展开会话栏及原始 1280×720 浏览器尺寸；原有会话和材料未清理，演示开关仍关闭。
- 页面无自有管理员登录，不为本轮新增认证；用户要求的本地管理员账号约定在项目存在该认证系统时才适用。

## 新用户首次运行

使用忽略目录下的独立源码副本与初始为空的数据目录，首次复制不包含 `.venv`、`.tools`、`node_modules`、`dist` 或 `.env`。清除继承的 Easel、OpenClaw 和模型环境变量，使用新建 Python **3.12.10** venv（不继承系统 site-packages）、Node **24.19.0**，重新安装依赖并执行 `npm ci` 与生产构建，没有借用开发环境的前端产物或发布浏览器缓存。主机已有 Git、Python、Node 和 FFmpeg，因此这是独立源码/依赖/数据的首装检查，**不是全新 Windows 系统验收**。最终两处 CSS 收尾由 7870 最终构建复核，独立安装副本的构建早于这两处修正。

实测首装发现并修正三处问题：`biliup>=1,<2` 解析到仅有源码包的 1.2.11，额外要求 Rust 工具链；现固定为与 Windows 发行锁一致的 **1.2.9**，实际取得 Windows wheel，`pip check` 通过。`.env.example` 的模型密钥默认留空，避免占位字符串被当作已配置。README 的 Windows 启动改用 `scripts/start_workspace.py`，恢复同一数据目录中的网关配置与本地工具路径，避免新终端裸启动读错运行环境。

官方 Chromium 下载在默认 30 秒及调整后的 120 秒等待下均失败；官方 CDN 地址最终可返回 HTTP200，但真实下载仍连续超时，**完整浏览器安装未通过**。没有关闭 TLS、改用第三方镜像或复用已有浏览器缓存。安装脚本保留用户自定义等待时间，并允许显式选择 `-DeferBrowser`；该项仅暂缓 Chromium，其余阶段失败仍返回失败，安装记录明确为 `skipped / deferred: true`。不带该参数重跑会重新执行浏览器安装，已有成功浏览器状态不会降级；这些恢复与错误分支由定向回归覆盖，并未宣称本机已完成真实补装。

实际运行的公开入口（从独立源码目录执行，`..\data` 为独立数据目录）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -NonInteractive -DeferBrowser -DataDir ..\data
.\.venv\Scripts\python.exe .\scripts\start_workspace.py --data-dir ..\data --port 7871 --no-browser
```

第一条实际退出 **0**，七个阶段 `ok`、Chromium 明确延期。第二条在新的 PowerShell、隔离用户目录及清空相关环境变量后执行，实际退出 **0**；独立 Gateway **37371** 健康，Web **7871** 可用。首页及其引用的四个本地 JS/CSS 均 **HTTP200**，内容与该次独立构建字节一致。`status`、模型设置、聊天模型预设、账号、办公室模型五个接口均 HTTP200：115 个技能、零画像、零已配置聊天模型、8 个聊天预设、七个平台均未登录；办公室模型明确返回尚未配置。该次自动安装的 OpenClaw 为 **2026.9.8**，基础启动通过不代表已支持仅对 2026.9.2 核验过的严格按轮指定模型协议。

真实浏览器另行打开 7871，看到新用户首页、空创作框与常驻技能入口；欢迎引导选择“先用通用模式”后，可进入「设置 → 模型配置」，显示“未配置”。实际展开「添加供应商」，名称、模型、Base URL、API Key、获取模型和设为主入口可见。未输入或保存密钥，也未调用模型；刷新后丢弃空白表单。验收结束关闭该临时页并清理本轮独立服务，保留主验收页。因此可以确认：按 README 从独立环境能启动**基础工作台并进入首次配置**；AI 创作需要用户有效模型配置，依赖 Chromium 的平台登录/发布需补装后另验。
