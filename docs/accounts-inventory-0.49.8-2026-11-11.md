# 默认账号与独立账号展示修复 · 0.49.8

## 根因与实际数据

用户截图中侧栏显示知乎既有昵称，账号中心却显示0个账号。2026-11-11通过138正式登录后只读查询确认：`/api/accounts`保留知乎默认登录资料与昵称快照；`/api/social-accounts`独立注册表为空。旧账号中心只统计独立注册表，默认账号入口在下方折叠区，因此把既有身份呈现成了“账号不存在”。这不是本次查询发现的账号数据删除。

侧栏状态点仍按实时核验期限判断；保存昵称不等于当前在线。此次接口核对未调用平台登录、投稿或模型。

## 修复范围

- 账号名单、平台卡和全部账号计数同时展示已知默认身份及独立账号，明确标记来源；只有空浏览器目录、无身份资料的通道不冒充一个账号。
- 默认行保留昵称快照；过期、未知与明确需登录分别呈现，身份键不匹配的旧缓存不串账号。昵称与编号遵循隐私开关。
- 默认账号详情跳转原管理弹窗，登录活动按平台筛选；不合成独立账号ID，不迁移或复制Cookie/浏览器资料。
- “可分发”只统计身份已核验且空闲的独立账号；默认身份不参与独立批次，在线默认账号仍通过原默认通道管理。
- 初次部分加载或读取失败显示未知/不完整提示，不提前显示“全部0”和首次添加空态；刷新同时重读默认与独立列表。
- 侧栏补充默认通道快照说明。两套发布执行路径、后端账号注册与认证方式保持原契约。
