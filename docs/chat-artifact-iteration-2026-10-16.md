# 对话产物与可靠图片生成迭代（2026-10-16）

按[产物链路调研](chat-artifact-harness-research-2026-10-16.md)的P0-A → P0-B → P1顺序实施。图片/HTML由独立文件交付记录进入原对话，刷新读取真实文件；生成工具和工坊共用一条持久队列。没有采用DeepSeek Harness作为运行依赖。

## 已实现

| 环节 | 实际行为 |
| --- | --- |
| 文件交付 | `ArtifactStore`在数据目录`outputs/_artifacts/registry.sqlite3`保存会话、轮次、工具调用、文件身份、版本和交付事件；批量交付先核验全部文件，事件与登记同事务。路径不能越界、经过外部符号链接或指向系统/隐藏文件。图片通过Pillow实际验证。 |
| 对话展示 | 所属助手轮次直接展示图片、隔离HTML及下载；没有最终正文仍能显示。服务端快照独立于浏览器缓存，重开同一已知会话可恢复文件；后台迟到的交付可形成独立消息。 |
| 真正刷新 | 内容SHA256与本地HTML/CSS关联资源共同决定版本；同名、同大小、同mtime覆盖仍可识别。手动刷新强制重载图片/iframe，失败可重试；可见卡片每8秒核对实际文件。刷新不调用生成端或模型。 |
| HTML隔离 | iframe只允许脚本、不开放同源权限；响应另有CSP sandbox，禁止联网接口、表单和嵌套网页。CSS/图片等本地依赖使用版本化、受限资源URL；原始HTML/SVG下载不在主应用域执行。内部数据库不能经旧文件/媒体接口读取。 |
| 真实工具 | OpenClaw插件提供`easel_present`与`easel_generate_image`；宿主通过运行时sessionKey校验会话，执行Python脚本后返回真实回执。Codex新线程注册动态工具，宿主处理真实`item/tool/call`并按0.147协议回复。旧Codex线程通过已完成命令的交付标记或本轮带凭据脚本兼容。 |
| 共用生图队列 | 工坊和Agent均写入`outputs/_artifacts/image-jobs.sqlite3`；宿主Web worker才调用现有`ai_image.py`。图片成功后校验、保存元数据并自动交付到发起的会话/轮次，不要求Agent再写最终链接。 |
| 幂等与成本边界 | 每次明确生成使用固定requestId；重复调用取回原job，参数冲突拒绝。Agent工具只用已配置专用图片模型，无聊天密钥/贵模型回退；工坊明确选定的模型随任务冻结。浏览器提交丢响应时保留原请求标识。 |
| 并发 | 同一渠道在SQLite事务中占位，跨worker不超过额度。xjbh主域/子域固定1；image.mlgb7默认4且可降低，最多4；其他渠道默认1，`IMG_MAX_CONCURRENCY`可在1–4内设置。单次n≤4和并发额度分别处理。 |
| 失联与恢复 | 本地成功回执先保存，再做交付/终态；重启可恢复已有成功文件而不重新生成。执行超时、失败或lease失效则标`unconfirmed`并保留渠道占位，供人工核对供应商后显式解除；不把断开网页当作供应商取消。 |
| 后台回写与旧链接 | 仅读取当前精确会话的`gateway-injected`助手事件（SQLite含压缩记录，兼容确定性JSONL路径），以稳定消息ID去重并标“后台交付记录”。只迁移其中明确引用、当前实际存在的本地文件；普通正文或外部HTTP地址不猜造归属。原run的失败/停止状态保留。 |
| 非文字payload | 当前已成功的Gateway运行返回结构化本地`mediaUrl/mediaUrls`时，宿主校验文件后直接登记；`isError`、越界、缺失及远端地址不算成功产物。 |

## 用法

常规聊天保存文件后调用`easel_present`，或使用本轮提示中提供的`present_artifact.py --ticket ... --file ...`命令。凭据由宿主绑定精确会话/轮次，不手动复制其他会话的凭据，不提交凭据或个人文件到Git。

用户明确要求AI生图时，调用`easel_generate_image`，提供固定requestId、prompt和可选size。没有原生工具的旧线程可按本轮指令调用`image_job.py submit`，`status --job-id ...`只查询原任务。返回queued表示尚未提交供应商；running表示执行端正在处理；只有实际文件验证通过才展示图片。Easel Web服务需要持续运行以执行队列。

修改HTML应使用自包含CSS/脚本或本地关联资源。聊天的“刷新预览”只读文件；新的提示词生成应作为明确的新任务，不能靠刷新按钮反复提交模型。若原任务结果未确认，先在供应商处核对，再点击“已核对供应商，解除占位”。这个操作不取消远端请求、不重发旧任务，也不确认免费。

## 明确边界

1. 本轮没有调用真实付费模型或图片供应商，因此不确认真实渠道当前可用性、费用、生成速度、视觉质量或8图最终验收；也没有重发138原会话。
2. OpenClaw原生插件源码、实际工具工厂执行及本机运行器catalog均已验证，尚未发起真实模型选择工具的付费端到端验收。旧会话可用本轮命令兼容路径。Codex审计的是本机0.147 App Server实验schema，新旧线程契约分开处理。
3. 本轮恢复的是产物及有明确来源的后台交付。没有清空/改写用户localStorage，也没有迁移全部普通聊天正文为服务端权威历史；清空浏览器全部会话列表后的全面历史发现仍属后续迁移范围。
4. HTML预览禁止外部CDN/API、表单和嵌套网页；JS动态拼接或ES模块隐式导入的文件不会全盘猜测扫描，必须显式提供本地依赖。SVG原文件提供下载。读取当前版本不等于保留每份历史文件字节。
5. 后台注入读取有8MiB、单事件256KiB、每映射会话最近2000事件及100条回写消息的界限；过大/缺失记录给出说明，不假称完整历史。产物快照最多1000次交付，增量事件分200条返回；当前前端以有界快照和轮询同步。
6. 138、安装器、便携包不更新；既有预算/Gateway未提交改动及所有早期清单保留。当前工作台没有管理员登录，本次不新增认证或默认管理员。
