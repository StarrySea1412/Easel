## ClawHub官方协议与真实只读检查

- [官方API说明](https://github.com/openclaw/clawhub/blob/main/docs/api.md)：匿名读取，不读取本机登录态。
- 搜索 `GET /api/v1/search?q=...&limit=...`；详情 `GET /api/v1/skills/{slug}?ownerHandle=...`；按作者和slug核验身份，官方页路径为 `/{owner}/skills/{slug}`。
- 本地代理限制查询200字符/20条、响应1MiB、20秒期限、64项/60秒缓存，合并相同在途请求并限制并发、遵守429冷却。前端取消旧请求，支持失败重试、Escape关闭和焦点恢复。
- 真实本机代理搜索 `web search` 返回2条；`tinyfish/tinyfish` 详情为版本 `1.0.6`，其[官方页面](https://clawhub.ai/tinyfish/skills/tinyfish)返回HTTP200。结果随目录变化，不作固定推荐或安全认证。

## GLM视频协议与填写方式

在生视频渠道填写 `GLM_VIDEO_API_KEY`，可选 `GLM_VIDEO_MODEL`、`GLM_VIDEO_BASE_URL`。视频Key独立于聊天Key；默认根地址 `https://open.bigmodel.cn/api/paas/v4`、模型 `cogvideox-3`，另支持 `cogvideox-2`、`cogvideox-flash`。

| 步骤 | 协议/约束 |
| --- | --- |
| 提交一次 | `POST /videos/generations`，Bearer视频Key；不自动重试提交或跟随API重定向 |
| 查询 | `GET /async-result/{id}`；区分PROCESSING、SUCCESS、FAIL，拒绝异常状态或缺失结果 |
| 输入 | 提示词最多512字符；16:9、9:16、1:1；cogvideox-3支持本适配的5/10秒，旧模型省略时长；图生参考图转PNG、最多5MiB |
| 音频 | 共享音频配置发送 `with_audio`，默认启用；实际效果待真实模型验证 |
| 下载 | 只接受HTTPS公网地址，连接时校验并固定解析地址、逐次校验重定向；不携带API鉴权；512MiB上限、限时与原子写入；工坊核验MP4盒结构后才发布 |
| 取消/超时 | 停止本地等待/下载，服务商任务可能继续生成计费；不自动重新提交 |

2026-10-15核对的官方依据：[视频生成异步](https://docs.bigmodel.cn/api-reference/模型-api/视频生成异步.md)、[查询异步结果](https://docs.bigmodel.cn/api-reference/模型-api/查询异步结果.md)、[CogVideoX-3指南](https://docs.bigmodel.cn/cn/guide/models/video-generation/cogvideox-3.md)。指南当日标价1元/次；实际计费以账户、模型和提交时官方价格为准。本轮没有付费调用。

用户填好凭据并要求测试后，再进行小样本生成，核对状态、下载、播放、通知跳转和费用。协议模拟通过不能写为真实视频生成通过。
