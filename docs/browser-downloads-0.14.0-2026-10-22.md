# 网页文件下载 0.14.0

日期：2026-10-22。用户要求：“已经能够访问了，你看看能不能自动识别并下载文件吧”。从0.13.4交付基线`f24f842448d6460f4f47ed036c09d2cbbf0ee6d2`继续，功能分支`codex/browser-downloads-0.14.0`。本轮新增文件传输模块，版本按minor升至0.14.0；主工作区其他未提交修改保持。

## 使用方式

对话 → 新增面板 → 浏览器 → 打开目标页 → 工具栏“文件与下载”。页面上的下载属性、文件链接及下载/导出标签用于发现入口；可从列表选择，或直接在实时网页里点击。下载开始后，Easel自动接收并保存到当前会话，面板显示“正在下载”“正在保存”“已保存”或具体失败原因。只有实际保存完成的记录提供“下载到本机”和“加入对话”；加入对话保留原草稿，不自动发送消息或调用模型。

刷新后下载记录仍可读取。草稿文字会恢复，草稿附件沿用既有规则，需要重新添加；可在下载面板再次选择“加入对话”，无需重复下载。后端重启后已保存文件仍可取回，旧网页不会自动重新打开或重复动作。

自动识别的是候选入口。预览、菜单或“导出”按钮可能需要后续选择；点击后未触发文件时返回提示，不批量点击、不自动重复业务动作。浏览器文件下载和API点击动作各有状态，点击成功不等于文件保存成功。普通链接、网页中的视频预览或生成中的占位内容不自动计为交付物。

原生浏览器工具和OpenClaw桥接支持`download`动作，以当前`tabId`、`snapshotId`及`ref`选择已观察的候选；Agent仍须获得当前会话的站点操作授权。工具读取`downloads`回执，确认`state=completed`且存在`file`后才能引用文件。网页经普通点击、直接附件导航或Blob触发的下载同样自动接收，无需额外抓取签名链接。

## 保存与限制

- 文件保存在`outputs/_inbox/<会话范围>/download-<GUID>/<清理后的名称>`，兼容已有附件引用；回执保存实际大小、SHA-256和来源页，来源URL去掉query/fragment。会话间不能通过下载API读取对方文件。
- 支持PDF、DOCX/PPTX/XLSX、ZIP、PNG/JPEG/WebP/GIF、MP4/WebM/MP3/WAV/M4A，以及UTF-8的TXT/MD/CSV/JSON/SRT。检查文件头及Office ZIP索引，拒绝空文件、HTML错误/登录页、扩展名不符和安装程序等不支持格式。这些检查不等于全文阅读、病毒扫描或媒体解码验收。
- 单文件100MB、每会话300MB、所有网页下载600MB；同时2个下载，每会话最多40条记录，接收及传输各有120秒上限。远程流读取另有15秒I/O超时，具体还受浏览器sidecar临时磁盘限制。大视频需后续按部署资源扩展，当前不会宣称任意大小可下载。
- 已保存文件与下载回执保留；关闭会话取消未完成下载。后端重启把未完成记录标为失败，不自动重放；登录态仍沿用现有隔离浏览器生命周期，本模块不新增平台登录态持久化。
- 138浏览器与应用文件系统不同，复用既有私有Basic认证CDP网关，仅流式传输标准GUID对应的文件；固定路径、禁止跟随符号链接，不新增公网端口。下载API按现有工作台认证访问，强制附件、no-store及nosniff。

同OS身份的工具执行仍沿用现有信任边界，本模块不建立强进程身份隔离。密钥、平台登录态及验收文件不提交到仓库。

## 升级与回滚

部署须使用本分支完整源码重建前端和服务器镜像，应用与browser sidecar一起更新：新的应用依赖`deployment/138/browser_cdp_proxy.mjs`中的私有文件GET/DELETE，以及`browser_sidecar.py`建立的700权限临时下载目录。只换前端或只换应用不能完成远程下载。沿用已有`EASEL_BROWSER_CDP_ENDPOINT`、`EASEL_BROWSER_AUTH_FILE`和私有网络，无需新开端口。

保留原访问配置、用户、outputs、平台资料、镜像及数据备份；不将本地固定测试密码植入生产。现有服务器测试管理员入口和认证规则沿用原部署，本轮没有新增认证、修改账号或重新验证生产登录。升级先在隔离实例核对版本/构建SHA、sidecar传输和草稿附件，再人工检查ChatGPT/Gemini现有文件下载及会话恢复。对收费生成、上传和发布另按用户任务授权处理。

回滚恢复旧应用和sidecar镜像及对应静态资源；本轮无数据库迁移，已保存文件保留。旧前端不展示新下载面板，旧后端也不自动接收网页文件。不要删除outputs、认证配置或真实浏览器资料来“回滚”。

本次授权完成源码、隔离验收与Git交付；遵照项目约定，不自动部署138、合并功能到main或发布安装器。默认分支只同步双语首页并链接本功能分支文档。
