# 通知位置、上下文细则与停止恢复修复（2026-10-15）

本轮接续[本机功能收尾](local-workbench-features-2026-10-15.md)，按用户截图纠正通知和上下文入口，并优先处理“不能终止、对话卡死”。仅在 [7880本机工作台](http://127.0.0.1:7880/) 生效；开发分支为 `codex/upstream-compat-2026-10-10`，main仅同步中英文首页。

## 界面与入口

| 入口 | 行为 | 数据边界 |
| --- | --- | --- |
| 左侧工具栏底部，账号与设置之间 → 事件通知 | 两种工具栏宽度均可用，保留未读/已读/清空/查看目标；浮层脱离侧栏裁切区域 | 同标签页100条历史的范围保持原样；完整服务端持久通知仍待实现 |

| 上下文弹层 → 消耗与费用明细 | 当前会话/项目账本、调用、缓存/推理、渠道与费用口径，复用实际用量组件 | 未上报保持未知，报价估算和记录费用均不是供应商账单；Codex账本未接入 |
| 容量未知 → 设置模型上下文容量 | 打开已有模型配置入口 | 不自动填写容量，也不增加模型真实上限 |
| 生成中 → 停止生成 | 输入新草稿后仍显示；有草稿时同时保留排队发送 | 不再因输入文字而隐藏停止按钮 |
| 停止失败/超时 → 重试停止、保留记录并新建对话 | 保留旧消息/草稿/任务标识，新建对话不自动发送请求 | 后台未确认时不谎报已停止；旧任务仍可返回核实 |

通知与上下文弹层均限制在视口内，Escape关闭并将焦点还给入口；用量模态框保留焦点循环及返回。停止提示改为明确的状态卡片，输入区过高时允许独立滚动，避免队列和错误把工具/按钮挤出可见区域。

## 上下文数据来源

新增只读 `GET /api/usage/context?sessionId=...&modelRef=...`，响应禁止缓存，仅返回数字快照及有限身份元数据，不返回提示词、工具Schema、技能正文、配置路径或凭据。

- 容量优先取所选模型配置 `contextWindow`，匹配身份时可读取运行时 `contextTokens`；没有值则显示未知。
- 占用优先取项目所属原生会话最近 `totalTokens`；缺失时使用账本**最新一次请求的输入Token**，不会累加历史，也不会跳过最新缺失值去借用更早请求。选择的模型与快照模型不一致或原快照模型身份缺失时，不拼接旧占用和新容量。
- 六类包括消息、系统工具、MCP工具、系统提示词、技能、其它。只有对应同模型的 `source=run` 提示词报告才按字符数÷4估算，显示“≈”；嵌入技能、工具列表和项目上下文从系统提示词中扣除，避免重复。消息是已知开销外的余量，包含附件/工具回执；其它含工作区注入，MCP仅凭明确工具名称识别。
- 缺报告或开销大于测量总量时不编造占比；Codex明确未提供。当前本机原生会话报告缺失，所以实测显示“未提供”，完整六类估算展示由隔离数据回归验证。

## 停止卡死的原因与修复

用户截图对应的旧任务留下 `running`标记和已有事件日志，但Web服务重启后没有原supervisor。旧恢复接口只要日志存在就不断发心跳，停止接口又因内存中没有原任务而返回false，页面长期停在等待。此前本轮更新本机时进行了Web重启，未把这种存量任务恢复闭环覆盖到，是本次明确补上的缺口。

现在恢复接口发现日志已无本机supervisor时会结束无效重连，显示可核实的停止/新建入口；新原生任务在接受时保存确切runId。显式停止可对已有标记、确切网关runId及会话锁进行核实，旧格式只接受共享事件中出现的同一唯一runId；只停止对应运行，不发送新的Agent提示。网关确认精确停止或已无活动运行后，保存已收到的正文（含替换快照）和思考，再补终态事件。已结束但最终结果丢失的任务标为中断，不能伪装为正常完成。

同时补齐等待会话锁时的取消、新任务不会被旧停止请求误伤、停止确认后不无限等待已失效的接收连接、50秒前端请求期限及停止/自然完成竞态。队列在手动停止后仍需用户确认继续，不自动重发付费请求。

本机真实取证中，旧任务的精确 `chat.abort` 回执为 `ok=true, aborted=false, runIds=[]`，`agent.wait`返回结束错误状态；共享原始事件也有同runId的 `assistant_message_end`。核实后清理了旧运行标记，保存55,009字符已收到的思考，正文为空，明确记录 `chat_supervisor_lost`。随后实际 `/api/chat/stop` 返回HTTP200及 `stopped=true/status=already_finished`，不再反复返回未确认。本轮未执行新模型或视频生成。
