# PPT 幻灯片生成

你负责写大纲内容，`skills/shared/scripts/pptx_build.py` 负责确定性生成。
一份大纲同时产出：`deck.pptx`（可编辑，交给 PowerPoint/WPS）＋ `deck.html` ＋
`slide-NN.png`（逐页预览）＋ `deck.pdf`（整册打印/分享）。

## 与其他演示类 SKILL 的区别

- **pptx-slides（本 SKILL）** = 产出**可编辑 .pptx** 文件 + 图片/PDF 预览。用户要"能改的 PPT"时用它。
- **slideshow-video** = 产出**视频**（配音、字幕、转场），不是可编辑文稿。
- **infographic / card-*** = 单页视觉（图卡/信息图），不产出演示文件。

## 输入

- 一份 Markdown 大纲（由你撰写，格式见下）。
- 用户可能只给一句"做一份关于 X 的 N 页 PPT"——缺的信息（受众、场合、页数）
  先给合理默认并在回复里说明，不要为了问清楚停下来。

## 大纲格式（确定性解析，逐条遵守）

```markdown
# 演示主题                  封面标题（必须，第一行）

副标题文字                  # 后、第一个 ## 前的文本行 = 封面副标题
> 封面备注                  封面区的 > 行 = 封面演讲者备注（进 pptx notes，不进画面）

## 每页标题                 开始一页（默认要点版面）

- 要点条目                  页内 - 行 = 要点
> 本页备注                  页内的 > 行 = 本页演讲者备注

### 左栏标题                 一页里出现 ≥2 个 ### 时启用两栏版面
- 左栏条目                  栏内 - 行 = 该栏条目
### 右栏标题
- 右栏条目

## 大数字页
!42%                        ! 行 = 大数字版面主数字（每页至多一个）
- 解释条目                  大数字页的 - 行为解释（灰色小字）

## 引用页
“一句话引用。”              页内普通段落 = 引用版面（引号写在这一行里，渲染不重复加）
— 出处                      以 — 开头的行 = 署名（右对齐小字）
```

规则优先级：大数字 > 两栏 > 引用 > 要点（一页同时出现多种标记时按此取版面）。
每页至多一种版面意图，不要混排。

## 执行步骤

### 1. 写大纲

写到 `outputs/<主题>/outline.md`（目录不存在就建）。内容由你确定，遵守上面的
格式与下面的设计规范；每页要点 ≤5 条、每条尽量 ≤28 字（过长会挤压版面，可拆成两栏）。

### 2. 生成产物

```bash
python skills/shared/scripts/pptx_build.py build -i outputs/<主题>/outline.md -o outputs/<主题>/
```

- 默认产出全部四类（pptx/html/逐页 PNG/PDF）。
- 无 Chromium 的环境加 `--skip-render`，只出 pptx/html（脚本会给安装指引，不裸错）。
- 产物基础名默认 `deck`，可用 `--name` 改。

### 3. 检查与登记

- 用 Read 打开 `slide-01.png` 等逐页预览核对：不溢出、不空页、大数字页只有一个焦点。
- 把 `deck.pptx`、逐页 PNG、`deck.pdf` 按现有机制登记进原对话（pptx 可下载、
  图片/PDF 可直接预览）。不要只给文件路径，也不要声称已发送不存在的文件。

### 4. 修改

用户要改内容时：改 `outline.md` 后重新运行 build（幂等覆盖同名产物），
**不要手改 pptx**。要改配色/版式时改大纲结构（如换成两栏），不要逐页对齐像素。

## 设计规范（精简版）

- **配色三色**：墨色 `#1F2937` 正文 / 蓝 `#2563EB` 强调 / 琥珀 `#F59E0B` 点缀；
  封面深色底 `#111827`、内容页白底。不要每页换色、不要彩虹渐变。
- **每页一个视觉焦点**：大数字页只放一个数字；引用页只放一句话；两栏页两栏信息量尽量对齐。
- **要点宁少勿挤**：每页 ≤5 条；写不下就拆页或改两栏，不要缩小字号硬塞。
- **避免"AI 味"**：不用模板水印、不堆 emoji、不写"赋能/闭环/抓手"这类空词
  （除非用户原文如此）；标题写具体的事，不写"关于……的探讨"。
- **备注放 `>` 行**：讲稿、口径提醒、数据出处提示都进备注，不进画面。

## 失败路径

- 缺 python-pptx：`pip install python-pptx`（脚本会给出同样提示）。
- 缺 playwright/Chromium：`pip install playwright && playwright install chromium`；
  或先 `--skip-render` 出 pptx/html，稍后补渲染。
- 大纲解析报错：按提示检查 `#` / `##` / `###` / `!` / `—` 行；一个 `#`、每页标题用 `##`。

## 边界（本版不做）

- 不做模板市场与主题编辑器；不支持转场动画、PPT 内嵌视频/复杂图表。
- 不做 pptx 反向渲染/编辑（读现有 pptx 出预览需要 LibreOffice，后续另评）。
- 生成与渲染全部离线、零付费模型调用。
