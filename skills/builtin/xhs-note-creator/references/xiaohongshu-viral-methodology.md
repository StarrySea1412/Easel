# 小红书爆款笔记制作方法论

> 可复用的爆款笔记方法论：素人感设计 + 卖点优先级 + 真实素材优先 + 迭代优化。
> 全文用占位符与规则表述，不绑定任何具体项目 / 品牌 / 生图服务。

## 一、核心原则

> 小红书卡组图片必须按card-xiaohongshu调用专用AI生图并取得真实回执；[card-design](../../card-design/SKILL.md) 只指导风格和构图，不把任务改为HTML截图。本文件只讲文案与内容，不覆盖生成工具选择。

### ❌ 内容上不要做的
1. **堆砌所有功能**：把所有特性都讲 → 没重点
2. **正式文案 / 品牌腔**：书面语、"革命性/颠覆性" → 距离感
3. **编造事实凑图**：生成示意不能伪装成实拍或实际效果；用户商品参考必须保持主体与可见特征

### ✅ 内容上要做的
1. **抓核心卖点**：只讲 1-2 个最稀缺的点（见"二、卖点优先级"）
2. **口语化**："有没有"、"宝藏"、"好看哭了"（闺蜜语气）
3. **事实参考优先**：商品实拍、实际截图和效果证据用于锁定主体和事实；卡组仍调用专用生图
4. **痛点共鸣**：说出用户具体场景的困扰

---

## 二、卖点优先级判断法则

### 判断标准（按优先级）
1. **稀缺性** > 常见功能 — 问：别人也能做到吗？独家 > 常见
2. **实用性** > 炫技 — 问：解决什么具体痛点？解决痛点 > 展示技术
3. **可感知** > 抽象概念 — 问：用户能直接看到效果吗？视觉对比 > 文字描述

### 打分法（可套任意主题）

把每个卖点按三维各打 1-5 分，相乘取 Top 1-2 作为核心：

| 卖点 | 稀缺性 | 实用性 | 可感知 | 得分 | 优先级 |
|------|--------|--------|--------|------|--------|
| {卖点A} | {1-5} | {1-5} | {1-5} | 乘积 | 🥇 核心 |
| {卖点B} | … | … | … | … | 🥈 辅助 |
| {卖点C} | … | … | … | … | 🥉 锦上添花 |

**结论**：封面主打得分最高的核心卖点，其余作背书或一笔带过。

## 三、素材使用策略

### 以真实素材约束生图主体与事实

| 内容类型 | 素材来源 | 处理方式 |
|---|---|---|
| **功能/效果对比** | 实际截图 / before-after | 仅用真实证据描述效果，专用生图制作卡面，不伪造对比 |
| **使用场景** | 实拍照片 | 同一referenceId约束商品和主体，专用图生图改变场景 |
| **知识/文字卡片** | 已核实文案与视觉设定 | 专用生图制作清晰少字卡面，准确文字按需局部修正 |

所有卡组先调用专用生图；真实素材用于参考主体和核实说法，不作为无需生图的替代交付。素材路径用工程内相对路径，不要硬编码本机绝对路径。

## 四、爆款封面文案模板

> 下面是**封面文案结构**（钩子怎么写）。封面**视觉**一律走 card-design 的封面骨架（大标题细字重 + 钩子副标 + kicker/信息行），用字号层级和留白营造张力，**不靠大 emoji / 手写感**。

### 模板 A：提问式封面
```
有没有那种
[核心功能描述]
的工具/方法？
[1-2 个关键数据/特点]
```
**适用**：新工具推荐、功能发现

### 模板 B：对比式封面（高转化）
```
左：[对比项 A]   右：[对比项 B]
大字：[反差点，如"几乎看不出差别"]
```
**适用**：有明显效果对比的内容（有真实 before/after 照片时用真实素材卡）

### 模板 C：发现式封面（高共鸣）
```
我发现了个宝藏！
[核心价值]
[解决的痛点]
终于不用 [痛点] 了
```
**适用**：解决痛点的工具/方法

## 五、文案公式库

### 封面钩子 / 标题公式
→ 公共源 `skills/shared/references/hook-title-formulas.md`（提问式/发现式/身份共鸣/对比式/数字冲击/热点切入等，小红书场景通用）。

### 正文结构（3 段式）
```
第 1 段 痛点共鸣："[具体场景痛点]？"
第 2 段 解决方案："[方案] 能做到："✅[卖点1] ✅[卖点2] ✅[卖点3]
第 3 段 社交证明 + CTA："我试了下，[具体效果]" + "[引导互动/拿资源]"
```

### 情绪词库
| 场景 | 正面情绪 | 负面情绪（痛点） |
|---|---|---|
| 发现 | 宝藏、绝了、爱了 | 后悔没早知道 |
| 效果 | 好看哭了、太强了 | 之前白熬夜了 |
| 速度 | 秒出、瞬间搞定 | 等到天荒地老 |
| 质量 | 专业、设计师级 | 土到掉渣 |

## 六、视觉风格

**卡片视觉完全交给 [card-design](../../card-design/SKILL.md) 设计系统**，本文件不再自定义视觉规则（旧版"纯色 + 大 emoji + 手写感 + 看起来不专业 + 文生图 prompt"已废弃——那套糙美学与高级感冲突、执行效果差）。

- 将card-design的选定风格、配色、字体层级和安全边距用于专用生图提示词；不写HTML作为替代出图路线。
- 「素人 / 真实感」通过参考商品、自然光线、构图与真实文案表达，不靠大emoji或糙排版。
- 取得真实生成图片和成功回执后，必要时才用Pillow局部叠字或合成，记录来源；缺配置、失败或结果未知不能用HTML截图兜底。

## 七、制作流程 SOP

1. **卖点分析**（~5 min）：列全部卖点 → 按"稀缺性 × 实用性 × 可感知"打分 → 选 Top 1 核心。
2. **素材盘点**（~5 min）：实拍/截图/对比图/数据图 → 提炼可核实事实并登记主体参考。
3. **确定封面类型**：有对比图 → 模板 B；解决痛点 → 模板 C；新工具推荐 → 模板 A。
4. **设计卡片结构**：默认恰好3张，封面钩子 → 核心细节/证据 → 同主体使用场景与自然收尾；只有用户明确要求其他数量时调整。
5. **生成卡片**：调用 `easel_xhs_cards` 或专用图片工具，取得真实成功回执和独立图片；随后逐张实际看图、按当前SHA提交review，不把排队或脚本通过当成质量合格。
6. **文案优化**：口语化？有情绪词？关键词突出？痛点+解决在位？

## 八、发布前 Checklist

- [ ] 封面抓住了最稀缺的卖点？（不是堆砌所有功能）
- [ ] 已取得专用生图成功回执、真实独立图片并逐张实际审图？（风格、主体、文案和边距都通过）
- [ ] 文案口语化？（不是正式文案 / 品牌腔）
- [ ] 参考图的商品主体和关键特征保持一致？生成示意没有冒充实拍/亲测？
- [ ] 关键词突出（字号层级 / 强调色）、层级清晰？
- [ ] 有情绪共鸣（痛点 + 解决）？CTA 清晰？

---

## 九、迭代优化原则

第一版先自检再交付，发现缺图、乱码、主体失真或虚构事实时明确未完成；通过实际审图后再收集用户反馈，每次改进1–2个关键点。
时间分配上，迭代往往比第一版更重要。**真实事实约束生图；聚焦核心卖点 > 功能堆砌；用户痛点 > 功能罗列。**
