# 小红书三图策划示例（仅说明工作流，未调用生图）

主题为虚构的黄色桌面玩具；示例不代表真实商品功能或生成结果。

1. 封面：参考图中的同一玩具放在干净书桌，短标题说明具体使用场景。
2. 细节：以同一主体展示参考图可见的外观与结构，不增加不存在的零件或性能。
3. 场景收尾：同一商品融入桌面收纳场景，给一个自然使用建议。

实际执行时使用 `easel_xhs_cards`，提供统一style、三个独立prompts与固定requestId；有参考图时三张使用同一referenceId。没有三图工具时使用专用 `easel_generate_image` 或ai-image-gen流程。

排队不等于完成；取得专用生图成功回执、真实独立图片并逐张实际看图后，才可提交当前SHA和具体审图依据。缺配置或失败明确未完成，不用HTML截图、拼贴或提示词作为图片成品。
