Backend platform keys are `xiaohongshu`, `kuaishou`, `weixin-channels`, `zhihu`, `bilibili`, `douyin`, and `wechat-oa`. The last key maps to `wechat.svg`. Video Channels uses its own orange loop mark, separate from WeChat's chat bubbles. Douyin uses its official multicolor site icon rather than substituting a TikTok-labelled asset.
